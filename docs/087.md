# 01 职场办公与项目效率工作台 · 完整搭建 SOP

## WorkBuddy 工作台全套资料 · 第 01 篇

<p><strong>本篇是「职场办公与项目效率工作台」的完整搭建 SOP，</strong><strong>也是全套 24 个工作台的功能总纲（风格先看第 00 篇）</strong><strong>——把这一篇走通，剩下 23 个就是换个主题重复一遍。</strong></p>

---

## 一、这个工作台解决什么问题

### 1.1 先看看你有没有这三个瞬间

<p><strong>瞬间一：</strong>周五下午四点，领导在群里@你：周报今天发。你翻聊天记录、翻文档、翻脑子，拼凑&quot;这周到底干了啥&quot;，拼了四十分钟，发出去总觉得少了点什么。</p>

<p><strong>瞬间二：</strong>手上同时跟着四五个项目，每个项目的关键节点全记在脑子里。某天早上领导问&quot;那个项目周三该交什么来着&quot;，你愣了三秒——完了，忘了。</p>

<p><strong>瞬间三：</strong>会上拍板的事，散会就散了。两周后开例会，领导问上次说好的那个事谁在跟，会议室安静得能听见空调声。</p>

<p>这三个瞬间，就是这一个工作台要干掉的。它不解决&quot;你怎么干活&quot;，它解决&quot;你怎么<strong>记住、看清、汇报</strong>你干的活&quot;。</p>

### 1.2 成品长什么样：一个桌面上的小软件

<p>先说清楚最终的形态，免得你搭到一半发现跟想的不一样：</p>

<p><strong>它会是你电脑桌面上的一个图标，双击就打开一个独立窗口，长得像个软件。</strong>不用联网也能用，所有数据都存在你自己电脑里，不需要注册任何账号，不需要装任何其他东西。</p>

<p>打开之后，它有四个页面，各管一件事：</p>

<table><thead><tr><th><p>页面</p></th><th><p>管什么</p></th><th><p>你什么时候打开它</p></th></tr></thead><tbody><tr><td><p><strong>今天</strong></p></td><td><p>今日到期的事、已经逾期的事、本周关键节点</p></td><td><p>每天早上到工位第一件事</p></td></tr><tr><td><p><strong>项目</strong></p></td><td><p>手上所有项目的状态、进度条、截止日期</p></td><td><p>领导问进度、自己心里没底的时候</p></td></tr><tr><td><p><strong>会议</strong></p></td><td><p>开过的会 + 会上拍板的行动项（谁、做什么、什么时候交）</p></td><td><p>开完会当场、以及下次会前翻旧账</p></td></tr><tr><td><p><strong>周报</strong></p></td><td><p>一键把本周项目进展、完成任务汇总成一段能直接交的周报</p></td><td><p>每周五下午</p></td></tr></tbody></table>

### 1.3 明确不做什么（这个比做什么更重要）

<p>第一版<strong>故意</strong>砍掉这些功能，别自己加戏：</p>

<table><thead><tr><th><p>不做的事</p></th><th><p>为什么不做</p></th></tr></thead><tbody><tr><td><p>多人协作、团队权限</p></td><td><p>这是给你自己用的私人工具，一上多人就得配账号系统，复杂度翻十倍</p></td></tr><tr><td><p>甘特图、资源排期那套重型项目管理</p></td><td><p>那是项目经理的活，你需要的是&quot;心里有数&quot;，不是管理整个部门</p></td></tr><tr><td><p>手机 App、跨设备同步</p></td><td><p>第一版先在电脑上用满两周，真有需求再说（第十一章给进阶路径）</p></td></tr><tr><td><p>接入微信、自动发消息</p></td><td><p>容易变成半成品。先让核心四页跑稳</p></td></tr></tbody></table>

> [!TIP]
> 💡
> <p><strong>为什么是&quot;桌面软件&quot;而不是表格？</strong>表格最大的问题是你得&quot;去填&quot;——填的过程就是成本，累的时候你就会放弃。软件把&quot;记&quot;这件事变成顺手点几下，成本够低，才能坚持。这是工作台能不能活过一个月的分水岭。</p>

## 二、开工前的准备（10 分钟，全在你这边）

<p>正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。</p>

### 2.1 准备清单

<ol><li><strong>WorkBuddy 客户端装好、登录。</strong>没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。</li><li><strong>在电脑上建一个空文件夹。</strong>比如<code>D:\我的工作台\职场办公</code>。这是 WorkBuddy 干活的地方，它生成的所有文件都会落在这里，别直接用 C 盘根目录或者桌面，乱。</li><li><strong>挑一个你顺手的浏览器。</strong>Edge 或 Chrome 都行。<strong>定了就一直用它开这个软件</strong>，因为数据跟着浏览器走（原因见第十章）。</li><li><strong>准备三条真实数据</strong>（纸面想好就行，不用打字）：你现在手上跟进的 2~3 个真实项目（名字、截止日期、大概进度）；最近开过的一场会（谁参加、拍板了什么事、谁负责）；你上周干的最主要的 5 件事。</li></ol>

> [!TIP]
> 💡
> <p><strong>唯一需要你动脑的就是第四条，但它是全套 SOP 里最不能省的一步。</strong>别用&quot;项目A、测试数据&quot;这种假东西——第一天就往里塞真项目，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。</p>

### 2.2 全程你会用到的角色分工

<p>整套流程就两个角色，别搞混：</p>

<ul><li><strong>WorkBuddy：施工队。</strong>所有代码、界面、功能都是它写，你一行代码都不用碰。</li><li><strong>你：甲方 + 验收员。</strong>你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。</li></ul>

<p>这个分工意味着：<strong>SOP 里所有&quot;做&quot;的动作都是复制粘贴提示词，所有&quot;判断&quot;的动作是你亲手点一遍。</strong>哪一步跳过了&quot;自己点一遍&quot;，后面必然返工。</p>

## 三、第一步：跟 WorkBuddy 把话说清楚（提示词一）

### 3.1 开工操作

<ol><li>打开 WorkBuddy，点<strong>新建任务</strong>，模式选<strong>Agent 模式</strong>（它能自己动手建文件，别选纯问答模式）。</li><li>把<strong>工作目录</strong>设成第二章建好的那个文件夹（比如<code>D:\我的工作台\职场办公</code>）。设错也不致命，就是文件会落别处，你得多翻一下。</li><li>在输入框粘贴下面这段提示词，回车。</li></ol>

### 3.2 提示词一：需求确认版（先别让它写代码）

```
我要做一个"职场办公与项目效率工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。需求背景：我是公司职员，同时跟 3-5 个项目，每周要写周报，经常开会。我的痛点是：项目节点容易漏、开会拍板的事没人跟、周五写周报全靠回忆。
```

### 3.3 为什么第一步是&quot;复述&quot;而不是&quot;开做&quot;

<p>你直接说&quot;帮我做个项目管理软件&quot;，它会按它想象中的样子给你一个<strong>通用的</strong>东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。</p>

<p>先让它复述，等于把&quot;需求的解释权&quot;拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。</p>

### 3.4 它大概会问你什么（提前有数，答得就快）

<ul><li>&quot;只有你一个人用吗？&quot;——答：是，就我自己。</li><li>&quot;项目类型是固定的几种还是随便填？&quot;——答：随便填，不想被预设框死。</li><li>&quot;周报要什么格式？&quot;——答：本周完成 / 下周计划 / 需要协调的事，三段。</li><li>&quot;数据要不要备份功能？&quot;——答：要，导出成文件存本地。</li><li>&quot;要不要提醒功能？&quot;——答：打开软件时能看到逾期和今天到期的就行。</li></ul>

<p><strong>这里出现第一个&quot;需要你输入&quot;的点：</strong>上面五个答案是我的版本，你照抄能跑通，但你最好按自己的真实情况改——比如你们周报格式是固定的，就把真实格式告诉它。这五句话，就是你这个工作台和别人的不一样的地方。</p>

## 四、第二步：让它先出方案，还是别写代码（提示词二）

### 4.1 提示词二：要一份方案

<p>需求确认完，先别放它写代码。继续粘贴：</p>

```
需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一个项目"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。方案用中文写，控制在 500 字以内，不要贴代码。
```

### 4.2 方案怎么验收：只看三样

<p>500 字方案一分钟看完，重点盯三处：</p>

<table><thead><tr><th><p>看什么</p></th><th><p>合格标准</p></th></tr></thead><tbody><tr><td><p>四个页面在不在</p></td><td><p>今天 / 项目 / 会议 / 周报，一页都不能少。少一个，你用几天就会发现要的东西没地方放</p></td></tr><tr><td><p>关键字段够不够</p></td><td><p>项目必须有&quot;截止日期&quot;和&quot;进度&quot;；任务必须有&quot;负责人&quot;和&quot;到期时间&quot;；会议的行动项必须挂&quot;负责人&quot;和&quot;截止时间&quot;</p></td></tr><tr><td><p>它砍掉的功能你认不认</p></td><td><p>它主动砍掉的，你扫一眼，砍得对就不吭声，砍错了就捞回来</p></td></tr></tbody></table>

### 4.3 方案不满意怎么改（提示词三，通用句式）

```
方案整体可以，改三处：
1. 项目列表按截止日期排，快到期的排最前面；
2. 会议里的行动项要能一键转成待办任务；
3. 把 XX 功能砍掉，改成 XX。确认后给我更新版方案，还是不要代码。
```

> [!NOTE]
> 📌
> <p><strong>一次最多改三处。</strong>这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。方案阶段改三处以内，能保证每处你都亲自验收过。</p>

## 五、第三步：生成第一版（提示词四，这次真写代码）

### 5.1 提示词四：带四条硬约束

<p>方案点头之后，粘贴这段。四条硬约束一条都别删——每一条背后都是踩过的坑：</p>

```
方案确认，开始做第一版。四条硬要求，必须全部满足：
1. 只做成一个单独的 HTML 文件，所有代码都写在这一个文件里，不要拆多个文件，不要安装任何依赖，做完我双击这个文件就能用；
2. 数据全部存在我电脑本地，刷新页面、关掉浏览器再打开，数据都不能丢；
3. 界面全中文，做得干净、字大、好点，我每天要打开好几次，别做成演示 demo 的样子；
4. 做完以后，你自己把整个软件从打开到写完一份周报完整点一遍，告诉我哪里顺手、哪里会让我困惑。做完告诉我：文件叫什么名字、放在哪个文件夹。
```

### 5.2 四条硬约束分别防什么坑

<table><thead><tr><th><p>约束</p></th><th><p>防的坑</p></th></tr></thead><tbody><tr><td><p>单文件、零依赖</p></td><td><p>不拆文件就没有环境问题，双击就能开；换个电脑整个文件拷过去照样能用；想发给别人也只是一个文件的事</p></td></tr><tr><td><p>数据存本地</p></td><td><p>数据丢失是这类工具的第一死因。刷新就清空的东西没人会用第二次</p></td></tr><tr><td><p>全中文、不做 demo 样</p></td><td><p>每天开好几次的东西，界面丑、字小、满屏英文，三天就把你的耐心耗光</p></td></tr><tr><td><p>让它自己先点一遍</p></td><td><p>省掉至少一半的返工。它自己走一遍流程发现的低级问题，比你上手之后一条条提快得多</p></td></tr></tbody></table>

### 5.3 第一版验收清单（5 分钟点完）

<p>WorkBuddy 做完后，去工作目录找到那个 HTML 文件，<strong>双击打开</strong>，然后逐条打勾：</p>

<ol><li>新建一个项目，随便填个名字和日期 →<strong>关掉浏览器 → 重新双击打开</strong>→ 数据还在。这一条不过，后面全白搭，直接打回去。</li><li>记一条会议，行动项里写&quot;张三、周三前交方案&quot; → 回到&quot;今天&quot;页，能看到这条待办。</li><li>点&quot;周报&quot;，能生成内容，有一键复制按钮，复制出来是正常文字不是乱码。</li><li>界面没有英文残留、没有乱码、字看得清。</li><li>三个页面都点一遍，没有点了没反应的按钮。</li></ol>

> [!TIP]
> 💡
> <p><strong>第一版只验&quot;通不通&quot;，不验&quot;好不好看&quot;。</strong>丑、慢、布局怪，都留到第七章的迭代环节统一处理。第一版就追求完美，你会陷入无止境的细节，搭不完。</p>

## 六、第四步：把真实数据喂进去（决定它是玩具还是工具）

<p>验收通过别急着庆祝。<strong>这一步最容易被跳过，也是决定工作台生死的一步。</strong></p>

### 6.1 操作

<p>把第二章纸面准备的三条真实数据，亲手录进去：2~3 个真实项目（含真实截止日期）、一场真实会议（含真实的行动项）、上周干过的 5 件事。慢没关系，15 分钟足够。</p>

### 6.2 录完你会遇到两类问题——这是好事

<p><strong>第一类：字段不合手。</strong>比如它默认&quot;优先级&quot;分高中低，但你心里想的是&quot;甲方催得紧不紧&quot;；比如它要你填&quot;项目编号&quot;，可你们公司根本没有编号。→ 记下来，这是第七章要改的。</p>

<p><strong>第二类：流程不顺手。</strong>比如新建一个项目要点五下、比如&quot;今天&quot;页信息太挤看不过来。→ 也记下来，同样进第七章。</p>

<p>拿张便签或者开个备忘录，标题就写&quot;工作台待改清单&quot;。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。</p>

> [!NOTE]
> 🎯
> <p><strong>本章验收：</strong>打开软件第一屏，看到的是你真实的名字、真实的项目、真实的截止日期——哪怕丑一点，你已经拥有一个&quot;能用的工作台&quot;了。反过来，界面再漂亮，里面全是测试数据，它也只是个 demo。</p>

## 七、第五步：迭代优化（8 条现成提示词，抄就完了）

<p>迭代不靠灵感，靠&quot;用的时候哪里硌手&quot;。第六章攒的&quot;待改清单&quot;就是原料。以下 8 条覆盖最常见的问题，直接抄，方括号里的换成你的情况：</p>

<table><thead><tr><th><p>哪里硌手</p></th><th><p>直接抄的提示词</p></th><th><p>改完怎么验</p></th></tr></thead><tbody><tr><td><p>新建太麻烦</p></td><td><p>新建一个项目要点好几下，改成：在项目页直接一行输入项目名就能建，其余字段以后随时补</p></td><td><p>新开一个项目，10 秒内完成</p></td></tr><tr><td><p>逾期看不清</p></td><td><p>把已超过截止日期的任务和项目标红，本周内到期的排在&quot;今天&quot;页最上面</p></td><td><p>故意填一条昨天的任务，看会不会红色置顶</p></td></tr><tr><td><p>周报不像人话</p></td><td><p>周报改成三段式：本周完成（按项目分组）/ 下周计划 / 风险与需要协调的事。语气自然，不要&quot;本周期&quot;&quot;持续推进&quot;这种套话</p></td><td><p>生成的周报你愿意直接发出去</p></td></tr><tr><td><p>行动项跟不住</p></td><td><p>会议的行动项完成后能勾掉，勾掉后从&quot;今天&quot;页消失，但会议记录里保留，能查到是谁什么时候做完的</p></td><td><p>勾掉一条，回会议记录里确认还在</p></td></tr><tr><td><p>找不到东西</p></td><td><p>加一个全局搜索框，按项目名、任务名、负责人、会议内容搜，搜中后高亮跳转</p></td><td><p>搜一个只记得一半的词</p></td></tr><tr><td><p>界面丑</p></td><td><p>整体换成深色模式，卡片间距加大，关键数字（逾期数、进度）加大加粗</p></td><td><p>看得顺眼，重点一眼能抓到</p></td></tr><tr><td><p>想看进度</p></td><td><p>项目卡片上加一个简单进度条，用代码直接画，不要引入任何外部图表库</p></td><td><p>进度数字变了进度条跟着变</p></td></tr><tr><td><p>怕忘写周报</p></td><td><p>每周五下午 4 点后第一次打开软件时弹提醒：该写周报了，本周未完成事项还有 N 条</p></td><td><p>改一下系统时间试一次</p></td></tr></tbody></table>

### 7.1 迭代的三条纪律

<ul><li><strong>一次只提 1~3 条。</strong>一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。</li><li><strong>改完用一遍，再提下一轮。</strong>改动生效后至少真实使用半天，硌手的地方会自己冒出来。</li><li><strong>提示词里带现象，别带结论。</strong>说&quot;我点周报按钮没反应&quot;比说&quot;周报功能坏了，你修一下&quot;效果好——前者是证据，后者是让你俩一起猜。</li></ul>

## 八、第六步：装到桌面（让它看起来像个软件）

<p>现在它还只是个 HTML 文件，打开方式是&quot;找到文件 → 双击 → 浏览器里开一个标签页&quot;。这一章把它变成桌面上真正意义的&quot;软件图标&quot;。</p>

### 8.1 三种方式对比

<table><thead><tr><th><p>方式</p></th><th><p>怎么做</p></th><th><p>适合谁</p></th></tr></thead><tbody><tr><td><p><strong>方式 A：浏览器快捷方式（推荐）</strong></p></td><td><p>用浏览器打开这个 HTML → 浏览器菜单&quot;更多工具 → 创建快捷方式&quot;（Edge 里是&quot;应用 → 将此站点作为应用安装&quot;）→ 勾选&quot;在窗口中打开&quot; → 桌面出现独立图标，双击就是<strong>一个没有地址栏的独立窗口</strong>，看起来就是个软件</p></td><td><p>所有人。5 分钟搞定，零成本，推荐首选</p></td></tr><tr><td><p><strong>方式 B：发布为在线链接</strong></p></td><td><p>让 WorkBuddy 用&quot;发布为应用&quot;把这个软件发布成一个网址，电脑手机都能打开，数据可以存云端；之后同样创建桌面快捷方式</p></td><td><p>想在手机上也看一眼、或多台电脑之间同步的人</p></td></tr><tr><td><p><strong>方式 C：打包成 exe</strong></p></td><td><p>用打包工具把网页套一层壳变成独立安装包</p></td><td><p>暂时不建议。要装打包环境、体积大、杀毒软件可能误报，折腾半天收益为零</p></td></tr></tbody></table>

<p><strong>推荐方式 A 的理由：</strong>改动即生效（WorkBuddy 每次改完，你重新打开就是新版）、数据在本机、不依赖任何服务。方式 B 等你确定&quot;我要在手机上用&quot;再升级，别一开始就上。</p>

### 8.2 收尾三件小事

<ul><li><strong>换个像样的图标：</strong>右键桌面快捷方式 → 属性 → 更改图标，挑一个顺眼的。别小看这个——桌面颜值决定你愿不愿意每天打开它。</li><li><strong>固定一个浏览器开它：</strong>右键 HTML 文件 → 打开方式 → 选你的浏览器并勾&quot;始终&quot;。数据跟浏览器走，别今天 Edge 明天 Chrome。</li><li><strong>给工作目录留个备份位：</strong>在<code>D:\我的工作台</code>旁边建一个<code>备份</code>文件夹，下一章马上用。</li></ul>

<p>软件搭完只是开始，这一章是它的&quot;日常运转节奏&quot;。就四个动作，加起来每天不到 5 分钟：</p>

## 十、数据备份（5 分钟一劳永逸，必须做）

### 10.1 先知道风险在哪

<p>本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：<strong>清理浏览器缓存、卸载浏览器、重装系统时，数据会没。</strong>所以备份不是可选项。</p>

### 10.2 先补上导出功能（如果你的第一版没有）

```
给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 项目工作台备份_20261110.json；2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
```

### 10.3 备份的三条规矩

<ol><li><strong>每周五发完周报，顺手导出一次</strong>，存进<code>D:\我的工作台\备份</code>。绑定在&quot;发周报&quot;这个动作后面，就不容易忘。</li><li><strong>换电脑、清缓存、重装系统之前，先导出。</strong>记住：清浏览器缓存 = 清空工作台，没有例外。</li><li><strong>恢复方法：</strong>点&quot;导入数据&quot;，选最新的 JSON 文件，确认。数据原样回来。</li></ol>

## 十一、进阶：让 WorkBuddy 继续替你干活

<p>软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合干活。三个进阶玩法：</p>

### 11.1 会议纪要直接变行动项

<p>开会时开录音转写（或拿到会议纪要），直接扔给 WorkBuddy：</p>

```
这是本周项目会的录音转写。请整理成两部分：
1. 决议列表，编号列出所有拍板事项；
2. 行动项表格：事项 / 负责人 / 截止时间。整理完告诉我：这些数据我手动录入工作台，还是帮我生成一份可以直接导入的 JSON？如果要生成 JSON，我现在把我工作台导出的数据结构发给你。
```

<p>开完会两分钟，会里的活就全进工作台了，不用手敲。</p>

### 11.2 让它看数据、挑毛病

<p>把导出的 JSON 发给 WorkBuddy：</p>

```
这是我项目工作台导出的全部数据。请分析：
1. 哪些任务逾期超过 3 天还没有进展；
2. 哪个项目风险最大，理由是什么；
3. 给我三条下周优先处理的建议。用平实的中文说，别客套。
```

<p>它给出的回答，值得你每周五花 5 分钟认真看一遍——相当于请了个免费的项目顾问。</p>

### 11.3 周报直接代写

<p>每周五把导出 JSON 发给 WorkBuddy，附一句：</p>

```
这是我工作台导出的本周数据。按"本周完成 / 下周计划 / 风险与协调事项"三段生成周报，语气自然、像人写的话，每段不超过 5 条。生成后我来改两句话就发。
```

<p><strong>注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。</strong>这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。</p>

## 十三、验收清单 + 写在最后

### 13.1 对照打勾

<ol><li>□ 桌面上有独立图标，双击打开是独立窗口</li><li>□ 断网也能正常使用</li><li>□ 录入了至少 3 个真实项目、2 条真实会议记录</li><li>□ 关掉重开，数据不丢</li><li>□ 周五用它 15 分钟内写完周报，全程没翻聊天记录</li><li>□ 至少导出过 1 次备份 JSON</li><li>□ 连续使用 5 个工作日以上</li></ol>

### 13.2 为什么这一篇是全套的总纲

<p>最后说透这套 SOP 的真正价值：它不是教你搭这一个软件，而是教你一套<strong>可复制 24 次的方法</strong>。</p>

<p>回头看整个流程，其实就五步：<strong>说清需求（先复述）→ 先出方案再写码 → 带硬约束生成 → 喂真实数据 → 硌手了再迭代</strong>。这套节奏对任何&quot;工作台&quot;都成立——下一回你想搭&quot;健身减脂工作台&quot;，把第 3~7 章提示词里的&quot;职场办公与项目效率&quot;换成&quot;健身减脂&quot;，痛点背景换成你的真实情况，走一遍流程就行。</p>

<p>24 个工作台，区别只在&quot;数据结构&quot;和&quot;你要喂的真实内容&quot;，方法一模一样。这也是为什么全套资料第一篇必须先做它——先会走，再想跑。</p>
