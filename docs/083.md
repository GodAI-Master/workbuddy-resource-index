# WorkBuddy 电商主图提示词与批量生成流程

本指南整理了通过 WorkBuddy 生成主图文案、设计出图提示词并执行批量任务的步骤。

## WorkBuddy 主图内容生成
1.1 适合场景
新品上架要一次性出一整套主图（白底、场景、促销、细节）
多 SKU、多产品需要批量出图，一张张做太慢
看到竞品主图排版好，想做出同样风格的新图
1.2 让 WorkBuddy 生成出图提示词（可直接复制）
打开 WorkBuddy，直接发下面这段指令（把产品信息换成自己的）：
你是一名资深电商美工。产品：【填写产品名和核心卖点】。请为我生成 5 组电商主图文案和对应的 AI 出图提示词，分别对应：①纯白底商品图 ②场景氛围图 ③促销活动图 ④模特使用图 ⑤细节特写图。每组包含：主标题（8 字内）、卖点短句（15 字内）、出图提示词（中文，含画面主体、背景、光线、色调、构图）。
WorkBuddy 会一次给出 5 组「标题 + 卖点 + 提示词」，确认满意后进入下一步批量出图。
1.3 一键批量出图
把产品清单整理成表格（产品名 / 卖点 / 想要的图类型），发给 WorkBuddy 说：
按表格逐行生成主图提示词，并逐张生成图片，生成后按「产品名-图类型」自动命名，统一存到本次交付目录。
WorkBuddy 会循环执行：生成提示词 → 生成图片 → 命名归档，一次跑完整批。产品多的话建议一行 3-5 张先试风格，满意后再跑全量。
1.4 参考图复刻
把竞品主图发给 WorkBuddy，指令：
拆解这张主图的排版结构、配色方案、文案层次，然后为我的产品【产品名】输出同风格的出图提示词，保留结构，替换产品与文案内容。
注意：只借鉴排版与配色结构，不搬运对方的原创设计与文案。
