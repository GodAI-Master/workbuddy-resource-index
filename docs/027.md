# FAQ与排错手册

21_FAQ与排错手册
WorkBuddy × ima 常见问题与排错手册
安装、授权、知识库、文件读取与结果质量
2026年7月整理版 · 操作前请核对当前官方界面

为什么找不到某个按钮？
先确认客户端版本和账号权限。AI工具更新快，旧视频的入口可能变化。优先查官方当前文档。
为什么读取不到本地文件？
检查文件路径、系统权限、文件是否被其他程序锁定；先用一个小测试文件重试。
为什么连接ima后看不到知识库？
确认授权账号是否就是目标ima账号；必要时解除绑定后重新授权。
为什么知识库回答很混乱？
知识库主题太杂、存在冲突版本或资料质量低。缩小主题并清理旧资料。
为什么结果会编造？
明确限制“只使用提供资料”，要求资料不足时说未找到，并人工核对关键事实。
可以让它直接删除文件吗？
不建议。先预览、用复制件测试、生成日志；高风险动作人工确认。
如何减少重复上传？
把长期复用资料放入ima主题知识库，任务中按需引用。
什么产物适合回存ima？
经过人工核对、未来可能复用的报告、FAQ、模板、复盘、正式笔记。
为什么自动化任务不稳定？
先确认单次任务稳定；再逐步自动化，并设计失败提醒和人工检查。
第三方教程和官方路径不一样怎么办？
以当前官方文档和客户端为准，第三方教程只作为思路参考。
