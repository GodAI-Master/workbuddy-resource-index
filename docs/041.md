# WorkBuddy 高频指令模板

108WorkBuddy 高频指令模板

核心发现：带"角色设定"的指令，输出质量比直接提问高出至少60%。
好指令公式 = 明确角色 + 具体任务 + 输出格式 + 注意事项

📁 01 办公场景指令模板（12条）
场景1：本地文件批量整理

你是文件管理专家。请帮我整理【目标文件夹】下的所有文件，按【文件类型/创建日期/文件名关键词】分类，生成新的文件夹结构，并输出一份整理报告。

场景2：Excel数据自动分析

你是数据分析师。请分析【上传的Excel文件】，完成以下任务：
1. 数据清洗（去重、补全缺失值）
2. 基础统计（均值、中位数、标准差）
3. 生成3个核心洞察
4. 输出可视化图表建议

场景3：周报/月报自动生成

你是我的职场助理。请根据我本周的工作记录，生成一份周报，包含：
1. 本周完成工作（按项目分类）
2. 本周数据与亮点
3. 下周计划
4. 需要的支持
语调：专业但不过于正式

场景4：会议录音/纪要自动整理

你是会议纪要整理专家。请将会议录音转写文本整理成标准会议纪要，包含：会议主题、参会人员、讨论要点、决策事项、待办任务（含负责人和截止时间）。

场景5：多平台文案同步生成

你是内容创作助手。请根据【核心内容】，生成3个版本的文案：
版本1（公众号，800字，深度分析风格）
版本2（小红书，300字，轻松活泼风格）
版本3（朋友圈，100字，简洁有力）

场景6：PDF与Word/Excel互转

你是格式转换专家。请将【上传的PDF文件】转换为Word格式，保持原排版，修复乱码，输出为【文件名.docx】。

场景7：多语种翻译

你是专业翻译。请将【选中文本】从【源语言】翻译成【目标语言】，保持专业术语准确，输出对照版本（原文+译文）。

场景8：网页内容自动抓取与整理

你是信息采集助手。请抓取【目标网址】的正文内容，提取核心观点，整理成结构化摘要（标题+要点+金句），输出为Markdown格式。

场景9：本地图片批量压缩/加水印

你是图片处理助手。请压缩【目标文件夹】下的所有图片，质量设为【80%】，宽度不超过【1920px】，并添加水印【水印文字】。

场景10：日程自动规划与提醒

你是我的日程助理。请根据【本周任务清单】和【时间预算】，生成最优日程安排，标注优先级，输出为日历格式（含提醒时间）。

场景11：邮件自动撰写与发送

你是邮件撰写助手。请起草一封【邮件类型】邮件，收件人【角色】，主题【主题】，内容包含【核心要点】，语调【正式/轻松】。

场景12：简历优化与修改

你是简历优化专家。请优化我的简历，针对【目标岗位】进行调整，突出【核心技能】，量化【工作成果】，输出优化建议+修改后简历。

办公场景核心：将繁琐的文件整理、数据清洗、文档生成等任务交给专业“角色”，解放双手，聚焦核心决策。

✍️ 02 创作场景指令模板（11条）
场景13：深度文章创作

你是一位拥有10年经验的内容创作者。请围绕【主题】写一篇深度文章，要求：
1. 标题吸引人但不标题党
2. 开头用故事/痛点引入
3. 主体部分有3-5个核心观点，每个配案例/数据
4. 结尾有互动提问
5. 字数【目标字数】

场景14：小红书文案创作

你是小红书爆款文案专家。请为【主题】创作一篇小红书笔记，要求：
1. 标题带emoji，12字以内
2. 正文分点叙述，用emoji引导
3. 结尾有互动钩子
4. 添加5-8个相关标签
5. 字数300-500字

场景15：PPT大纲自动生成

你是PPT设计顾问。请根据【主题】和【目标受众】，生成一份PPT大纲，包含：
1. 封面页
2. 目录页
3. 内容页（每页一个核心观点，配图表建议）
4. 总结页
5. Q&A页
总页数：【目标页数】

场景16：设计灵感自动抓取

你是设计灵感收集助手。请搜索【设计关键词】的最新设计趋势，整理成灵感板（配图描述+配色方案+字体建议）。

场景17：视频脚本自动生成

你是短视频脚本创作专家。请根据【主题】生成一段【时长】的短视频脚本，包含：画面描述、旁白文案、BGM建议、转场建议。

场景18：错别字/语法检查

你是文字校对专家。请检查【上传的文档】中的错别字、语法错误、标点误用，输出修改建议清单（含原文+修改后+修改理由）。

场景19：标题优化（生成多个变体）

你是标题优化专家。请为【文章内容】生成10个标题变体，分3类：悬念型、数字型、反差型。每个标题附上点击率预测。

场景20：内容去AI味

你是去AI味专家。请改写【文章内容】，要求：
1. 改用第一人称
2. 加入口语化表达
3. 删除AI高频词
4. 加入个人观点/踩坑经历
5. 保持原意但彻底改变文风

场景21：公众号排版建议

你是公众号排版专家。请为【文章内容】提供排版建议，包含：段落长度、重点标注位置、配图建议、分隔符使用、互动引导位置。

场景22：多模态内容生成

你是多模态内容创作助手。请根据【核心内容】生成：
1. 公众号文章（图文版）
2. 小红书笔记（图文版）
3. 短视频脚本（口播版）

场景23：内容合规检查

你是内容合规审查员。请检查【文章内容】是否存在：敏感词、夸大宣传、虚假信息、版权风险。输出合规报告+修改建议。

创作场景核心：从选题、写作、排版、合规到多平台分发，提供全链路“专家”支持，提升内容生产效率与质量。

🤖 03 自动化场景指令模板（10条）
场景24：定时任务设置（每日汇总）

请设置一个定时任务：每天早上8点，自动汇总我钉钉群里@我的消息，提取核心信息（谁、什么事、截止时间），生成一份待办清单，发送到我的微信。

场景25：多Agent并行调度（内容流水线）

请搭建一个内容创作流水线，包含3个Agent：
Agent1（选题研究员，每天早上9点抓取热点）
Agent2（内容创作者，根据选题写文章）
Agent3（排版助手，负责美化HTML）

场景26：批量文件操作（重命名/格式转换）

请批量处理【目标文件夹】下的所有文件：
1. 按【规则】重命名
2. 转换为【目标格式】
3. 输出处理报告（成功/失败清单）

场景27：自动数据备份

请设置一个每周日凌晨2点自动备份【源文件夹】到【备份文件夹】的任务，保留最近4个版本的备份文件。

场景28：网站内容自动监控

请设置一个每小时检查【目标网址】是否更新的任务，如果有更新，自动抓取更新内容并发送通知到我的微信。

场景29：社交媒体自动发布

请设置一个定时发布任务：每周一/三/五早上9点，自动将【内容库】中的文章发布到公众号草稿箱。

场景30：客户信息自动整理

请自动整理【客户沟通记录文件夹】中的信息，提取：客户名称、需求、预算、跟进状态、下次跟进时间，输出为Excel表格。

场景31：竞品信息自动追踪

请每周一早上9点自动抓取【竞品名称】的最近动态（官网/公众号/社交媒体），整理成竞品周报。

场景32：财务报表自动生成

请每月1号自动汇总【财务数据文件夹】中的报表，生成月度财务报告（含收入/支出/利润/现金流分析）。

场景33：项目进度自动跟进

请每天下午5点自动检查【项目管理表格】中的任务状态，提醒逾期任务，生成明日待办清单。

自动化场景核心：将重复性、周期性的工作（如数据备份、信息监控、报表生成）交给Agent，实现7x24小时无人值守。

📊 04 数据处理场景指令模板（10条）
场景34：Excel数据清洗

你是数据分析师。请清洗【上传的Excel文件】，完成：
1. 删除重复行
2. 补全缺失值（用均值/中位数/众数）
3. 统一格式（日期/数字/文本）
4. 标记异常值
5. 输出清洗后的文件和清洗报告

场景35：数据可视化建议

你是数据可视化专家。请根据【上传的数据文件】和【分析目标】，推荐最合适的图表类型（柱状图/折线图/散点图/热力图等），并给出配色方案和图表标题建议。

场景36：报表自动生成

你是报表生成助手。请根据【原始数据文件】生成一份【报表类型】，包含：
1. 核心指标卡片
2. 趋势分析图表
3. 同比/环比分析
4. 异常值标注
5. 结论与建议

场景37：调查问卷数据统计分析

请分析【上传的调查问卷数据】，生成：
1. 样本基本情况统计
2. 各题项频数分析
3. 交叉分析（如有）
4. 核心发现摘要
5. 可视化建议

场景38：销售数据多维分析

请对【销售数据文件】进行多维分析：按产品/地区/销售人员/时间段拆解，找出Top 20%的业绩贡献因素，输出洞察报告。

场景39：用户反馈情感分析

请对【用户反馈文本】进行情感分析，标注正面/负面/中性，提取高频关键词，归纳核心痛点，输出情感分析报告。

场景40：财务数据异常检测

请检查【财务数据文件】中的异常值（超出3倍标准差/环比波动超过30%），标注异常点和可能原因，输出异常检测报告。

场景41：库存数据智能预警

请根据【库存数据文件】计算安全库存、库存周转率、呆滞库存，生成库存预警清单（需补货/需促销/需清仓）。

场景42：项目成本自动核算

请根据【项目成本数据文件】自动核算：人工成本/材料成本/外包成本/其他成本，生成成本结构分析和成本优化建议。

场景43：数据故事化（让数据会说话）

你是数据故事化专家。请将【数据分析结果】转化为一个有趣的故事，包含：背景设定、冲突/挑战、数据揭示的真相、解决方案、结尾金句。让非专业人士也能看懂。

数据处理场景核心：从数据清洗、分析、可视化到洞察报告与故事化呈现，提供端到端的“专家”级数据处理服务。

🛠️ 05 使用方法
用法1：直接复制粘贴
找到你要的场景，复制指令模板，替换【方括号】里的内容，回车就行。
用法2：保存为常用指令
WorkBuddy有个"指令库"功能，可以把常用指令保存，下次直接点一下就能用。
用法3：改写成自己的风格
根据行业、岗位、工作习惯调整指令模板。

⚠️ 注意事项
每个人的工作场景不一样，必须根据自己的实际需求调整。
涉及敏感数据（财务数据、客户信息），使用前请备份原文件。
