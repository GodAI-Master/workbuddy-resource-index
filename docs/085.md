# 工作台制作（内含24个行业的完整制作流程）

## WorkBuddy 工作台全套资料 · 00 风格总纲 + 24 个工作台

<p><strong>一句话：1 篇风格总纲（00 篇）+ 24 个工作台，每一个工作台都是</strong><strong>一份&quot;照着做就能在自己电脑上做出一个桌面小软件&quot;的完整 SOP。</strong></p>

<p>这里说的&quot;工作台&quot;不是一张表格，也不是一份文档。它是你电脑桌面上的一个图标，双击打开就是独立窗口，数据全存在本机，断网也能用。每个工作台只管一件事：把你某个生活领域里&quot;记不住、看不清、懒得整理&quot;的东西，变成点几下就记下来的东西。</p>

> [!NOTE]
> <p>📌 <strong>24 个不是让你全做。</strong>挑你真正有痛点的 2~3 个先做，用满两周，再决定要不要加下一个。做法全部一样，区别只在&quot;数据结构&quot;和&quot;你要喂的真实内容&quot;。</p>

## 怎么用这套资料

<ol><li><strong>先看第 00 篇（工作台风格设定）。</strong>第 00 篇定风格，这一篇管功能——五步流程（说清需求 → 先方案后代码 → 带硬约束生成 → 喂真实数据 → 硌手再迭代）在这一篇讲得最细，走通它，后面每篇都是顺着走。</li><li><strong>再按需挑主题。</strong>每篇都能独立使用，不需要按顺序。想做哪个直接点进去，从&quot;开工前准备&quot;开始抄提示词。</li><li><strong>每篇都给现成的提示词。</strong>你不需要懂代码，所有提示词都能直接复制粘贴，只需要把方括号里的内容换成你自己的真实情况。</li></ol>
