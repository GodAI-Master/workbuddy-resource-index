# 15 收藏品图鉴与藏品管理工作台 · 完整搭建 SOP

## WorkBuddy 工作台全套资料 · 第 15 篇

<p><strong>本篇是「收藏品图鉴与藏品管理工作台」的完整搭建 SOP。</strong>一句话：把「这件什么时候买的、花了多少、现在值多少、放哪了」变成一份属于你自己的藏品图鉴。</p>

## 一、这个工作台解决什么问题

### 1.1 先看看你有没有这三个瞬间

<p><strong>瞬间一：</strong>朋友问你那枚纪念币哪来的，你只记得「好几年前买的」，具体年份、价格、来路全忘了。</p>

<p><strong>瞬间二：</strong>藏品越攒越多，某天发现买重了——同一款手办买了两盒。</p>

<p><strong>瞬间三：</strong>想给藏品估个价或者出手，完全不知道该卖多少，只能凭感觉被人砍。</p>

<p>收藏的乐趣一半在「有」，一半在「知道」。这个工作台负责后者：<strong>每件藏品的来路、成本、现状</strong>。它不会让你的收藏更值钱，但会让你收藏得更清楚。</p>

### 1.2 成品长什么样：一个桌面上的小软件

<p>先说清楚最终形态，免得你搭到一半发现跟想的不一样：</p>

<p><strong>它会是你电脑桌面上的一个图标，双击就打开一个独立窗口，长得像个软件。</strong>不用联网也能用，所有数据都存在你自己电脑里，不需要注册任何账号，不需要装任何其他东西。</p>

<p>打开之后，它有四个页面，各管一件事：</p>

<table><thead><tr><th><p>页面</p></th><th><p>管什么</p></th><th><p>你什么时候打开它</p></th></tr></thead><tbody><tr><td><p>藏品库</p></td><td><p>每件：名称、类别、入手日期、入手价、现估值、存放位置</p></td><td><p>收进来时</p></td></tr><tr><td><p>图鉴</p></td><td><p>按类别或系列排的图谱视图，带照片</p></td><td><p>想看的时候</p></td></tr><tr><td><p>保养提醒</p></td><td><p>需要防潮、上油、避光的藏品，按期提醒</p></td><td><p>每月</p></td></tr><tr><td><p>出手记录</p></td><td><p>卖掉或交换的，记去向和价格</p></td><td><p>发生时</p></td></tr></tbody></table>

### 1.3 明确不做什么（这个比做什么更重要）

<p>第一版<strong>故意</strong>砍掉这些功能，别自己加戏：</p>

<table><thead><tr><th><p>不做的事</p></th><th><p>为什么不做</p></th></tr></thead><tbody><tr><td><p>市场行情、拍卖数据</p></td><td><p>需要联网抓行情，本地软件做不到，数据也不可靠</p></td></tr><tr><td><p>鉴定、真伪判断</p></td><td><p>需要专业能力，软件不能替代</p></td></tr><tr><td><p>交易撮合、挂卖</p></td><td><p>涉及平台和资金，绝对不做</p></td></tr><tr><td><p>社交展示、圈子</p></td><td><p>会变成社交软件</p></td></tr></tbody></table>

> [!TIP]
> 💡
> <p><strong>为什么是&quot;桌面软件&quot;而不是表格？</strong>藏品的价值有一半是「信息」——你记得它怎么来的，它才有故事；你记得成本，你才知道自己赚没赚。这些东西不记，十年后就是一堆「不知道哪来的东西」。</p>

## 二、开工前的准备（10 分钟，全在你这边）

<p>正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。</p>

### 2.1 准备清单

<ol><li><strong>WorkBuddy 客户端装好、登录。</strong>没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。</li><li><strong>在电脑上建一个空文件夹。</strong>比如<code>D:\我的工作台\收藏品</code>。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。</li><li><strong>挑一个你顺手的浏览器。</strong>Edge 或 Chrome 都行。<strong>定了就一直用它开这个软件</strong>，因为数据跟着浏览器走（原因见第十章）。</li><li><strong>准备几条真实数据</strong>（纸面想好就行，不用打字）：你收藏的品类（手办/钱币/邮票/球鞋/唱片）；最有意义的 3 件的入手价和年份；你最怕它坏的一件。</li></ol>

> [!TIP]
> 💡
> <p><strong>唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。</strong>别用&quot;项目A、测试数据&quot;这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。</p>

### 2.2 全程你会用到的角色分工

<p>整套流程就两个角色，别搞混：</p>

<ul><li><strong>WorkBuddy：施工队。</strong>所有代码、界面、功能都是它写，你一行代码都不用碰。</li><li><strong>你：甲方 + 验收员。</strong>你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。</li></ul>

<p>这个分工意味着：<strong>SOP 里所有&quot;做&quot;的动作都是复制粘贴提示词，所有&quot;判断&quot;的动作是你亲手点一遍。</strong>哪一步跳过了&quot;自己点一遍&quot;，后面必然返工。</p>

## 三、第一步：跟 WorkBuddy 把话说清楚（提示词一）

### 3.1 开工操作

<ol><li>打开 WorkBuddy，点<strong>新建任务</strong>，模式选<strong>Agent 模式</strong>（它能自己动手建文件，别选纯问答模式）。</li><li>把<strong>工作目录</strong>设成第二章建好的那个文件夹（比如<code>D:\我的工作台\收藏品</code>）。设错也不致命，就是文件会落别处，你得多翻一下。</li><li>在输入框粘贴下面这段提示词，回车。</li></ol>

### 3.2 提示词一：需求确认版（先别让它写代码）

```
我要做一个"收藏品图鉴与藏品管理工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。需求背景：我有收藏爱好（手办/钱币/球鞋/唱片/邮票）。痛点是：记不清每件的入手价和年份、买重过、不知道该卖多少钱、有些需要保养但总忘。
```

### 3.3 为什么第一步是&quot;复述&quot;而不是&quot;开做&quot;

<p>你直接说&quot;帮我做个收藏品图鉴与藏品管理工作台&quot;，它会按它想象中的样子给你一个<strong>通用的</strong>东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。</p>

<p>先让它复述，等于把&quot;需求的解释权&quot;拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。</p>

### 3.4 它大概会问你什么（提前有数，答得就快）

<ul><li>&quot;收藏什么？&quot;——品类，可以多类</li><li>&quot;要记估值吗？&quot;——要，但允许写大概</li><li>&quot;要不要照片？&quot;——要，图鉴靠照片</li><li>&quot;存放位置要记吗？&quot;——要，找不到是最常见的痛</li><li>&quot;出手记录要不要？&quot;——要，能看出赚没赚</li></ul>

<p><strong>这里出现第一个&quot;需要你输入&quot;的点：</strong>上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。</p>

## 四、第二步：让它先出方案，还是别写代码（提示词二）

### 4.1 提示词二：要一份方案

<p>需求确认完，先别放它写代码。继续粘贴：</p>

```
需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一条记录"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。方案用中文写，控制在 500 字以内，不要贴代码。
```

### 4.2 方案怎么验收：只看三样

<p>500 字方案一分钟看完，重点盯三处：</p>

<table><thead><tr><th><p>看什么</p></th><th><p>合格标准</p></th></tr></thead><tbody><tr><td><p>每件有「入手价」和「入手日期」</p></td><td><p>没有成本，永远算不出赚没赚</p></td></tr><tr><td><p>有「存放位置」</p></td><td><p>藏品多了一定会找不到，这是刚需</p></td></tr><tr><td><p>有「现估值」</p></td><td><p>允许大概，但要有，否则不知道整体值多少</p></td></tr></tbody></table>

### 4.3 方案不满意怎么改（提示词三，通用句式）

```
方案整体可以，改三处：
1. 藏品库按类别分组，同类里按入手时间排；
2. 图鉴视图用卡片，一张图一件；
3. 把行情、鉴定、交易相关全砍掉。确认后给我更新版方案，还是不要代码。
```

> [!NOTE]
> 📌
> <p><strong>一次最多改三处。</strong>这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。</p>

## 五、第三步：生成第一版（提示词四，这次真写代码）

### 5.1 提示词四：带四条硬约束

<p>方案点头之后，粘贴这段。四条硬约束一条都别删——每一条背后都是踩过的坑：</p>

```
方案确认，开始做第一版。四条硬要求，必须全部满足：
1. 只做成一个单独的 HTML 文件，所有代码都写在这一个文件里，不要拆多个文件，不要安装任何依赖，做完我双击这个文件就能用；
2. 数据全部存在我电脑本地，刷新页面、关掉浏览器再打开，数据都不能丢；
3. 界面全中文，做得干净、字大、好点，我每天要打开好几次，别做成演示 demo 的样子；
4. 每件藏品能贴一张照片，并且列表里直接显示缩略图
做完以后，你自己把整个软件从头到尾完整点一遍，告诉我哪里顺手、哪里会让我困惑。做完告诉我：文件叫什么名字、放在哪个文件夹。
```

### 5.2 四条硬约束分别防什么坑

<table><thead><tr><th><p>约束</p></th><th><p>防的坑</p></th></tr></thead><tbody><tr><td><p>单文件、零依赖</p></td><td><p>不拆文件就没有环境问题，双击就能开</p></td></tr><tr><td><p>数据存本地</p></td><td><p>藏品价值和存放位置，尤其不该上云</p></td></tr><tr><td><p>全中文、卡片式浏览</p></td><td><p>图鉴是拿来看的，不是拿来查的</p></td></tr><tr><td><p>必须有缩略图</p></td><td><p>看图鉴没有图，等于没有图鉴</p></td></tr></tbody></table>

### 5.3 第一版验收清单（5 分钟点完）

<p>WorkBuddy 做完后，去工作目录找到那个 HTML 文件，<strong>双击打开</strong>，然后逐条打勾：</p>

<ol><li>加 3 件藏品，填名称、类别、入手价、位置</li><li>给一件贴照片，列表里能看到缩略图</li><li>首页能看到「藏品总数 + 总投入」</li><li>关掉重开数据不丢</li><li>界面中文，卡片排得整齐</li></ol>

> [!TIP]
> 💡
> <p><strong>第一版只验&quot;通不通&quot;，不验&quot;好不好看&quot;。</strong>丑、慢、布局怪，都留到第七章的迭代环节统一处理。第一版就追求完美，你会陷入无止境的细节，搭不完。</p>

## 六、第四步：把真实数据喂进去（决定它是玩具还是工具）

<p>验收通过别急着庆祝。<strong>这一步最容易被跳过，也是决定工作台生死的一步。</strong></p>

### 6.1 操作

<p>录进去：你最想记的 5 件藏品（连入手价和年份，记不清就写大概）、买重过的那件、你最怕坏的一件（它需要什么保养）。</p>

### 6.2 录完你会遇到两类问题——这是好事

<p><strong>第一类：字段不合手。</strong>比如它要求填「品相等级」（全新/九成新），但你收藏的是钱币，用的是评级；比如它把「系列」设成必填，你的收藏没有系列。</p>

<p><strong>第二类：流程不顺手。</strong>比如加一件藏品要填八个字段，加五件就累；比如照片要点进去才能看，列表里是空白。</p>

<p>拿张便签或者开个备忘录，标题就写&quot;工作台待改清单&quot;。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。</p>

> [!NOTE]
> 🎯
> <p><strong>本章验收：</strong>打开藏品库，能看到你真实的那几件，照片、价格、位置都在。</p>

## 七、第五步：迭代优化（8 条现成提示词，抄就完了）

<p>迭代不靠灵感，靠&quot;用的时候哪里硌手&quot;。第六章攒的&quot;待改清单&quot;就是原料。以下 8 条覆盖这个工作台最常见的问题，直接抄，方括号里的换成你的情况：</p>

<table><thead><tr><th><p>哪里硌手</p></th><th><p>直接抄的提示词</p></th><th><p>改完怎么验</p></th></tr></thead><tbody><tr><td><p>录入太累</p></td><td><p>快速录入：只填名称、类别、入手价三样就能存，其余后补</p></td><td><p>30 秒一件</p></td></tr><tr><td><p>找不到某件</p></td><td><p>加搜索，按名称或类别搜</p></td><td><p>能搜到</p></td></tr><tr><td><p>想看图鉴</p></td><td><p>加「图鉴模式」：卡片流，一张图一件，只显示名称和估值</p></td><td><p>像本册子</p></td></tr><tr><td><p>不知道总共值多少</p></td><td><p>首页显示「共 X 件，总投入 Y，现估值 Z」</p></td><td><p>三个数字</p></td></tr><tr><td><p>忘了保养</p></td><td><p>需要保养的藏品单独标「保养周期」，到期在首页提示</p></td><td><p>能提醒</p></td></tr><tr><td><p>买重了没发现</p></td><td><p>加藏品时如果同名或同系列已存在，提示「你可能已经有一件」</p></td><td><p>能提示</p></td></tr><tr><td><p>想看出手赚没赚</p></td><td><p>出手时自动算差价，单独一页列出所有已出手的</p></td><td><p>能算</p></td></tr><tr><td><p>想分类看</p></td><td><p>按类别筛选，支持多选</p></td><td><p>能筛</p></td></tr></tbody></table>

### 7.1 迭代的三条纪律

<ul><li><strong>一次只提 1~3 条。</strong>一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。</li><li><strong>改完用一遍，再提下一轮。</strong>改动生效后至少真实使用半天，硌手的地方会自己冒出来。</li><li><strong>提示词里带现象，别带结论。</strong>说&quot;我点保存没反应&quot;比说&quot;保存功能坏了，你修一下&quot;效果好——前者是证据，后者是让你俩一起猜。</li></ul>

## 八、第六步：装到桌面（让它看起来像个软件）

<p>现在它还只是个 HTML 文件，打开方式是&quot;找到文件 → 双击 → 浏览器里开一个标签页&quot;。这一章把它变成桌面上真正意义的&quot;软件图标&quot;。</p>

### 8.1 三种方式对比

<table><thead><tr><th><p>方式</p></th><th><p>怎么做</p></th><th><p>适合谁</p></th></tr></thead><tbody><tr><td><p><strong>方式 A：浏览器快捷方式（推荐）</strong></p></td><td><p>用浏览器打开这个 HTML → 浏览器菜单&quot;更多工具 → 创建快捷方式&quot;（Edge 里是&quot;应用 → 将此站点作为应用安装&quot;）→ 勾选&quot;在窗口中打开&quot; → 桌面出现独立图标，双击就是一个没有地址栏的独立窗口</p></td><td><p>所有人。5 分钟搞定，零成本，推荐首选</p></td></tr><tr><td><p><strong>方式 B：发布为在线链接</strong></p></td><td><p>让 WorkBuddy 用&quot;发布为应用&quot;把这个软件发布成一个网址，电脑手机都能打开，数据可以存云端；之后同样创建桌面快捷方式</p></td><td><p>想在手机上也看一眼、或多台电脑之间同步的人</p></td></tr><tr><td><p><strong>方式 C：打包成 exe</strong></p></td><td><p>用打包工具把网页套一层壳变成独立安装包</p></td><td><p>暂时不建议。要装打包环境、体积大、杀毒软件可能误报，折腾半天收益为零</p></td></tr></tbody></table>

<p><strong>推荐方式 A 的理由：</strong>改动即生效（WorkBuddy 每次改完，你重新打开就是新版）、数据在本机、不依赖任何服务。方式 B 等你确定&quot;我要在手机上用&quot;再升级，别一开始就上。</p>

### 8.2 收尾三件小事

<ul><li><strong>换个像样的图标：</strong>右键桌面快捷方式 → 属性 → 更改图标，挑一个顺眼的。别小看这个——桌面颜值决定你愿不愿意每天打开它。</li><li><strong>固定一个浏览器开它：</strong>右键 HTML 文件 → 打开方式 → 选你的浏览器并勾&quot;始终&quot;。数据跟浏览器走，别今天 Edge 明天 Chrome。</li><li><strong>给工作目录留个备份位：</strong>在<code>D:\我的工作台</code>旁边建一个<code>备份</code>文件夹，下一章马上用。</li></ul>

<p>软件搭完只是开始，这一章是它的&quot;日常运转节奏&quot;。就四个动作，加起来每天不到 5 分钟：</p>

## 十、数据备份（5 分钟一劳永逸，必须做）

### 10.1 先知道风险在哪

<p>本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：<strong>清理浏览器缓存、卸载浏览器、重装系统时，数据会没。</strong>所以备份不是可选项。</p>

### 10.2 先补上导出功能（如果你的第一版没有）

```
给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 藏品图鉴备份_20261110.json；2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
```

### 10.3 备份的三条规矩

<ol><li><strong>每次用完固定导出一次</strong>，存进<code>D:\我的工作台\备份</code>。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。</li><li><strong>换电脑、清缓存、重装系统之前，先导出。</strong>记住：清浏览器缓存 = 清空工作台，没有例外。</li><li><strong>恢复方法：</strong>点&quot;导入数据&quot;，选最新的 JSON 文件，确认。数据原样回来。</li></ol>

## 十一、进阶：让 WorkBuddy 继续替你干活

<p>软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：</p>

### 11.1 藏品整理建议

<p>收藏久了，重心会悄悄偏移。</p>

```
这是我的藏品清单（粘贴）：名称、类别、入手价、现估值。请帮我分析：
1. 我收藏的重心在哪一类；
2. 哪些是纯情绪价值、哪些有升值；3. 如果我要精简，建议先处理哪几件。
```

### 11.2 保养方案

<p>潮、光、氧化，是三类藏品的三个天敌。</p>

```
我有一件【材质/类型】的藏品，目前放在【位置】，环境是【湿度/光照情况】。请告诉我它最怕什么、日常怎么保养、多久需要检查一次。说具体做法，别讲原理。
```

### 11.3 出手定价

<p>定价错了，不是少赚就是卖不掉。</p>

```
我要出手一件【藏品】，入手价【X】，现在市场大概【X】。请帮我分析该定什么价、在哪些平台出更合适、要注意什么坑（到手刀、真假争议）。
```

<p><strong>注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。</strong>这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。</p>
