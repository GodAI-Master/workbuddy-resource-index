# WorkBuddy 提示词设计与应用模板

WorkBuddy 提示词设计与应用模板

使用 WorkBuddy 时，任务效果很大程度取决于需求是否清楚、限制是否具体。
同一个功能，有人用出120%的效果，有人用出60%。差距不在工具，在Prompt。
这一篇整理100个职场高频模板，直接复制就能用。每个模板都经过实测，标注了使用场景和效果预期。
一、周报类（4个）
周报结构化输出

我是【岗位】，本周做了【3件事】：1.……2.……3.……。下周计划：【3件事】。请按「本周成果+数据+下周计划」格式帮我整理成一份简洁周报，重点突出我做得好的部分，字数控制在300字以内。
适用：每周五写周报，5分钟出初稿
数据型周报

我是运营，本周核心数据：【拉新200人/转化率15%/活跃度提升8%】。请结合这些数据写一份周报，重点说明数据背后的原因和下周优化方向，用数据讲故事，不要流水账。
适用：有具体数据指标的岗位
项目进展汇报

项目名称：【XXX】，当前进度：【XX%】，本周完成：【事项列表】，遇到的问题：【问题描述】，下周计划：【计划】。请按「进度-成果-问题-计划」格式整理成项目周报，控制在200字内发给领导。
适用：需要定期向领导汇报项目进展
跨部门周报同步

我们部门本周完成了【事项】，对贵部门的影响是【说明】。需要贵部门配合的是【具体需求】，期望完成时间是【时间】。请帮我写一段200字以内的跨部门周报同步文字，语言专业但不高高在上。
适用：需要与其他部门协作配合的工作
二、邮件类（4个）
工作请示邮件

领导好，关于【事项】我有两个方案：A方案【优点/缺点】；B方案【优点/缺点】。我的建议是【选择方案+理由】。请您在百忙中抽空确认，谢谢。
适用：需要领导决策的工作请示
客户跟进邮件

您好，我是【你的名字】，负责【项目/产品】。上次沟通后我们完成了【进展】，目前的状态是【现状】。想跟您确认一下：【需要确认的问题】。期待您的反馈，祝好。
适用：客户关系维护和跟进
会议邀请邮件

您好，邀请您参加【会议名称】，时间：【具体时间】，时长约【XX分钟】，方式：【线下/线上链接】。本次会议议程：1.……2.……3.……，预计需要讨论【需要对方提前准备的内容】。请确认是否参加，谢谢。
适用：组织会议前的邀请发送
方案发送邮件

您好，附件是我们为【项目】准备的方案，主要包含【核心内容概述】。有几个关键点想特别说明：【1-2个重点】。期待您的反馈，如有疑问随时沟通，谢谢。
适用：发送方案、提案后的说明邮件
三、汇报类（3个）
述职报告

我是【岗位】，在岗【X年/X月】。本季度我的核心成果是【3个成果+数据支撑】，遇到的挑战是【挑战描述+解决方案】，下季度目标是【目标】。请帮我整理成一份3分钟的述职报告，重点说成果，简洁不啰嗦。
适用：季度/年度述职
工作复盘

项目/任务：【名称】，最终结果：【结果】，计划 vs 实际：【对比】。做得好的地方：【原因分析】；需要改进的地方：【原因分析+下次做法】。这件事给我的核心启示是：【1句话总结】。
适用：项目结束后的结构化复盘
需求汇报

我需要向【对象：领导/客户/同事】汇报【需求名称】。背景是【背景描述】，我的诉求是【具体诉求】，期望结果是【期望结果】。请帮我用「背景-现状-诉求-期望」结构写一段2分钟的口头汇报稿，语言简洁有说服力。
适用：向上级或客户提需求

四、总结类（4个）
会议纪要整理

以下是会议记录：【粘贴记录内容】。请帮我整理成结构化纪要，包含：会议结论（确定的）、待办事项（负责人+截止时间）、未解决问题（需要继续跟进）、下次会议时间。格式要清晰，便于分享。
适用：会议结束后快速整理纪要
读书/学习笔记

我刚学了【内容主题】，作者/来源是【来源】。核心观点是：【1-2句话概括】。对我最有用的点是：【具体启发】。我可以马上用起来的是：【马上能做的1件事】。请帮我整理成一张知识卡片，包含观点+启发+行动。
适用：学习后快速沉淀
月度总结

我是【岗位】，这个月完成了【主要成果，数据支撑】。对比上个月，进步的地方是【进步】，做得不够好的地方是【不足+原因】。下个月我重点要提升的是【方向】，具体计划是【计划】。请帮我整理成一份月度总结，800字左右，有数据有分析。
适用：月度复盘和总结
项目结项总结

项目：【名称】，时间：【周期】，目标：【目标】，实际结果：【结果】，投入产出：【说明】。请帮我按「项目概述-核心成果-关键动作-经验沉淀-待改进」格式写一份结项总结，重点说经验，为以后做参考。
适用：项目结束后的完整复盘
五、沟通类（3个）
拒绝/婉拒回复

您好，关于【对方的请求】，感谢您的信任。目前我手上有【现有工作说明】，在这个时间段内无法承接【请求内容】。我的建议是【替代方案或推荐人选】。希望有机会下次合作，谢谢理解。
适用：无法接受请求时的专业回复
批评反馈

我想给你一个反馈，关于【具体事件】。我观察到的情况是【描述行为，不评价人】，这对【影响】产生了影响。我希望的是【具体期望】。我相信你可以做好，这只是过程中的一点调整。
适用：需要给同事或下属提意见
感谢信/表扬信

我想感谢【人名】，他是【岗位/角色】。在【具体事件】中，他【具体做了什么】，这件事对我的帮助是【帮助描述】，最终结果是【结果】。他的这种做法让我感受到【感受】。请帮我写一封真诚的感谢信，200字以内。
适用：感谢同事、客户、合作伙伴

六、创意类（2个）
方案头脑风暴

我需要解决【问题/挑战】。背景是【背景描述】，约束条件是【预算/时间/资源限制】。请帮我提供至少5个不同方向的解决方案，每个方案说明：核心思路、预估效果、需要的资源、潜在风险。最后推荐一个最值得尝试的方案。
适用：需要创意方案时
内容选题

我的公众号/账号定位是【定位】，目标读者是【人群】，本周我想写一篇关于【主题】的文章。请帮我提供5个标题选项（每个不同角度），并说明每个标题的切入角度和预期效果。最后推荐一个最值得写的。
适用：内容创作前的选题策划

使用方法：直接复制模板，替换【】内的内容即可。WorkBuddy支持上下文记忆，多轮对话时会越来越贴合你的习惯。
核心心法：好Prompt的公式 = 身份 + 任务 + 格式要求 + 参考信息。按这个结构写，输出质量提升明显。
