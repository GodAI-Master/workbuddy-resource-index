# WorkBuddy 本地学习路线

本页仅指向仓库中的说明文档和配套视频，按操作顺序组织学习内容。

## 路线一：WorkBuddy 入门

1. 阅读 [基础操作](002.md)，熟悉常用功能。
2. 查看 [安装与使用指南](043.md) 和 [桌面端与小程序实操指南](051.md)。
3. 遇到问题时查阅 [常见问题与排错](027.md)。

## 路线二：知识库协作

1. 阅读 [ima 知识库实战指南](008.md)。
2. 按 [WorkBuddy 与 ima 知识库协同指南](009.md) 了解连接流程。
3. 参考 [知识库整理流程](037.md) 和 [自动整理知识库](039.md) 设计自己的步骤。

## 路线三：任务与工作流

1. 从 [应用场景](010.md) 或 [实战案例](014.md) 中选择一个小任务。
2. 按 [提问与任务描述指南](049.md) 写清目标、材料、限制和输出格式。
3. 查看 [版本说明](028.md)，核对不同版本的界面差异。
