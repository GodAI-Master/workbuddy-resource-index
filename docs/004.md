P01远程助理

WorkBuddy｜远程办公助理搭建：随时随地远控 WorkBuddy，手机遥控电脑办公
课程提示词示例：

我现在不在电脑前，请你在电脑上帮我做一件事。

文件在：【这里换成助理工作目录下的文件夹名，比如"报价与图纸"】
用哪几份：【这里换成准确的文件名，比如"2026-10 旧报价.xlsx、柜子图纸.pdf、客户交期.md"】
要什么：【这里换成你要的东西，比如"给张先生出一份客户版报价单"】
按这个规格：【这里换成规格，比如"本次 120 平，柜型、单价和加项沿用指定旧报价"】
什么时候要：【这里换成时间，比如"今晚 10 点前"】

规则：
- 只读上面指定的文件，结果另存到"本次输出"子文件夹；原文件不要改名、不要覆盖。
- 本次面积以"按这个规格"里写的为准；柜型、单价、加项和交期按指定材料里的内容。
- 需要重新计算总价时，列出计算公式和每个数的来源；不要估算，不要四舍五入，不要替我凑整。
- 指定材料里没有、也不能按上面的规则计算的信息，写"待定"，不要编一个填上。
- 拿不准的地方先问我一句，不要自己决定。
- 做完告诉我三件事：文件存在哪、你改了哪几处、
  有哪一处需要我自己核。
P02-文件解析

WorkBuddy｜文件智能整理：多格式文档自动识别、提取、整理关键信息
课程提示词示例：

请把这个文件夹里的文件逐份读一遍，整理成三份东西。
这批文件是【这里换成是什么，比如"我去年做的一个全屋软装项目的报价和方案"】，
我要回答的问题是【这里换成你的问题，比如"去年最后报给客户的是多少钱"】。

请按下面做：

1.《文件清单.csv》，一行一个文件，六列：
   文件名 / 类型 / 日期 / 能不能读 / 关键金额 / 是不是最新版。
   "能不能读"这一列，读不出文字的写"读不到"，不要跳过不写。

2.《关键信息.csv》，只放与本次问题有关、能回原件核对的那几份，
   一行一个金额、一个日期，另外注明来自哪个文件。

3.《待确认.md》，写三类：
   我读不到的、看起来是同一份的两个版本、两份文件里对不上的数字。

规则：
- 只读，不改名、不移动、不删除任何一个原文件。
- 读不出文字的（拍糊了、反光、歪了），写"读不到"并说一句为什么，
  不要猜、不要按上下文补。
- 有两份内容几乎一样的，指出来是哪两份、差在哪里，
  不要自己选一个当最新版。
- 两份文件里的数字不一致，两个都留下，不要替我判断哪个对。
- 不要写建议，不要写总结，不要替我做决定。

做完告诉我：一共读了几份、有几份读不到、哪三份最需要我自己看一遍。
P03-录音纪要

WorkBuddy｜会议录音一键分析：一场对话自动转写梳理，把交谈变成可复用资产
课程提示词示例：

请把通话录音整理成三份文件。
背景：我是【这里换成你的身份】，对方是【这里换成对方】，谈的是【这里换成事由】。

1.《通话纪要.md》：按话题分段，每段有标题、不超过5行；闲聊另放“其他”。
2.《承诺与待办.csv》：谁承诺、承诺什么、原话、录音时间点、截止时间、下一步、状态，一条一行；状态分已承诺、已确认、待确认，没说日期写“未定”。
3.《下次跟进卡.md》：仅三行——谈到哪、还犹豫什么、下次先问什么；没依据写待确认，开口句只作供我选择的问题。

规则：
- 数字照抄，不换算、不凑整；改口前后均保留，分清说话者、用途和最终确认；预算、别家报价、全包与半包不混淆。
- “再考虑”“回去商量”保留原意，不写成同意；工期与账期分别判断是否确认。
- 听不清不补全，写“未听清，需回听”并填实际录音时间点；能听清时也给关键记录的时间点。
- 不替对方做决定，不编日期或结论，不加“总结与展望”。

做完告诉我文件存在哪、最需回听的三处；不足三处据实说明。

P05-数据分析

WorkBuddy｜AI 数据分析实战：自动清洗表格生成图表，快速提炼业务洞察
课程提示词示例：

用我交进来的这张流水表，回答一个问题：这些月份里，哪个月是白干的。

列我说明了：收入看【收入列名】，成本看【成本列名、平台扣点列名、快递费列名】。
毛利 = 收入 - 成本 - 平台扣点 - 快递费。

按这个顺序做：

1. 出《分析结果.xlsx》，一个工作簿含两个工作表：
   - "清洗明细"：同一个人的几种写法先列给我确认，再合并；加一列"原写法"。同一客户同月的零散记录按规则合并，空着的格写"缺"，不要填 0。
   - "月度汇总"：每月一行，列收入、三类成本和毛利。完整月份按公式计算；缺成本的月份，毛利写"待补齐"。最后加合计行，收入可合计，毛利仍有缺口就写"待补齐"。

2. 再出三张图，只要三张：
   - 月度毛利柱状图：每个月一根柱；完整月份负数用另一种颜色，缺成本月标"待补齐"。
   - 成本结构饼图：只使用有依据的已知成本，并注明缺口。
   - 客户贡献前 10：按毛利排；受缺失成本影响时标"含缺失，待核"。

3. 最后出《结论.md》，只写三句：
   哪个月白干、为什么、先改哪个数；缺数据时写明限制。

规则：
- 明细、月度汇总和图使用同一套口径，能回原表核对。
- 合并客户写法不得改变全表收入及已知成本总账。
- 不写与这三句无关的建议或总结，不另做别的文件。

2. 再出三份：Word、Excel、PPT。数字全部取自底稿，不许自己算、

- 两处"待定"，三份都写"待定"，不要替我定。
- 别写建议和总结、别改版式，先把三处数对齐。

P09-定时任务

WorkBuddy｜定时自动化任务执行：周期任务一次配置，到点自动执行、推送结果
课程提示词示例：

每次执行时，重新读取【材料目录】中的上周流水、客户跟进、本周待办和周汇总模板，不沿用上次对话的附件或结果。
日期口径：【课堂演示固定为2026-11-02；日常使用改为按每次实际执行日期，以周一到周日划分自然周】。
先列出本次执行日期、上周和本周的起止日期，以及实际读取的文件名。材料日期不匹配时说明问题，不把旧材料当作本期数据。
按模板生成一页汇总：
1. 收入：有合计就引用并核对；只有明细就求和并列出计算依据。
2. 跟进：仅列下次跟进日期在本周内的人，日期未定者另列待确认。
3. 待办：保留原意；不完整的条目注明待补充。
4. 异常：区分文件未读到、字段缺失和日期不匹配，不猜测。
5. 结论：只依据本页已核实的信息。
保存到【结果目录】，文件名包含本次执行日期；同日重跑另存一份，不覆盖前次结果。
无法生成完整汇总时，仍保存问题说明。
