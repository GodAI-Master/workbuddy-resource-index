一、这个工作台解决什么问题
1.1 先看看你有没有这三个瞬间
瞬间一：一首曲子练了两个月，自己也不知道到底算不算会了，每次都是「差不多吧」。
瞬间二：买琴时说要坚持，练了三周就断。回头看，完全不知道是怎么断的。
瞬间三：弦该换了、琴该保养了，全靠某天突然觉得声音闷。
练琴最大的敌人不是难，是看不见进步。每天练半小时，一个月后你还是觉得「好像没什么变化」。软件的价值是把这个变化变成数字和进度。

偏离核心

为什么是"桌面软件"而不是表格？练琴的进步是非线性的——你会有一段很长时间「感觉没变」，然后突然跨一个台阶。这段平台期最容易放弃。软件的作用是把「这个月练了 18 天、这首从 3 分到 4 分」摆出来，让你知道自己在动。
二、开工前的准备（10 分钟，全在你这边）
正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。
2.1 准备清单
WorkBuddy 客户端装好、登录。没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。
在电脑上建一个空文件夹。比如 D:\我的工作台\乐器练习。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。
挑一个你顺手的浏览器。Edge 或 Chrome 都行。定了就一直用它开这个软件，因为数据跟着浏览器走（原因见第十章）。
准备几条真实数据（纸面想好就行，不用打字）：你在练的 2-3 首曲子；你每天大概练多久；你手上这件乐器什么时候买的。

唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。别用"项目A、测试数据"这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。
2.2 全程你会用到的角色分工
整套流程就两个角色，别搞混：
WorkBuddy：施工队。所有代码、界面、功能都是它写，你一行代码都不用碰。
你：甲方 + 验收员。你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。
这个分工意味着：SOP 里所有"做"的动作都是复制粘贴提示词，所有"判断"的动作是你亲手点一遍。哪一步跳过了"自己点一遍"，后面必然返工。
三、第一步：跟 WorkBuddy 把话说清楚（提示词一）
3.1 开工操作
打开 WorkBuddy，点新建任务，模式选 Agent 模式（它能自己动手建文件，别选纯问答模式）。
把工作目录设成第二章建好的那个文件夹（比如 D:\我的工作台\乐器练习）。设错也不致命，就是文件会落别处，你得多翻一下。
在输入框粘贴下面这段提示词，回车。
3.2 提示词一：需求确认版（先别让它写代码）

我要做一个"乐器管理与曲目管理工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。
需求背景：我在学乐器（钢琴/吉他/尤克里里）。痛点是：练了很久感觉没进步、不知道一首曲子算不算会了、经常断更、乐器保养总忘。
3.3 为什么第一步是"复述"而不是"开做"
你直接说"帮我做个乐器管理与曲目管理工作台"，它会按它想象中的样子给你一个通用的东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。
先让它复述，等于把"需求的解释权"拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。
3.4 它大概会问你什么（提前有数，答得就快）
"学什么乐器？"——具体乐器，可以多件
"曲目记到哪一级？"——熟练度 1-5 级就够
"要不要记练习时长？"——要，但要简单
"要不要记难点？"——要，这是最有用的
"要不要管保养？"——要，换弦、调律、清洁
这里出现第一个"需要你输入"的点：上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。
四、第二步：让它先出方案，还是别写代码（提示词二）
4.1 提示词二：要一份方案

六、第四步：把真实数据喂进去（决定它是玩具还是工具）
验收通过别急着庆祝。这一步最容易被跳过，也是决定工作台生死的一步。
6.1 操作
录进去：你在练的真实 2-3 首（连熟练度和难点，别自欺，难点写实话）、你每天大概练多久、这件乐器什么时候买的、上次换弦或调律是什么时候。
6.2 录完你会遇到两类问题——这是好事
第一类：字段不合手。比如它要求填「曲谱版本」「调性」，你根本不懂；比如它把「练习速度 BPM」设成必填，你还没到那一步。
第二类：流程不顺手。比如开始练习要点进去、选曲目、点开始，三步；你想的是一键开始，结束再补。比如熟练度藏在详情里，改起来麻烦。
拿张便签或者开个备忘录，标题就写"工作台待改清单"。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。

本章验收：打开曲目页，看到你真在练的那几首，熟练度和难点都写着你自己的话。

7.1 迭代的三条纪律
一次只提 1~3 条。一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。
改完用一遍，再提下一轮。改动生效后至少真实使用半天，硌手的地方会自己冒出来。
提示词里带现象，别带结论。说"我点保存没反应"比说"保存功能坏了，你修一下"效果好——前者是证据，后者是让你俩一起猜。

十、数据备份（5 分钟一劳永逸，必须做）
10.1 先知道风险在哪
本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：清理浏览器缓存、卸载浏览器、重装系统时，数据会没。所以备份不是可选项。
10.2 先补上导出功能（如果你的第一版没有）

给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 练琴记录备份_20261110.json；
2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
10.3 备份的三条规矩
每次用完固定导出一次，存进 D:\我的工作台\备份。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。
换电脑、清缓存、重装系统之前，先导出。记住：清浏览器缓存 = 清空工作台，没有例外。
恢复方法：点"导入数据"，选最新的 JSON 文件，确认。数据原样回来。
十一、进阶：让 WorkBuddy 继续替你干活
软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：
11.1 练习计划
每天练什么，靠感觉排一定偏科。

我在学【乐器】，目前水平【入门/中级】，在练这几首（粘贴，含熟练度和难点），每天能练【X】分钟。请帮我排一周的练习计划：每天练哪首、练哪几小节、各花多久。要留出热身和休息时间。
11.2 难点拆解
卡住的地方，通常是方法问题不是时间问题。

这首曲子的这一段我一直弹不好（描述难点：比如「第 12 小节换把总是慢半拍」）。请告诉我：这个难点通常是什么原因造成的、有什么专门的练习方法、大概要练多久才能过。
11.3 断更恢复
断更后最难的不是技术，是重新开始的决心。

我已经停练【X】周了，之前练到【粘贴曲目和熟练度】。请帮我设计一个恢复计划：前三天练什么（不要一上来就练难的）、怎么避免再次断更、给自己的最低标准是什么（比如每天 5 分钟也算）。
注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。
