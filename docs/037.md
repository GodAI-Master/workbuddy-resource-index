# WorkBuddy 与 ima 知识库协作指南

这份指南说明如何让 WorkBuddy 协助检索文章、整理资料并写入 ima 知识库。具体功能和权限会随产品版本变化，操作前应核对当前界面与账号权限。

## 工具分工

- **ima 知识库**：集中保存文章、PDF 和其他资料，并基于已收录内容进行检索与问答。
- **WorkBuddy**：执行检索、文件处理和自动化任务，可通过已授权的技能调用知识库功能。

## 一、安装所需技能

在 WorkBuddy 的技能商店搜索并安装 ima 知识库技能，以及用于检索公众号文章的搜索技能。安装前检查技能来源、权限范围和维护情况。

## 二、准备知识库位置

在 ima 中创建一个专用知识库或文件夹，用于存放本流程检索到的文章。先确认目标位置和写入权限，再将 ima 相关技能添加到 WorkBuddy 当前任务。

## 三、执行文章检索与导入

明确主题、时间范围、来源类型、筛选条件和目标文件夹。可参考以下任务描述：

> 检索指定主题的公开文章，列出标题、日期、来源和摘要；只保留与主题直接相关的内容。先展示候选清单供我检查，确认后再写入指定知识库，并记录导入结果。

如流程需要 API 凭证，请使用平台当前提供的安全授权方式。不要把 AppSecret、API Key、访问令牌或个人账号资料粘贴到公开对话、文档或代码仓库中。

## 四、设置周期任务

在 WorkBuddy 自动化页面创建任务，设置检索主题、来源范围、执行频率和结果保存位置。首次运行先手动检查任务计划；后续定期复核检索结果，避免重复、过期或不相关内容进入知识库。

## 使用注意

- 核对来源和发布日期，不要把未经确认的内容当作事实。
- 尊重文章及图片的版权和平台规则，只导入有权使用的内容。
- 自动写入前检查目标位置和访问权限；重要内容保留人工审核。
- 定期归档或删除过期资料，避免知识库长期堆积。
