# 07 宝妈孩子学习与成长管理工作台 · 完整搭建 SOP

## WorkBuddy 工作台全套资料 · 第 07 篇

<p><strong>本篇是「宝妈孩子学习与成长管理工作台」的完整搭建 SOP。</strong>一句话：把「孩子今天学了什么、最近对什么感兴趣、下个月该补什么」从模糊印象，变成一份能翻回去看的成长档案。</p>

## 一、这个工作台解决什么问题

### 1.1 先看看你有没有这三个瞬间

<p><strong>瞬间一：</strong>老师说孩子拼音弱，你回家想辅导，但不知道具体弱在哪，只能让他把整本书再读一遍。孩子哭，你也烦。</p>

<p><strong>瞬间二：</strong>孩子突然对恐龙着迷，那阵子天天问，你随口答了几天。半年后他又问，你完全不记得当时聊到哪，那个机会就过去了。</p>

<p><strong>瞬间三：</strong>想记录成长，照片存了八千张，但「第一次自己系鞋带是哪天」完全查不到。</p>

<p>这个工作台不负责教孩子，它负责<strong>替你记住他长大的过程</strong>，并让「该补什么」这件事有据可依。</p>

### 1.2 成品长什么样：一个桌面上的小软件

<p>先说清楚最终形态，免得你搭到一半发现跟想的不一样：</p>

<p><strong>它会是你电脑桌面上的一个图标，双击就打开一个独立窗口，长得像个软件。</strong>不用联网也能用，所有数据都存在你自己电脑里，不需要注册任何账号，不需要装任何其他东西。</p>

<p>打开之后，它有四个页面，各管一件事：</p>

<table><thead><tr><th><p>页面</p></th><th><p>管什么</p></th><th><p>你什么时候打开它</p></th></tr></thead><tbody><tr><td><p>今天</p></td><td><p>今天要做的三件小事（读 10 分钟 / 一道错题 / 一个提问）</p></td><td><p>每天放学后</p></td></tr><tr><td><p>学习档案</p></td><td><p>各科薄弱点 + 老师反馈 + 每次小测记录</p></td><td><p>每周一次</p></td></tr><tr><td><p>成长记录</p></td><td><p>里程碑、第一次、说过的话、兴趣变化</p></td><td><p>想到就记</p></td></tr><tr><td><p>兴趣地图</p></td><td><p>最近在迷什么，持续多久，延伸出了什么</p></td><td><p>每月看一次</p></td></tr></tbody></table>

### 1.3 明确不做什么（这个比做什么更重要）

<p>第一版<strong>故意</strong>砍掉这些功能，别自己加戏：</p>

<table><thead><tr><th><p>不做的事</p></th><th><p>为什么不做</p></th></tr></thead><tbody><tr><td><p>排课表、作业批改</p></td><td><p>那是学校和自己辅导的事，软件只管记录</p></td></tr><tr><td><p>儿童内容库、绘本推荐</p></td><td><p>会变成内容平台，偏离核心</p></td></tr><tr><td><p>家长社交、经验分享</p></td><td><p>一旦引入别人家孩子，焦虑就来了</p></td></tr><tr><td><p>成绩排名、横向对比</p></td><td><p>坚决不做。这是给家长看的档案，不是给孩子排名的</p></td></tr></tbody></table>

> [!TIP]
> 💡
> <p><strong>为什么是&quot;桌面软件&quot;而不是表格？</strong>孩子成长最快的那几年，恰恰是家长最忙的几年。你会记得「他很爱恐龙」，但记不住「他从三岁半开始迷恐龙，迷了七个月，因为这个认识了四十个字」。软件的价值是把这个过程留住——不是为了发朋友圈，是为了半年后你还接得上他的话。</p>

## 二、开工前的准备（10 分钟，全在你这边）

<p>正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。</p>

### 2.1 准备清单

<ol><li><strong>WorkBuddy 客户端装好、登录。</strong>没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。</li><li><strong>在电脑上建一个空文件夹。</strong>比如<code>D:\我的工作台\孩子成长</code>。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。</li><li><strong>挑一个你顺手的浏览器。</strong>Edge 或 Chrome 都行。<strong>定了就一直用它开这个软件</strong>，因为数据跟着浏览器走（原因见第十章）。</li><li><strong>准备几条真实数据</strong>（纸面想好就行，不用打字）：孩子现在最薄弱的 1-2 个点；最近一次老师反馈的原话；孩子最近在迷什么。</li></ol>

> [!TIP]
> 💡
> <p><strong>唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。</strong>别用&quot;项目A、测试数据&quot;这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。</p>

### 2.2 全程你会用到的角色分工

<p>整套流程就两个角色，别搞混：</p>

<ul><li><strong>WorkBuddy：施工队。</strong>所有代码、界面、功能都是它写，你一行代码都不用碰。</li><li><strong>你：甲方 + 验收员。</strong>你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。</li></ul>

<p>这个分工意味着：<strong>SOP 里所有&quot;做&quot;的动作都是复制粘贴提示词，所有&quot;判断&quot;的动作是你亲手点一遍。</strong>哪一步跳过了&quot;自己点一遍&quot;，后面必然返工。</p>

## 三、第一步：跟 WorkBuddy 把话说清楚（提示词一）

### 3.1 开工操作

<ol><li>打开 WorkBuddy，点<strong>新建任务</strong>，模式选<strong>Agent 模式</strong>（它能自己动手建文件，别选纯问答模式）。</li><li>把<strong>工作目录</strong>设成第二章建好的那个文件夹（比如<code>D:\我的工作台\孩子成长</code>）。设错也不致命，就是文件会落别处，你得多翻一下。</li><li>在输入框粘贴下面这段提示词，回车。</li></ol>

### 3.2 提示词一：需求确认版（先别让它写代码）

```
我要做一个"宝妈孩子学习与成长管理工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。需求背景：我是家长，孩子在上小学。痛点是：老师说孩子哪里弱，我不知道具体弱在哪；孩子对什么感兴趣，过一阵就忘了；想记录成长，照片一堆但查不到事。
```

### 3.3 为什么第一步是&quot;复述&quot;而不是&quot;开做&quot;

<p>你直接说&quot;帮我做个宝妈孩子学习与成长管理工作台&quot;，它会按它想象中的样子给你一个<strong>通用的</strong>东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。</p>

<p>先让它复述，等于把&quot;需求的解释权&quot;拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。</p>

### 3.4 它大概会问你什么（提前有数，答得就快）

<ul><li>&quot;孩子几年级？&quot;——具体年级，影响内容深度</li><li>&quot;要记几科？&quot;——语文数学英语，三科够</li><li>&quot;成长记录要写多细？&quot;——一句话就够，不用成篇</li><li>&quot;要不要提醒？&quot;——打开能看到「这周还没记录」就够</li><li>&quot;数据给谁看？&quot;——主要自己看，偶尔给老师看</li></ul>

<p><strong>这里出现第一个&quot;需要你输入&quot;的点：</strong>上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。</p>

## 四、第二步：让它先出方案，还是别写代码（提示词二）

### 4.1 提示词二：要一份方案

<p>需求确认完，先别放它写代码。继续粘贴：</p>

```
需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一条记录"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。方案用中文写，控制在 500 字以内，不要贴代码。
```

### 4.2 方案怎么验收：只看三样

<p>500 字方案一分钟看完，重点盯三处：</p>

<table><thead><tr><th><p>看什么</p></th><th><p>合格标准</p></th></tr></thead><tbody><tr><td><p>薄弱点要能标到具体知识点</p></td><td><p>不能只写「数学弱」，要能写到「两位数进位加法」</p></td></tr><tr><td><p>成长记录必须有日期</p></td><td><p>没有日期，半年后翻就是一锅粥</p></td></tr><tr><td><p>有兴趣追踪</p></td><td><p>一个兴趣要能看到「从什么时候开始、持续多久」</p></td></tr></tbody></table>

### 4.3 方案不满意怎么改（提示词三，通用句式）

```
方案整体可以，改三处：
1. 薄弱点改成三级：科目、章节、具体知识点；
2. 成长记录默认按时间倒序，最新的在最上面；
3. 把任何排名、对比、评分功能全砍掉。确认后给我更新版方案，还是不要代码。
```

> [!NOTE]
> 📌
> <p><strong>一次最多改三处。</strong>这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。</p>

## 五、第三步：生成第一版（提示词四，这次真写代码）

### 5.1 提示词四：带四条硬约束

<p>方案点头之后，粘贴这段。四条硬约束一条都别删——每一条背后都是踩过的坑：</p>

```
方案确认，开始做第一版。四条硬要求，必须全部满足：
1. 只做成一个单独的 HTML 文件，所有代码都写在这一个文件里，不要拆多个文件，不要安装任何依赖，做完我双击这个文件就能用；
2. 数据全部存在我电脑本地，刷新页面、关掉浏览器再打开，数据都不能丢；
3. 界面全中文，做得干净、字大、好点，我每天要打开好几次，别做成演示 demo 的样子；
4. 成长记录要能只写一句话就保存，不要逼我写完整的日记
做完以后，你自己把整个软件从头到尾完整点一遍，告诉我哪里顺手、哪里会让我困惑。做完告诉我：文件叫什么名字、放在哪个文件夹。
```

### 5.2 四条硬约束分别防什么坑

<table><thead><tr><th><p>约束</p></th><th><p>防的坑</p></th></tr></thead><tbody><tr><td><p>单文件、零依赖</p></td><td><p>不拆文件就没有环境问题，双击就能开</p></td></tr><tr><td><p>数据存本地</p></td><td><p>孩子的成长记录，更不该上云</p></td></tr><tr><td><p>全中文、字够大</p></td><td><p>这个软件可能要跟孩子一起看</p></td></tr><tr><td><p>一句话就能记</p></td><td><p>要写完整日记，你一定坚持不了三天</p></td></tr></tbody></table>

### 5.3 第一版验收清单（5 分钟点完）

<p>WorkBuddy 做完后，去工作目录找到那个 HTML 文件，<strong>双击打开</strong>，然后逐条打勾：</p>

<ol><li>建 3 个科目，各加 2 个薄弱点，能写到具体知识点</li><li>记一条成长记录，只写一句话，能存</li><li>兴趣地图能显示「恐龙，从 3 月开始，持续 2 个月」</li><li>关掉重开数据不丢</li><li>界面字够大，能跟孩子一起看</li></ol>

> [!TIP]
> 💡
> <p><strong>第一版只验&quot;通不通&quot;，不验&quot;好不好看&quot;。</strong>丑、慢、布局怪，都留到第七章的迭代环节统一处理。第一版就追求完美，你会陷入无止境的细节，搭不完。</p>

## 六、第四步：把真实数据喂进去（决定它是玩具还是工具）

<p>验收通过别急着庆祝。<strong>这一步最容易被跳过，也是决定工作台生死的一步。</strong></p>

### 6.1 操作

<p>录进去：孩子现在真实的薄弱点（写到具体知识点）、最近老师说的原话、孩子最近在迷的东西。别写「表现良好」这种话，写具体的。</p>

### 6.2 录完你会遇到两类问题——这是好事

<p><strong>第一类：字段不合手。</strong>比如它把「成绩」设成必填，可你不想给孩子打分；比如它要求成长记录填「类别」，可你只想随便记一句。</p>

<p><strong>第二类：流程不顺手。</strong>比如记一条成长记录要先选孩子（明明只有一个孩子），多一步；比如薄弱点藏在三层菜单里，找半天。</p>

<p>拿张便签或者开个备忘录，标题就写&quot;工作台待改清单&quot;。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。</p>

> [!NOTE]
> 🎯
> <p><strong>本章验收：</strong>打开软件，能看到孩子真实的薄弱点，而且你能一眼说出「哦对，他这里确实弱」。</p>

## 七、第五步：迭代优化（8 条现成提示词，抄就完了）

<p>迭代不靠灵感，靠&quot;用的时候哪里硌手&quot;。第六章攒的&quot;待改清单&quot;就是原料。以下 8 条覆盖这个工作台最常见的问题，直接抄，方括号里的换成你的情况：</p>

<table><thead><tr><th><p>哪里硌手</p></th><th><p>直接抄的提示词</p></th><th><p>改完怎么验</p></th></tr></thead><tbody><tr><td><p>记录太麻烦</p></td><td><p>首页放一个大输入框，写一句话回车就存成成长记录，自动带今天日期</p></td><td><p>一句话 3 秒</p></td></tr><tr><td><p>找不到旧记录</p></td><td><p>加搜索，按关键词搜成长记录内容</p></td><td><p>搜「恐龙」能搜到</p></td></tr><tr><td><p>不知道这周该补啥</p></td><td><p>首页显示本周聚焦的 1 个薄弱点，其余折叠</p></td><td><p>只有一个重点</p></td></tr><tr><td><p>想看时间线</p></td><td><p>成长记录加时间线视图，按月分组</p></td><td><p>能按月看</p></td></tr><tr><td><p>兴趣断了没发现</p></td><td><p>兴趣地图里超过 30 天没记录的标灰，提示「要不要问问他还喜欢吗」</p></td><td><p>能提醒</p></td></tr><tr><td><p>想给老师看</p></td><td><p>加「导出给老师」按钮，生成一段可复制的近况总结</p></td><td><p>能复制</p></td></tr><tr><td><p>字太小</p></td><td><p>整体字号加大一档，行距放宽</p></td><td><p>能一起看</p></td></tr><tr><td><p>想存照片</p></td><td><p>每条成长记录能贴一张本地图片</p></td><td><p>能贴图</p></td></tr></tbody></table>

### 7.1 迭代的三条纪律

<ul><li><strong>一次只提 1~3 条。</strong>一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。</li><li><strong>改完用一遍，再提下一轮。</strong>改动生效后至少真实使用半天，硌手的地方会自己冒出来。</li><li><strong>提示词里带现象，别带结论。</strong>说&quot;我点保存没反应&quot;比说&quot;保存功能坏了，你修一下&quot;效果好——前者是证据，后者是让你俩一起猜。</li></ul>

## 八、第六步：装到桌面（让它看起来像个软件）

<p>现在它还只是个 HTML 文件，打开方式是&quot;找到文件 → 双击 → 浏览器里开一个标签页&quot;。这一章把它变成桌面上真正意义的&quot;软件图标&quot;。</p>

### 8.1 三种方式对比

<table><thead><tr><th><p>方式</p></th><th><p>怎么做</p></th><th><p>适合谁</p></th></tr></thead><tbody><tr><td><p><strong>方式 A：浏览器快捷方式（推荐）</strong></p></td><td><p>用浏览器打开这个 HTML → 浏览器菜单&quot;更多工具 → 创建快捷方式&quot;（Edge 里是&quot;应用 → 将此站点作为应用安装&quot;）→ 勾选&quot;在窗口中打开&quot; → 桌面出现独立图标，双击就是一个没有地址栏的独立窗口</p></td><td><p>所有人。5 分钟搞定，零成本，推荐首选</p></td></tr><tr><td><p><strong>方式 B：发布为在线链接</strong></p></td><td><p>让 WorkBuddy 用&quot;发布为应用&quot;把这个软件发布成一个网址，电脑手机都能打开，数据可以存云端；之后同样创建桌面快捷方式</p></td><td><p>想在手机上也看一眼、或多台电脑之间同步的人</p></td></tr><tr><td><p><strong>方式 C：打包成 exe</strong></p></td><td><p>用打包工具把网页套一层壳变成独立安装包</p></td><td><p>暂时不建议。要装打包环境、体积大、杀毒软件可能误报，折腾半天收益为零</p></td></tr></tbody></table>

<p><strong>推荐方式 A 的理由：</strong>改动即生效（WorkBuddy 每次改完，你重新打开就是新版）、数据在本机、不依赖任何服务。方式 B 等你确定&quot;我要在手机上用&quot;再升级，别一开始就上。</p>

### 8.2 收尾三件小事

<ul><li><strong>换个像样的图标：</strong>右键桌面快捷方式 → 属性 → 更改图标，挑一个顺眼的。别小看这个——桌面颜值决定你愿不愿意每天打开它。</li><li><strong>固定一个浏览器开它：</strong>右键 HTML 文件 → 打开方式 → 选你的浏览器并勾&quot;始终&quot;。数据跟浏览器走，别今天 Edge 明天 Chrome。</li><li><strong>给工作目录留个备份位：</strong>在<code>D:\我的工作台</code>旁边建一个<code>备份</code>文件夹，下一章马上用。</li></ul>

## 十、数据备份（5 分钟一劳永逸，必须做）

### 10.1 先知道风险在哪

<p>本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：<strong>清理浏览器缓存、卸载浏览器、重装系统时，数据会没。</strong>所以备份不是可选项。</p>

### 10.2 先补上导出功能（如果你的第一版没有）

```
给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 成长档案备份_20261110.json；2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
```

### 10.3 备份的三条规矩

<ol><li><strong>每次用完固定导出一次</strong>，存进<code>D:\我的工作台\备份</code>。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。</li><li><strong>换电脑、清缓存、重装系统之前，先导出。</strong>记住：清浏览器缓存 = 清空工作台，没有例外。</li><li><strong>恢复方法：</strong>点&quot;导入数据&quot;，选最新的 JSON 文件，确认。数据原样回来。</li></ol>

## 十一、进阶：让 WorkBuddy 继续替你干活

<p>软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：</p>

### 11.1 顺着兴趣设计活动

<p>孩子的兴趣是最便宜的教育入口，但得有人帮你翻译成具体的事。</p>

```
我孩子今年 X 岁，最近半年一直在迷【恐龙】。这是他这半年的成长记录（粘贴）。请帮我：
1. 分析他的兴趣点具体在哪（是恐龙本身，还是分类，还是故事）；
2. 顺着这个兴趣，给我 5 个能延伸出去的方向（阅读、动手、数学都可以）；3. 每个方向给一个这周就能做的小活动。
```

### 11.2 薄弱点辅导方案

<p>「多练练」这种建议等于没说。</p>

```
我孩子三年级，数学薄弱点在【两位数进位加法】。请给我一个两周的辅导方案，每天不超过 15 分钟，要有具体题目示例，最后告诉我怎么判断他是不是真的掌握了。
```

### 11.3 老师沟通稿

<p>跟老师说话，说轻了不像回事，说重了像挑刺。</p>

```
这是我孩子最近的情况记录（粘贴）。我要跟老师沟通一次，请帮我写一段话：先说清楚我在家观察到什么，再问三个具体问题。语气要谦虚但不卑微。
```

<p><strong>注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。</strong>这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。</p>
