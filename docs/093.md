WorkBuddy 工作台全套资料 · 第 07 篇
本篇是「宝妈孩子学习与成长管理工作台」的完整搭建 SOP。一句话：把「孩子今天学了什么、最近对什么感兴趣、下个月该补什么」从模糊印象，变成一份能翻回去看的成长档案。
一、这个工作台解决什么问题
1.1 先看看你有没有这三个瞬间
瞬间一：老师说孩子拼音弱，你回家想辅导，但不知道具体弱在哪，只能让他把整本书再读一遍。孩子哭，你也烦。
瞬间二：孩子突然对恐龙着迷，那阵子天天问，你随口答了几天。半年后他又问，你完全不记得当时聊到哪，那个机会就过去了。
瞬间三：想记录成长，照片存了八千张，但「第一次自己系鞋带是哪天」完全查不到。
这个工作台不负责教孩子，它负责替你记住他长大的过程，并让「该补什么」这件事有据可依。

为什么是"桌面软件"而不是表格？孩子成长最快的那几年，恰恰是家长最忙的几年。你会记得「他很爱恐龙」，但记不住「他从三岁半开始迷恐龙，迷了七个月，因为这个认识了四十个字」。软件的价值是把这个过程留住——不是为了发朋友圈，是为了半年后你还接得上他的话。
二、开工前的准备（10 分钟，全在你这边）
正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。
2.1 准备清单
WorkBuddy 客户端装好、登录。没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。
在电脑上建一个空文件夹。比如 D:\我的工作台\孩子成长。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。
挑一个你顺手的浏览器。Edge 或 Chrome 都行。定了就一直用它开这个软件，因为数据跟着浏览器走（原因见第十章）。
准备几条真实数据（纸面想好就行，不用打字）：孩子现在最薄弱的 1-2 个点；最近一次老师反馈的原话；孩子最近在迷什么。

唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。别用"项目A、测试数据"这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。
2.2 全程你会用到的角色分工
整套流程就两个角色，别搞混：
WorkBuddy：施工队。所有代码、界面、功能都是它写，你一行代码都不用碰。
你：甲方 + 验收员。你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。
这个分工意味着：SOP 里所有"做"的动作都是复制粘贴提示词，所有"判断"的动作是你亲手点一遍。哪一步跳过了"自己点一遍"，后面必然返工。
三、第一步：跟 WorkBuddy 把话说清楚（提示词一）
3.1 开工操作
打开 WorkBuddy，点新建任务，模式选 Agent 模式（它能自己动手建文件，别选纯问答模式）。
把工作目录设成第二章建好的那个文件夹（比如 D:\我的工作台\孩子成长）。设错也不致命，就是文件会落别处，你得多翻一下。
在输入框粘贴下面这段提示词，回车。
3.2 提示词一：需求确认版（先别让它写代码）

我要做一个"宝妈孩子学习与成长管理工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。
需求背景：我是家长，孩子在上小学。痛点是：老师说孩子哪里弱，我不知道具体弱在哪；孩子对什么感兴趣，过一阵就忘了；想记录成长，照片一堆但查不到事。
3.3 为什么第一步是"复述"而不是"开做"
你直接说"帮我做个宝妈孩子学习与成长管理工作台"，它会按它想象中的样子给你一个通用的东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。
先让它复述，等于把"需求的解释权"拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。
3.4 它大概会问你什么（提前有数，答得就快）
"孩子几年级？"——具体年级，影响内容深度
"要记几科？"——语文数学英语，三科够
"成长记录要写多细？"——一句话就够，不用成篇
"要不要提醒？"——打开能看到「这周还没记录」就够
"数据给谁看？"——主要自己看，偶尔给老师看
这里出现第一个"需要你输入"的点：上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。
四、第二步：让它先出方案，还是别写代码（提示词二）
4.1 提示词二：要一份方案
需求确认完，先别放它写代码。继续粘贴：

需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一条记录"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。
方案用中文写，控制在 500 字以内，不要贴代码。
4.2 方案怎么验收：只看三样
500 字方案一分钟看完，重点盯三处：

看什么

合格标准

薄弱点要能标到具体知识点

不能只写「数学弱」，要能写到「两位数进位加法」

成长记录必须有日期

没有日期，半年后翻就是一锅粥

有兴趣追踪

一个兴趣要能看到「从什么时候开始、持续多久」
4.3 方案不满意怎么改（提示词三，通用句式）

方案整体可以，改三处：
1. 薄弱点改成三级：科目、章节、具体知识点；
2. 成长记录默认按时间倒序，最新的在最上面；
3. 把任何排名、对比、评分功能全砍掉。
确认后给我更新版方案，还是不要代码。

一次最多改三处。这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。
五、第三步：生成第一版（提示词四，这次真写代码）
5.1 提示词四：带四条硬约束
方案点头之后，粘贴这段。四条硬约束一条都别删——每一条背后都是踩过的坑：

方案确认，开始做第一版。四条硬要求，必须全部满足：
1. 只做成一个单独的 HTML 文件，所有代码都写在这一个文件里，不要拆多个文件，不要安装任何依赖，做完我双击这个文件就能用；

做完以后，你自己把整个软件从头到尾完整点一遍，告诉我哪里顺手、哪里会让我困惑。

5.3 第一版验收清单（5 分钟点完）
WorkBuddy 做完后，去工作目录找到那个 HTML 文件，双击打开，然后逐条打勾：
建 3 个科目，各加 2 个薄弱点，能写到具体知识点
记一条成长记录，只写一句话，能存

关掉重开数据不丢
界面字够大，能跟孩子一起看

第一版只验"通不通"，不验"好不好看"。丑、慢、布局怪，都留到第七章的迭代环节统一处理。第一版就追求完美，你会陷入无止境的细节，搭不完。
六、第四步：把真实数据喂进去（决定它是玩具还是工具）
验收通过别急着庆祝。这一步最容易被跳过，也是决定工作台生死的一步。
6.1 操作
录进去：孩子现在真实的薄弱点（写到具体知识点）、最近老师说的原话、孩子最近在迷的东西。别写「表现良好」这种话，写具体的。
6.2 录完你会遇到两类问题——这是好事
第一类：字段不合手。比如它把「成绩」设成必填，可你不想给孩子打分；比如它要求成长记录填「类别」，可你只想随便记一句。
第二类：流程不顺手。比如记一条成长记录要先选孩子（明明只有一个孩子），多一步；比如薄弱点藏在三层菜单里，找半天。
拿张便签或者开个备忘录，标题就写"工作台待改清单"。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。

本章验收：打开软件，能看到孩子真实的薄弱点，而且你能一眼说出「哦对，他这里确实弱」。

7.1 迭代的三条纪律
一次只提 1~3 条。一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。
改完用一遍，再提下一轮。改动生效后至少真实使用半天，硌手的地方会自己冒出来。
提示词里带现象，别带结论。说"我点保存没反应"比说"保存功能坏了，你修一下"效果好——前者是证据，后者是让你俩一起猜。

十、数据备份（5 分钟一劳永逸，必须做）
10.1 先知道风险在哪
本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：清理浏览器缓存、卸载浏览器、重装系统时，数据会没。所以备份不是可选项。
10.2 先补上导出功能（如果你的第一版没有）

给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 成长档案备份_20261110.json；
2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
10.3 备份的三条规矩
每次用完固定导出一次，存进 D:\我的工作台\备份。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。
换电脑、清缓存、重装系统之前，先导出。记住：清浏览器缓存 = 清空工作台，没有例外。
恢复方法：点"导入数据"，选最新的 JSON 文件，确认。数据原样回来。
十一、进阶：让 WorkBuddy 继续替你干活
软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：
11.1 顺着兴趣设计活动
孩子的兴趣是最便宜的教育入口，但得有人帮你翻译成具体的事。

我孩子今年 X 岁，最近半年一直在迷【恐龙】。这是他这半年的成长记录（粘贴）。请帮我：
1. 分析他的兴趣点具体在哪（是恐龙本身，还是分类，还是故事）；
2. 顺着这个兴趣，给我 5 个能延伸出去的方向（阅读、动手、数学都可以）；
3. 每个方向给一个这周就能做的小活动。
11.2 薄弱点辅导方案
「多练练」这种建议等于没说。

我孩子三年级，数学薄弱点在【两位数进位加法】。请给我一个两周的辅导方案，每天不超过 15 分钟，要有具体题目示例，最后告诉我怎么判断他是不是真的掌握了。
11.3 老师沟通稿
跟老师说话，说轻了不像回事，说重了像挑刺。

这是我孩子最近的情况记录（粘贴）。我要跟老师沟通一次，请帮我写一段话：先说清楚我在家观察到什么，再问三个具体问题。语气要谦虚但不卑微。
注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。

答案
