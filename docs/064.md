### 一、整体流程：让 AI 按框架做竞品调研

> <p>竞品调研的关键不是&quot;信息越多越好&quot;，而是先明确目的，再把信息变成可执行决策。</p>

```
1        2        3        4        5        6定目标 → 选竞品 → 收资料 → AI拆解 → 横向对比 → 找机会
```

<table><thead><tr><th><p>阶段</p></th><th><p>关键动作</p></th><th><p>说明</p></th></tr></thead><tbody><tr><td><p>1. 定目标</p></td><td><p>明确是为了做选题、改卖点、优化定价，还是提升转化</p></td><td><p>越具体越好</p></td></tr><tr><td><p>2. 选竞品</p></td><td><p>选 3-5 个：直接竞品、间接竞品、替代方案</p></td><td><p>三类一起看</p></td></tr><tr><td><p>3. 收资料</p></td><td><p>准备可被分析的产品 / 内容 / 反馈信息</p></td><td><p>越具体越好</p></td></tr><tr><td><p>4. AI 拆解</p></td><td><p>让 WorkBuddy 按固定字段提炼</p></td><td><p>事实 / 判断分开</p></td></tr><tr><td><p>5. 横向对比</p></td><td><p>把竞品放进同一张表</p></td><td><p>找差异和空白</p></td></tr><tr><td><p>6. 找机会</p></td><td><p>转化为今天就能执行的动作</p></td><td><p>内容 / 产品 / 转化</p></td></tr></tbody></table>

#### 这份教程的使用原则

<ul><li>❌ 不要一上来就问&quot;帮我分析竞品&quot;</li><li>✅ 正确做法是：给背景、给目标、给字段、给资料、让 AI 先输出表格，再追问结论</li></ul>

### 二、第 1 步：准备资料，先喂可分析的信息

> <p>没有资料就让 AI 调研，结果通常会很空。新手先准备下面这些信息，越具体越好。</p>

#### 资料准备清单

<table><thead><tr><th><p>资料类型</p></th><th><p>去哪里找</p></th><th><p>复制给 WorkBuddy 时怎么写</p></th></tr></thead><tbody><tr><td><p>你的业务信息</p></td><td><p>自己整理</p></td><td><p>你卖什么、给谁用、解决什么问题、价格、交付方式</p></td></tr><tr><td><p>竞品入口</p></td><td><p>官网 / 店铺 / 小红书 / 课程页 / 详情页 / 直播间 / 私域转化页</p></td><td><p>任选能看到信息的入口</p></td></tr><tr><td><p>竞品内容样本</p></td><td><p>小红书 / 抖音 / 公众号 / 视频号</p></td><td><p>最近 10 篇内容标题、封面关键词、评论区高频问题、用户反馈截图</p></td></tr><tr><td><p>竞品产品信息</p></td><td><p>详情页 / 官网 / 朋友圈 / 落地页</p></td><td><p>主卖点、价格、套餐、赠品、承诺结果、售后方式、成交路径</p></td></tr><tr><td><p>你的调研目标</p></td><td><p>自己想清楚</p></td><td><p>这次调研到底是为了改标题、改产品、做选题、做定价，还是优化转化</p></td></tr></tbody></table>

#### 三个不要

<ul><li>❌<strong>不要只给截图</strong>：先把关键信息复制成文字，标题 / 价格 / 评论都分开粘贴</li><li>❌<strong>不要让 AI 脑补</strong>：资料没有就标&quot;待补充&quot;，结论必须有依据</li><li>❌<strong>不要一次只做一类</strong>：先拆产品，再拆内容，最后再合并成总表</li></ul>

#### 资料类型的标准描述模板

<ul><li>产品资料：&quot;这是竞品 A 的产品介绍，请按卖点 / 人群 / 价格拆解。&quot;</li><li>内容资料：&quot;这是竞品最近 10 条内容标题，请分析选题方向。&quot;</li><li>用户反馈：&quot;这些是用户反馈，请提炼需求、顾虑和未被满足点。&quot;</li><li>转化资料：&quot;这是竞品转化路径，请拆解用户从看到到购买的步骤。&quot;</li></ul>

### 三、第 2 步：设定目标，先把问题问窄

> <p>竞品调研不是写论文，而是为一个明确决策服务。目标越窄，WorkBuddy 输出越能落地。</p>

#### 4 种典型目标

<table><thead><tr><th><p>目标</p></th><th><p>关键动作</p></th><th><p>最终产出</p></th></tr></thead><tbody><tr><td><p>做内容选题</p></td><td><p>看竞品靠什么标题吸引人；找用户最常问的问题</p></td><td><p>30 个可发选题</p></td></tr><tr><td><p>优化产品卖点</p></td><td><p>看竞品主打什么结果；找别人没讲透的价值</p></td><td><p>重新包装核心卖点</p></td></tr><tr><td><p>调整定价套餐</p></td><td><p>对比价格、权益、赠品；判断用户愿意为哪部分付费</p></td><td><p>入门 / 标准 / 高阶套餐设计</p></td></tr><tr><td><p>提升咨询转化</p></td><td><p>拆竞品成交路径；提炼用户顾虑和临门一脚</p></td><td><p>优化私信话术和 FAQ</p></td></tr></tbody></table>

#### 新手目标公式

> <p>我要通过竞品调研，解决【具体决策】，最终输出【可执行物】。示例：我要通过调研 3 个同类账号，找到可复用的小红书选题方向，最终输出 30 个标题 + 5 个卖点优化建议。</p>

#### 提示词 1：先让 WorkBuddy 帮你定调研范围

```
你是一个资深竞品调研顾问。我的业务是【写你的业务】，
目标用户是【写人群】，这次调研的目的不是大而全，
而是为了【做内容选题 / 优化卖点 / 调整定价 / 提升转化】。

请你先帮我把本次竞品调研拆成：
1. 必须收集的信息；
2. 需要对比的维度；
3. 最终应该输出的表格；
4. 后续追问方向。输出要适合小白执行。
```

### 四、第 3 步：建立竞品清单，别只盯直接竞品

> <p>真正有价值的竞品通常分三类：直接竞品、间接竞品、替代方案。三类一起看，才容易找到机会。</p>

<table><thead><tr><th><p>类型</p></th><th><p>定义</p></th><th><p>重点观察</p></th></tr></thead><tbody><tr><td><p>直接竞品</p></td><td><p>卖的东西和你很像，目标用户也类似</p></td><td><p>1. 如何包装卖点；2. 价格和套餐结构；3. 成交路径</p></td></tr><tr><td><p>间接竞品</p></td><td><p>服务同一类用户，但解决路径不同</p></td><td><p>1. 切入什么痛点；2. 内容如何建立信任；3. 抢占了哪个场景</p></td></tr><tr><td><p>替代方案</p></td><td><p>用户不买你时，会用的其他办法</p></td><td><p>1. 用户为什么不付费；2. 低成本替代品；3. 你必须说清的价值</p></td></tr></tbody></table>

#### 举例：如果你卖&quot;AI 获客训练营&quot;

<ul><li>直接竞品：其他 AI 获客课</li><li>间接竞品：小红书运营课、私域成交课</li><li>替代方案：免费教程、社群资料包、代运营服务</li></ul>

### 五、第 4 步：信息整理成表，不要只丢截图

> <p>WorkBuddy 更擅长处理结构化资料。你可以先按下面这张表收集，再让 AI 继续拆解。</p>

<table><thead><tr><th><p>字段</p></th><th><p>填写示例</p></th><th><p>你需要观察什么</p></th></tr></thead><tbody><tr><td><p>竞品定位</p></td><td><p>AI 获客陪跑课</p></td><td><p>它服务谁？主打什么结果？一句话能否听懂？</p></td></tr><tr><td><p>核心卖点</p></td><td><p>30 天搭建获客闭环</p></td><td><p>卖点是否具体？是讲功能、方法，还是结果？</p></td></tr><tr><td><p>产品结构</p></td><td><p>资料包 + 直播课 + 陪跑</p></td><td><p>有哪些模块？哪个模块负责成交信任？</p></td></tr><tr><td><p>价格套餐</p></td><td><p>199 / 999 / 3999</p></td><td><p>低价入口、高价转化分别卖什么？</p></td></tr><tr><td><p>内容打法</p></td><td><p>痛点帖 + 案例帖</p></td><td><p>哪些标题高频出现？靠情绪、结果还是教程吸引？</p></td></tr><tr><td><p>转化路径</p></td><td><p>评论区领取 - 私信 - 社群 - 成交</p></td><td><p>用户从看到内容到购买经历几步？</p></td></tr><tr><td><p>用户反馈</p></td><td><p>想要模板 / 怕学不会</p></td><td><p>评论区暴露了哪些真实需求、顾虑和阻力？</p></td></tr></tbody></table>

#### 提示词 2：让 WorkBuddy 把资料整理成竞品卡片

```
下面是我收集的竞品资料：【粘贴竞品页面 / 标题 / 评论 / 价格等】。

请你不要先下结论，先按字段整理成一张"竞品卡片"：
定位、目标用户、核心痛点、主卖点、产品结构、价格套餐、
内容打法、转化路径、用户反馈、可借鉴点、风险点。缺失信息请标注"未看到"，不要编造。
```

### 六、第 5 步：先拆单个竞品，再横向对比

> <p>新手常犯的错误是：一次性把所有竞品丢进去。建议先让 WorkBuddy 逐个拆解，得到统一格式。</p>

#### 4 个标准动作

<ol><li><strong>单个竞品拆解</strong>：一次只分析一个竞品，让 AI 输出&quot;竞品卡片&quot;。</li><li><strong>信息缺口补全</strong>：让 AI 列出缺失字段，你再去补截图或链接内容。</li><li><strong>统一字段命名</strong>：所有竞品都用同一套字段，后面才能横向对比。</li><li><strong>再合并成总表</strong>：把 3-5 张竞品卡合成表，对比才会清楚。</li></ol>

#### 新手注意

<ul><li>❌ 不要让 AI 直接&quot;给我结论&quot;</li><li>✅ 先要结构化事实，再要判断</li><li>✅ 事实和判断分开，竞品调研才不容易跑偏</li></ul>

#### 提示词 3：单个竞品深度拆解

```
你现在只分析【竞品 A】。请按"事实-判断-启发"三层输出：

1. 事实：从我提供的资料中能明确看到的信息；
2. 判断：你推测它为什么这样设计，但请说明依据；
3. 启发：对我的业务有什么可借鉴和不能照抄的地方。

最后请用表格输出，字段包括：维度、事实、判断、对我的启发、我需要补充的信息。
```

### 七、第 6 步：5 维度对比，快速看出差异

> <p>竞品分析不是把资料堆在一起，而是把同类信息放在同一行，看谁做得更强、哪里有空白。</p>

#### 5 个对比维度

<table><thead><tr><th><p>维度</p></th><th><p>核心问题</p></th></tr></thead><tbody><tr><td><p>用户维度</p></td><td><p>服务谁？用户痛点是否更具体？用户愿意为什么结果付费？</p></td></tr><tr><td><p>产品维度</p></td><td><p>卖什么？模块如何组合？有没有低门槛入口和高价值交付？</p></td></tr><tr><td><p>内容维度</p></td><td><p>靠什么内容吸引用户？标题、封面、案例、教程各占多少？</p></td></tr><tr><td><p>转化维度</p></td><td><p>从看到到购买有几步？私信、社群、直播、落地页如何承接？</p></td></tr><tr><td><p>交付维度</p></td><td><p>买完如何交付？是否有模板、陪跑、答疑、结果验证？</p></td></tr></tbody></table>

#### 提示词 4：生成横向对比表

```
我已经整理了多个竞品卡片。请把它们合并成一张横向对比表，
列为：竞品 A / 竞品 B / 竞品 C / 我的业务，
行为：用户定位、核心痛点、主卖点、产品结构、价格套餐、
内容打法、转化路径、交付方式、用户顾虑、可借鉴点、差异化机会。请用表格输出。
```

### 八、第 7 步：挖评论区，找到真实需求

> <p>竞品页面写的是&quot;卖点&quot;，评论区暴露的是&quot;用户为什么想买、为什么犹豫、为什么不满意&quot;。</p>

<table><thead><tr><th><p>用户视角</p></th><th><p>典型原话</p></th></tr></thead><tbody><tr><td><p>用户想要什么</p></td><td><p>&quot;有没有模板？&quot; &quot;适合小白吗？&quot; &quot;能不能直接套用？&quot;</p></td></tr><tr><td><p>用户担心什么</p></td><td><p>&quot;学不会怎么办？&quot; &quot;会不会太复杂？&quot; &quot;有没有售后答疑？&quot;</p></td></tr><tr><td><p>用户不满意什么</p></td><td><p>&quot;内容太泛&quot; &quot;案例不够真实&quot; &quot;没有具体步骤&quot;</p></td></tr><tr><td><p>用户愿意付费点</p></td><td><p>省时间、少走弯路、拿到结果、有人带着做</p></td></tr></tbody></table>

#### 评论区提炼公式

> <p><strong>高频问题 = 真实需求</strong>；<strong>重复顾虑 = 转化阻力</strong>；<strong>差评内容 = 改进机会</strong>；<strong>用户原话 = 你的内容标题和销售话术素材</strong>。</p>

#### 提示词 5：分析评论区 / 用户反馈

```
下面是我收集的竞品评论区和用户反馈：【粘贴评论】。

请你按 4 类提炼：
1. 用户最想解决的问题；
2. 用户购买前的顾虑；
3. 用户对竞品不满意的点；
4. 可以转化成我内容标题 / 卖点 / FAQ 的话术。

要求：尽量保留用户原话，不要写空泛总结，并给我 10 个可以直接发的小红书选题。
```

### 九、第 8 步：输出竞品矩阵，找到机会点

> <p>矩阵不是为了好看，而是为了回答：竞品强在哪里？弱在哪里？我从哪里切入更容易成交？</p>

#### 竞品矩阵示例

#### 机会判断的 3 种策略

### 十一、通用提示词模板（4 个）

> <p>把【】里的内容替换成你的业务信息，即可开始跑一次完整竞品调研。</p>

#### 模板 1：建立调研表

```
我正在做【业务 / 产品】，目标用户是【人群】，
这次想调研【3-5 个竞品名称】。

请你作为竞品调研顾问，先帮我设计一张调研表，
字段包括：定位、人群、痛点、卖点、产品结构、价格、内容打法、转化路径、交付方式、用户反馈、可借鉴点、风险点。
```

#### 模板 2：拆解单个竞品

```
下面是竞品资料：【粘贴资料】。

请按"事实-判断-启发"输出。事实只能来自我提供的信息，
判断需要说明依据，启发要结合我的业务。不要编造缺失信息，缺失处标注"待补充"。
```

#### 模板 3：横向对比

```
请把竞品 A / B / C 和我的业务做横向对比，
输出一张表。重点找出：竞品共性、差异化位置、用户未被满足的需求、我最容易切入的机会点。
```

#### 模板 4：输出行动方案

```
请基于竞品调研结果，帮我生成：
1. 10 个小红书内容选题；
2. 5 个产品卖点优化方向；
3. 1 套私信转化 FAQ；
4. 14 天执行计划。要求具体、可执行、适合小白。
```
