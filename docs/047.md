前言

WorkBuddy 是 OpenClaw  家族的企业级 AI 助手，最大的优势之一就是支持 Skills 扩展——通过加载不同领域的专业技能包，让 AI 在特定任务上表现得更加专业和高效。

Skill 2：Copywriter（文案写作）
用途：生成按钮标签、错误提示、落地页文案、CTA（行动号召）等用户界面文案。
使用场景：
运营活动需要大量文案
产品界面的按钮文案不知道写什么好
需要 A/B 测试版本的文案对比
核心能力：根据不同平台和用户场景，生成符合语境的精准短文案。

# WorkBuddy Skills 使用指南
import requests

payload = {
    "type": "cta",           # 文案类型：cta / button / error / empty_state
    "product": "企业协作平台",
    "audience": "企业IT负责人",
    "tone": "professional"  # 语气：professional / friendly / urgent
}

response = requests.post(
    "",
    json=payload
)
print(response.json()["suggestions"])

用途：通过 HTTP API 控制浏览器 ，完成网页导航、元素点击、表单填写、数据抓取等操作。

Skill 5：Code Explorer（代码库探索）
用途：在大型代码库中搜索文件、类、函数，理解代码结构和依赖关系。
使用场景：
接手一个新项目，需要快速了解代码结构
搜索某个功能在哪里实现
查找变量或函数的引用位置
核心能力：支持模式匹配、全文搜索、依赖图分析、批量文件操作。

# WorkBuddy Skills 使用指南
import requests

response = requests.post(
    "",
    json={
        "query": "用户登录 authentication login",
        "file_types": ["*.py", "*.js"],  # 限定文件类型
        "max_results": 10
    }
)

for result in response.json()["matches"]:
    print(f"文件: {result['file']}")
    print(f"匹配内容: {result['snippet']}")
    print("---")

四、知识管理类 Skills
Skill 10：腾讯云 COS（对象存储）
用途：管理腾讯云对象存储（COS），支持文件上传下载、批量管理、签名链接生成、图片处理等。
使用场景：
将 WorkBuddy 生成的内容自动上传到云端
生成文件分享链接
对图片进行压缩、水印等处理

# WorkBuddy Skills 使用指南
import requests

response = requests.post(
    "",
    json={
        "bucket": "my-bucket-1234567890",
        "region": "ap-shanghai",
        "file_path": "/local/path/to/report.pdf",
        "object_key": "reports/2026-Q2-marketing.pdf",
        "generate_signed_url": True,  # 生成签名分享链接
        "url_expire_seconds": 3600     # 链接有效期（秒）
    }
)
result = response.json()
print(f"文件地址: {result['url']}")
print(f"签名链接: {result['signed_url']}")
