## 一、内容创作类 Skills

### Skill 1：Humanizer（去 AI 味）

<p><strong>用途：</strong>将 AI 生成的文章改写成更自然、更像真人写作的风格。</p>

<p><strong>使用场景：</strong></p>

<ol><li>生成的文章太&quot;模板化&quot;，需要润色</li><li>需要降低 AI 生成内容的机器感，提升可读性</li></ol>

<p><strong>核心能力：</strong>检测并修复 AI 写作特征，包括夸大的宣传语、过度使用破折号、规则三段式等。</p>

```javascript
# 使用示例：调用 Humanizer 润色文本
# 安装 skill 后，直接在对话中使用自然语言指令
# 例如："帮我把这篇文章去AI味，让它读起来更自然"

# 如果需要编程调用，可通过 skill 暴露的 API：
import requests

response = requests.post(
    "http://localhost:8080/skills/humanizer",
    json={"text": "在这里输入你需要润色的文章内容"}
)print(response.json()["result"])
```

### Skill 2：Copywriter（文案写作）

<p><strong>用途</strong>：生成按钮标签、错误提示、落地页文案、CTA（行动号召）等用户界面文案。</p>

<p><strong>使用场景</strong>：</p>

<ul><li>运营活动需要大量文案</li><li>产品界面的按钮文案不知道写什么好</li><li>需要 A/B 测试版本的文案对比</li></ul>

<p><strong>核心能力</strong>：根据不同平台和用户场景，生成符合语境的精准短文案。</p>

```javascript
# 使用示例：为 SaaS 产品生成 CTA 文案
import requests

payload = {
    "type": "cta",           # 文案类型：cta / button / error / empty_state
    "product": "企业协作平台",
    "audience": "企业IT负责人",
    "tone": "professional"  # 语气：professional / friendly / urgent
}

response = requests.post(
    "http://localhost:8080/skills/copywriter",
    json=payload
)
print(response.json()["suggestions"])# 输出示例：["立即开始免费试用", "预约DEMO演示", "获取专属解决方案"]
```

### Skill 3：公众号文章排版

<p><strong>用途：</strong>将 Markdown 文章自动排版为微信公众号格式，生成预览链接 。</p>

<p><strong>使用场景：</strong></p>

<ol><li>写完公众号文章后，需要一键排版</li><li>希望看到 AI 结构化版和主题渲染版两个预览</li></ol>

<p><strong>核心能力：</strong>自动识别标题层级、生成引用块、适配公众号阅读体验。</p>

```javascript
# 使用示例：排版公众号文章
import requests

response = requests.post(
    "http://localhost:8080/skills/公众号文章排版",
    json={
        "markdown_content": "# 这里是标题\n\n这里是正文内容..."
    }
)
# 返回两个预览链接：AI结构化版 + 预设主题渲染版print(response.json())
```

## 二、技术开发类 Skills

### Skill 4：BrowserWing（浏览器自动化）

<p><strong>用途：</strong>通过 HTTP API 控制浏览器 ，完成网页导航、元素点击、表单填写、数据抓取等操作。</p>

<p><strong>使用场景：</strong></p>

<ol><li>需要定时抓取竞品官网价格更新</li><li>自动填写和提交表单</li><li>批量截图或导出网页数据</li></ol>

<p><strong>核心能力：</strong>支持页面导航、元素交互、截图、JavaScript 执行、批量操作。</p>

```javascript
# 使用示例：用 BrowserWing 抓取网页数据
import requests

# 启动浏览器并导航到目标页面
session = requests.post(
    "http://localhost:8080/skills/browser/start",
    json={"headless": True}
)
session_id = session.json()["session_id"]

# 截图
requests.post(
    "http://localhost:8080/skills/browser/screenshot",
    json={"session_id": session_id, "url": "https://work.weixin.qq.com/"}
)

# 提取页面内容
requests.post(
    "http://localhost:8080/skills/browser/extract",
    json={
        "session_id": session_id,
        "selector": ".index-content"  # CSS选择器
    })
```

### Skill 5：Code Explorer（代码库探索）

<p><strong>用途：</strong>在大型代码库中搜索文件、类、函数，理解代码结构和依赖关系。</p>

<p><strong>使用场景：</strong></p>

<ol><li>接手一个新项目，需要快速了解代码结构</li><li>搜索某个功能在哪里实现</li><li>查找变量或函数的引用位置</li></ol>

<p><strong>核心能力：</strong>支持模式匹配、全文搜索、依赖图分析、批量文件操作。</p>

```javascript
# 使用示例：在代码库中搜索功能实现
import requests

response = requests.post(
    "http://localhost:8080/skills/code-explorer/query",
    json={
        "query": "用户登录 authentication login",
        "file_types": ["*.py", "*.js"],  # 限定文件类型
        "max_results": 10
    }
)

for result in response.json()["matches"]:
    print(f"文件: {result['file']}")
    print(f"匹配内容: {result['snippet']}")print("---")
```

<p><strong>使用场景：</strong></p>

## 三、效率办公类 Skills

### Skill 7：Himalaya（邮件管理）

<p><strong>用途</strong>：通过 CLI 管理邮件，支持列表、阅读、撰写、回复、转发、搜索等操作。</p>

<p><strong>使用场景</strong>：</p>

<ul><li>需要在终端快速处理邮件</li><li>将邮件内容整合到其他工作流中</li><li>批量管理客户邮件</li></ul>

```
# 安装
# 参考：https://github.com/soyElSagg/Himalaya

# 列出收件箱前10封邮件
himalaya list --account your-email@example.com

# 发送邮件
himalaya write --account your-email@example.com \
  --to recipient@example.com \
  --subject "工作周报" \--body "本周工作总结如下..."
```

### Skill 8：飞书套件（Lark/Feishu CLI）

<p><strong>用途</strong>：通过命令行操作飞书生态，包括即时通讯、云文档、表格、日历、邮件、视频会议等。</p>

<p><strong>使用场景</strong>：</p>

<ul><li>定时从飞书文档拉取数据</li><li>自动发送飞书消息通知</li><li>创建和管理飞书日程</li></ul>

```
# 安装飞书 CLI 后，基本操作示例：
# 发送飞书消息
feishu im message create \
  --receiver_type=user_id \
  --receiver_id=ou_xxxxx \
  --msg_type=text \
  --content='{"text":"会议将在10分钟后开始"}'

# 创建飞书文档
feishu docs document create \--title="2026 Q2 工作计划"
```

### Skill 9：腾讯会议（Tencent Meeting）

<p><strong>用途</strong>：通过命令行管理腾讯会议，包括创建会议、查询成员、获取录制文件等。</p>

<p><strong>使用场景</strong>：</p>

<ul><li>定时创建周期性会议</li><li>自动获取会议参会人员名单</li><li>查询和管理历史录制文件</li></ul>

```javascript
# 使用示例：创建腾讯会议
import requests

response = requests.post(
    "http://localhost:8080/skills/腾讯会议/create",
    json={
        "topic": "产品周会",
        "start_time": "2026-04-15T10:00:00+08:00",
        "duration": 60,  # 分钟
        "password": False
    }
)
meeting_info = response.json()
print(f"会议号: {meeting_info['meeting_id']}")print(f"入会链接: {meeting_info['join_url']}")
```

## 四、知识管理类 Skills

### Skill 10：腾讯云 COS（对象存储）

<p><strong>用途</strong>：管理腾讯云对象存储（COS），支持文件上传下载、批量管理、签名链接生成、图片处理等。</p>

<p><strong>使用场景</strong>：</p>

<ul><li>将 WorkBuddy 生成的内容自动上传到云端</li><li>生成文件分享链接</li><li>对图片进行压缩、水印等处理</li></ul>

```javascript
# 使用示例：上传文件并生成分享链接
import requests

response = requests.post(
    "http://localhost:8080/skills/腾讯云COS/upload",
    json={
        "bucket": "my-bucket-1234567890",
        "region": "ap-shanghai",
        "file_path": "/local/path/to/report.pdf",
        "object_key": "reports/2026-Q2-marketing.pdf",
        "generate_signed_url": True,  # 生成签名分享链接
        "url_expire_seconds": 3600     # 链接有效期（秒）
    }
)
result = response.json()
print(f"文件地址: {result['url']}")print(f"签名链接: {result['signed_url']}")
```
