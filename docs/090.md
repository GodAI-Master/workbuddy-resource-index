WorkBuddy 工作台全套资料 · 第 04 篇
本篇是「副业赚钱与个人财务工作台」的完整搭建 SOP。一句话：把你所有进账出账摊在一张桌上，第一次清楚知道「我这个月到底赚了多少、钱花哪了、哪个副业值得继续做」。
一、这个工作台解决什么问题
1.1 先看看你有没有这三个瞬间
瞬间一：月底看余额，感觉这个月赚了不少，但具体哪个渠道赚的、一共多少，说不清。有人问「你副业一个月能挣多少」，只能含糊说「看情况」。
瞬间二：同时做三四件事——接单、带货、写稿、卖点闲置。每件都在花时间，但从来没算过时薪。结果最耗时间那件，可能一小时只赚 8 块。
瞬间三：钱进来就花掉了，没有账。年底想存点钱，发现不知道钱去哪了，只能安慰自己「生活成本高」。
这个工作台只干一件事：让每一笔钱和每一小时都有归处。它不教你赚钱，它让你看清现在到底赚不赚。

为什么是"桌面软件"而不是表格？记账软件最大的敌人是「记着记着就不记了」，原因通常是输入太麻烦。这个工作台的设计目标是：记一笔账不超过 5 秒。快到你不需要下决心，它才能活下来。
二、开工前的准备（10 分钟，全在你这边）
正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。
2.1 准备清单
WorkBuddy 客户端装好、登录。没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。
在电脑上建一个空文件夹。比如 D:\我的工作台\副业财务。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。
挑一个你顺手的浏览器。Edge 或 Chrome 都行。定了就一直用它开这个软件，因为数据跟着浏览器走（原因见第十章）。
准备几条真实数据（纸面想好就行，不用打字）：你上个月的收入来源（几个渠道、各多少）；上个月最大的三笔支出；正在做的副业，各自每周花多少小时。

唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。别用"项目A、测试数据"这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。
2.2 全程你会用到的角色分工
整套流程就两个角色，别搞混：
WorkBuddy：施工队。所有代码、界面、功能都是它写，你一行代码都不用碰。
你：甲方 + 验收员。你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。
这个分工意味着：SOP 里所有"做"的动作都是复制粘贴提示词，所有"判断"的动作是你亲手点一遍。哪一步跳过了"自己点一遍"，后面必然返工。
三、第一步：跟 WorkBuddy 把话说清楚（提示词一）
3.1 开工操作
打开 WorkBuddy，点新建任务，模式选 Agent 模式（它能自己动手建文件，别选纯问答模式）。
把工作目录设成第二章建好的那个文件夹（比如 D:\我的工作台\副业财务）。设错也不致命，就是文件会落别处，你得多翻一下。
在输入框粘贴下面这段提示词，回车。
3.2 提示词一：需求确认版（先别让它写代码）

我要做一个"副业赚钱与个人财务工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。
需求背景：我有主业，也在做副业。痛点是：说不清副业到底赚多少、没算过时间投入值不值、钱花了不知道去哪、月底从来不复盘。
3.3 为什么第一步是"复述"而不是"开做"
你直接说"帮我做个副业赚钱与个人财务工作台"，它会按它想象中的样子给你一个通用的东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。
先让它复述，等于把"需求的解释权"拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。
3.4 它大概会问你什么（提前有数，答得就快）
"要记到多细？"——记到「类」，不记到「分」，比如餐饮、交通、房租
"副业收入要分渠道吗？"——要，每个渠道单独统计
"要不要算时薪？"——要，这是核心
"固定支出怎么处理？"——单独一个日历，到期前提醒
"数据从哪来？"——全部手动录，不接任何银行
这里出现第一个"需要你输入"的点：上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。
四、第二步：让它先出方案，还是别写代码（提示词二）
4.1 提示词二：要一份方案
需求确认完，先别放它写代码。继续粘贴：

需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一条记录"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。
方案用中文写，控制在 500 字以内，不要贴代码。
4.2 方案怎么验收：只看三样
500 字方案一分钟看完，重点盯三处：

看什么

合格标准

每条账有日期、金额、分类

少一个分类，月度汇总就没意义

副业有「投入小时数」

没有小时数就算不出时薪，这个台子的核心价值就没了

有月度汇总页

必须能自动算出总收入、总支出、各渠道占比
4.3 方案不满意怎么改（提示词三，通用句式）

方案整体可以，改三处：
1. 记账页改成一行输入：金额加备注，分类自动猜；
2. 副业页加「时薪」列，按收入除以小时数自动算；
3. 把预算警告改成中性提示。
确认后给我更新版方案，还是不要代码。

一次最多改三处。这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。

六、第四步：把真实数据喂进去（决定它是玩具还是工具）
验收通过别急着庆祝。这一步最容易被跳过，也是决定工作台生死的一步。
6.1 操作
录进去：上个月真实的收入（有几个渠道就几条）、最大三笔支出、正在做的副业和每周投入小时数。这一步会有点扎心，尤其算出来时薪很低的时候——但看清了才有得改。
6.2 录完你会遇到两类问题——这是好事
第一类：字段不合手。比如它的分类是预设的十几项，你想加「宠物」和「随礼」；比如它要求每笔都填「支付方式」，可你根本不在乎。
第二类：流程不顺手。比如记账要选日期、选分类、输金额、写备注、点保存，五步；你想的是输个数字回车就完事。
拿张便签或者开个备忘录，标题就写"工作台待改清单"。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。

本章验收：打开现金流页，看到的是你这个月真实的收入和支出，结余数字是你自己的。

7.1 迭代的三条纪律
一次只提 1~3 条。一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。
改完用一遍，再提下一轮。改动生效后至少真实使用半天，硌手的地方会自己冒出来。
提示词里带现象，别带结论。说"我点保存没反应"比说"保存功能坏了，你修一下"效果好——前者是证据，后者是让你俩一起猜。

十、数据备份（5 分钟一劳永逸，必须做）
10.1 先知道风险在哪
本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：清理浏览器缓存、卸载浏览器、重装系统时，数据会没。所以备份不是可选项。
10.2 先补上导出功能（如果你的第一版没有）

给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 财务工作台备份_20261110.json；
2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
10.3 备份的三条规矩
每次用完固定导出一次，存进 D:\我的工作台\备份。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。
换电脑、清缓存、重装系统之前，先导出。记住：清浏览器缓存 = 清空工作台，没有例外。
恢复方法：点"导入数据"，选最新的 JSON 文件，确认。数据原样回来。
十一、进阶：让 WorkBuddy 继续替你干活
软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：
11.1 让它算值不值
副业最怕的就是「忙了很久，算完发现不如上班」。

这是我的副业数据（粘贴）：每个项目的月收入、每周投入小时数。请帮我算每个项目的时薪，从高到低排，并告诉我：如果要砍掉一个，应该砍哪个，为什么。
11.2 消费结构体检
你以为自己花得不多，数据不会骗你。

这是我上个月的支出明细（粘贴）。请分析：
1. 哪三类支出占比最高；
2. 有哪些可以直接砍掉不影响生活质量；
3. 如果我要每月多存 1000 块，最该从哪下手。

我做的副业是【XXX】，目前收费【XXX】，每周投入【X】小时。请分析这个定价合不合理，给出三个调整方案（涨价/打包/降本），并说明各自风险。
注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。
