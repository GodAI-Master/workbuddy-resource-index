# WorkBuddy 全流程提效

## 这套合集讲什么：WorkBuddy 全流程提效

<p>WorkBuddy 是腾讯出品的全场景 AI 办公工作台：你用一句话说出要求，它会自主规划、调用工具、生成文件，把过程和结果都留给你审核。这套合集把它拆成「入门」和「应用与开发」两大阶段、三个实战方向，从零基础一路讲到能独立搭建自己的 AI 工作台。</p>
