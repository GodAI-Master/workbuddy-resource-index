## 选题与视频规划

内容选题可以从明确需求、常见问题和公开讨论中整理。检索时应使用有权限的来源，并记录日期与依据；不要仅凭热度推断真实需求。

### 选题步骤

1. 收集主题相关的公开问题和讨论。
2. 对比关联问题，区分普遍需求与个别反馈。
3. 根据目标受众、内容形式和可用素材筛选主题。
4. 将选题、来源、状态和下一步整理到本地选题清单。

### 视频脚本结构

可按“开场问题 → 解释或演示 → 结果与依据 → 下一步建议”的顺序组织脚本。录制前确认口播时长、画面切换、字幕、配乐和所需素材；素材须有合法使用权。

### 发布前检查

检查事实、字幕、音量、画面和授权范围。发布前确认文件中没有个人账号信息、访问凭证、未授权音乐或不需要公开的二维码。
