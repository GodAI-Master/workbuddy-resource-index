二、制作交互式 PPT（HTML 嵌入）

在传统物理教学中，许多光学实验因受限于器材、场地与瞬时现象，常难以在课堂中清晰、动态地展示。为突破这一教学瓶颈，我们创新性地采用 WorkBuddy 与 WPS 相结合的数字化方案，将交互式光学模拟实验直接嵌入教学课件中。
借助 WPS 对 HTML 内容的嵌入式支持，我们能够将原本静态的 PPT 转化为一个可操作、可演示的 轻量化实验平台。教师可以在讲解「小孔成像」时让学生实时调整物距、像距；也可以在演示「光的折射」时动态改变入射角与介质参数，使光线路径与折射规律可视化呈现。
这不仅提升了课堂的互动性与探究性，更实现了 抽象原理的具象转化、瞬时过程的动态掌控，为物理教学与学生学习提供了全新的数字化路径。
