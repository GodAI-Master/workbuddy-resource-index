# WorkBuddy 消息机器人接入指南

本指南整理将授权的消息机器人接入 WorkBuddy 的基本流程。平台界面和可用渠道会随版本变化，请以当前产品说明为准。

## 接入前准备

- 使用有权管理的消息平台账号和机器人应用。
- 明确需要接入的会话类型与事件范围，只启用实际需要的能力。
- 确认回调地址、网络访问权限和账号授权均由管理员配置。

## 创建机器人应用

在相应平台的开发者控制台创建机器人，填写名称、简介和头像等基本信息。名称应能说明用途，避免使用个人账号资料作为公开标识。

## 配置凭证与回调

平台可能提供 App ID、App Secret、Token、Webhook 或事件回调地址。将凭证通过平台或 WorkBuddy 提供的安全设置入口配置，切勿把真实值写入公开文档、提示词、截图或代码仓库。若凭证曾被公开，立即在平台轮换并重新授权。

配置回调时，只勾选任务所需的消息事件，并核对平台要求的校验方式、网络范围和回调地址。不同平台的字段名称与流程可能不同。

## 在 WorkBuddy 中绑定

打开 WorkBuddy 的集成或 Claw 设置，选择对应消息渠道，按界面提示完成授权。首次接入先用测试账号发送一条普通消息，确认机器人能收到、处理并按预期回复。

## 检查与维护

1. 检查机器人权限是否限于必要范围。
2. 检查消息来源、自动回复内容和人工接管方式。
3. 定期复核凭证、回调配置和事件范围；发现异常时暂停自动化并撤销授权。
4. 不要在公开材料中保留二维码、个人账号、手机号、邮箱、证件信息或真实密钥。
