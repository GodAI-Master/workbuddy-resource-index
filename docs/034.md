# 腾讯版小龙虾 WorkBuddy 来了，接入微信直接替你24小时干活!(实操指南）

## 资料在下面

> [!TIP]

> <p>最近，腾讯推出了一个非常简单就能安装部署的小龙虾。本文从 0 到 1 带你部署小龙虾，<strong>接入到微信、QQ、企业微信</strong>里面。同时还能让它听懂语音，和你说话。</p>

## 01、<strong>腾讯小龙虾：WorkBuddy</strong>

<p>WorkBuddy Claw 是 CodeBuddy 团队推出的一项全新能力。</p>

<p>它让你从<strong>在本地电脑里等 AI 回答几行文字</strong>，升级成<strong>用手机直接下任务，让 AI 把整件事做完</strong>。</p>

<p>你不再需要守在电脑前盯着对话框，而是在 微信、QQ、企业微信、飞书等 IM 工具里，像和同事聊天一样派活。</p>

<img src="../assets/images/image_0100.jpg" alt="原文配图" width="1080" />

<p>只要在手机上打开微信或QQ，给 WorkBuddy 说句话，<strong>就能调动这个躺在你电脑上的小龙虾给你干活儿。</strong></p>

<p>而且，<strong>手机和桌面端能同步控制。</strong></p>

<img src="../assets/images/image_0101.jpg" alt="原文配图" width="1080" />

<p>WorkBuddy 最近也上线了插件市场，你可以从里面<strong>安装各种各样的 Skill 和 Agent。</strong>包括 Office 文件处理、深度研究搜索、海报生成、应用开发。</p>

<img src="../assets/images/image_0102.png" alt="原文配图" width="1080" />

<img src="../assets/images/image_0103.png" alt="原文配图" width="1080" />

<p>关于模型，支持 GLM、Minimax、Kimi、DeepSeek 国产模型。</p>

<img src="../assets/images/image_0104.png" alt="原文配图" width="766" />

## 02、<strong>如何配置</strong>

<p><strong>① 先安装  WorkBuddy</strong>先去下载 WorkBuddy，安装在你的电脑上。安装完先登录一下。</p>

<img src="../assets/images/image_0105.png" alt="原文配图" width="1080" />

<ul><li></li></ul>

```
下载地址：https://www.codebuddy.cn/work/
```

<p><strong>② 在微信中聊天</strong></p>

<p>登录完，直接打开右上角「Claw 设置」。</p>

[原文图片暂未收录]

<p>然后找到微信客服号集成，点击配置。然后使用你的微信扫描二维码就行了。</p>

[原文图片暂未收录]

<p>扫码成功，手机会进入到微信的一个聊天界面。WordBuddy 会提示你微信已经绑定成功。</p>

[原文图片暂未收录]

<img src="../assets/images/image_0106.jpg" alt="原文配图" width="1080" />

<p><strong>③ 在企业微信中聊天</strong></p>

<p>如果你想在企业微信里和小龙虾聊天，可以看下面。</p>

<p>我这里拿个人用户举例，也就是企业微信里面就你一个人，或者你是管理员。</p>

<p>你先去访问企业微信管理后台，使用管理员账号登录后，依次点击<strong>安全与管理 → 管理工具 → 智能机器人 → 创建机器人</strong></p>

<ul><li></li></ul>

```
地址：https://work.weixin.qq.com/wework_admin/frame
```

<img src="../assets/images/image_0107.png" alt="原文配图" width="1080" />

<p>点击创建机器人</p>

<img src="../assets/images/image_0108.png" alt="原文配图" width="1080" />

<p>注意，点击右下角的手动创建。</p>

<img src="../assets/images/image_0109.png" alt="原文配图" width="1080" />

<p>点击右下角很隐晦的 API 模式。</p>

<img src="../assets/images/image_0110.png" alt="原文配图" width="1080" />

<p>可以使用长链接。记住 Bot ID 和 Secret。</p>

<img src="../assets/images/image_0111.png" alt="原文配图" width="1080" />

<p>这时候打开 WorkBuddy，找到企业微信 AIBot 集成。</p>

<img src="../assets/images/image_0112.png" alt="原文配图" width="1080" />

<p>把刚刚记录的 id 和密钥添进去。</p>

<img src="../assets/images/image_0113.png" alt="原文配图" width="1080" />

<p>然后回到企业微信后台，设置一下可见范围。也就是说企业里面的谁能看到这个机器人，选中你就行了。</p>

<img src="../assets/images/image_0114.png" alt="原文配图" width="1080" />

<p>打开企业微信，在通讯录就会有你刚刚创建的小龙虾了。你就能和他对话了。</p>

<img src="../assets/images/image_0115.png" alt="原文配图" width="958" />

<img src="../assets/images/image_0116.png" alt="原文配图" width="1080" />

<p><strong>④ 在 QQ 中聊天</strong></p>

<p>同样，你也能在 QQ 中和他聊天。只不过，目前配置 QQ 聊天机器人还稍微有一点繁琐。</p>

<p>打听到，更简化长链接版本在路上了，上线后我第一时间在评论区给出教程。</p>

<p>下面是目前稍微复杂一点的接入 QQ 的教程。</p>

<p>首先，登录 QQ 开放平台。注意是 QQ 开发平台而不是 QQ 本身。地址是下面这个：</p>

<ul><li></li></ul>

```
地址：https://q.qq.com/#/apps
```

<img src="../assets/images/image_0117.png" alt="原文配图" width="1080" />

<p>点击下面的「立即注册」先注册一个 QQ 开发平台的账号。</p>

<img src="../assets/images/image_0118.jpg" alt="原文配图" width="1080" />

<p>然后你的注册邮箱会收到一个链接，你通过这个链接输入下面这些信息就行了：设置超级管理员。</p>

<img src="../assets/images/image_0119.jpg" alt="原文配图" width="1080" />

<p>填写主体信息。</p>

<img src="../assets/images/image_0120.png" alt="原文配图" width="1080" />

<p>身份验证。</p>

<img src="../assets/images/image_0121.png" alt="原文配图" width="1080" />

<p>创建机器人。</p>

<img src="../assets/images/image_0122.png" alt="原文配图" width="1080" />

<p>输入机器人的信息。</p>

<img src="../assets/images/image_0123.png" alt="原文配图" width="1080" />

<p>开发管理里面，你要记下 AppID 和 AppSecret。</p>

<img src="../assets/images/image_0124.png" alt="原文配图" width="1080" />

<p>打开你的 QQ 机器人集成，把 AppID 和 AppSecret 配置进去。记录下 Webhook 后面会用到。</p>

<img src="../assets/images/image_0125.png" alt="原文配图" width="1080" />

<p>然后在回调配置里面，把 Webhook 和单聊的事件都配置上。</p>

[原文图片暂未收录]

<p>然后再「沙箱配置」里面，QQ 扫描二维码就能在 QQ 里面和 Claw 聊天了。</p>

[原文图片暂未收录]
