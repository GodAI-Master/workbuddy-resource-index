一、这个工作台解决什么问题
1.1 先看看你有没有这三个瞬间
瞬间一：每天早上称体重，今天重了 0.4 公斤就心情差一天，明天轻了 0.3 又觉得有希望。一个月下来体重没变，情绪坐了三十趟过山车。
瞬间二：办了年卡，前两周天天去，第三周开始「今天太累了明天补」，然后就没有然后了。回头看，根本不知道是哪一天断的。
瞬间三：想减脂，教练说「控制饮食」，但「控制」到底是多少？吃了一份麻辣烫算多少？完全没数，最后靠「感觉吃得不多」安慰自己。
这个工作台不负责让你变瘦，它负责把「感觉」换成「数字」。减脂失败十次有九次不是不够努力，是根本不知道自己吃了多少、练了多少。

为什么是"桌面软件"而不是表格？体重每天在 1 公斤范围内波动是正常的——水、盐、排便、女性生理周期都在影响它。但人眼只会看「今天比昨天重了」。软件做一件人做不到的事：算 7 天平均值。只有平均值才反映真实趋势，这一条就是它比手机备忘录强的地方。
二、开工前的准备（10 分钟，全在你这边）
正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。
2.1 准备清单
WorkBuddy 客户端装好、登录。没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。
在电脑上建一个空文件夹。比如 D:\我的工作台\健身减脂。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。
挑一个你顺手的浏览器。Edge 或 Chrome 都行。定了就一直用它开这个软件，因为数据跟着浏览器走（原因见第十章）。
准备几条真实数据（纸面想好就行，不用打字）：你最近一个月的体重（能想起几个写几个）；你现在的训练安排（或诚实的「完全没有」）；你常吃的 10 样东西。

唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。别用"项目A、测试数据"这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。
2.2 全程你会用到的角色分工
整套流程就两个角色，别搞混：
WorkBuddy：施工队。所有代码、界面、功能都是它写，你一行代码都不用碰。
你：甲方 + 验收员。你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。
这个分工意味着：SOP 里所有"做"的动作都是复制粘贴提示词，所有"判断"的动作是你亲手点一遍。哪一步跳过了"自己点一遍"，后面必然返工。

3.1 开工操作
打开 WorkBuddy，点新建任务，模式选 Agent 模式（它能自己动手建文件，别选纯问答模式）。
把工作目录设成第二章建好的那个文件夹（比如 D:\我的工作台\健身减脂）。设错也不致命，就是文件会落别处，你得多翻一下。
在输入框粘贴下面这段提示词，回车。
3.2 提示词一：需求确认版（先别让它写代码）

我要做一个"健身减脂与身体成长工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。
需求背景：我想减脂或增肌，但一直没成功。痛点是：体重天天波动看不出效果、不知道每天该练什么、吃了多少完全没概念、坚持两周就断。
3.3 为什么第一步是"复述"而不是"开做"
你直接说"帮我做个健身减脂与身体成长工作台"，它会按它想象中的样子给你一个通用的东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。
先让它复述，等于把"需求的解释权"拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。
3.4 它大概会问你什么（提前有数，答得就快）
"要记录哪些身体数据？"——体重必填，体脂和围度选填
"训练计划我自己定还是软件排？"——我自己定一个模板，软件按周循环
"饮食要精确算卡路里吗？"——不要，只估算个大概区间
"要不要接运动手环？"——不要，手动录就行
"目标是什么？"——比如三个月减 5 公斤，或增肌 3 公斤
这里出现第一个"需要你输入"的点：上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。

六、第四步：把真实数据喂进去（决定它是玩具还是工具）
验收通过别急着庆祝。这一步最容易被跳过，也是决定工作台生死的一步。
6.1 操作
录进去：最近一周的真实体重（哪怕只有 3 天）、你现在的训练安排（没有就写「每周三次，随便练」）、你昨天真实吃的三顿饭。别美化——昨天吃了炸鸡就写炸鸡。
6.2 录完你会遇到两类问题——这是好事
第一类：字段不合手。比如它要求体重精确到 0.1 公斤，但你家的秤只显示整数；比如它把「体脂率」设成必填，可你没有体脂秤。这些都要改成选填。
第二类：流程不顺手。比如每次录体重要点开「身体」页 → 点「新增」→ 选日期 → 输数字 → 保存，五步；你想的是打开就能输。
拿张便签或者开个备忘录，标题就写"工作台待改清单"。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。

本章验收：打开「身体」页，看到的是你自己过去一周真实的体重曲线，哪怕只有三个点。

7.1 迭代的三条纪律
一次只提 1~3 条。一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。
改完用一遍，再提下一轮。改动生效后至少真实使用半天，硌手的地方会自己冒出来。
提示词里带现象，别带结论。说"我点保存没反应"比说"保存功能坏了，你修一下"效果好——前者是证据，后者是让你俩一起猜。

十、数据备份（5 分钟一劳永逸，必须做）
10.1 先知道风险在哪
本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：清理浏览器缓存、卸载浏览器、重装系统时，数据会没。所以备份不是可选项。
10.2 先补上导出功能（如果你的第一版没有）

给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 健身工作台备份_20261110.json；
2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
10.3 备份的三条规矩
每次用完固定导出一次，存进 D:\我的工作台\备份。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。
换电脑、清缓存、重装系统之前，先导出。记住：清浏览器缓存 = 清空工作台，没有例外。
恢复方法：点"导入数据"，选最新的 JSON 文件，确认。数据原样回来。
