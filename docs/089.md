# 03 健身减脂与身体成长工作台 · 完整搭建 SOP

## WorkBuddy 工作台全套资料 · 第 03 篇

<p><strong>本篇是「健身减脂与身体成长工作台」的完整搭建 SOP。</strong>一句话：把体重秤上那个天天波动的数字，变成一条能看出趋势的线；把「今天该练什么」从纠结变成照做。</p>

## 一、这个工作台解决什么问题

### 1.1 先看看你有没有这三个瞬间

<p><strong>瞬间一：</strong>每天早上称体重，今天重了 0.4 公斤就心情差一天，明天轻了 0.3 又觉得有希望。一个月下来体重没变，情绪坐了三十趟过山车。</p>

<p><strong>瞬间二：</strong>办了年卡，前两周天天去，第三周开始「今天太累了明天补」，然后就没有然后了。回头看，根本不知道是哪一天断的。</p>

<p><strong>瞬间三：</strong>想减脂，教练说「控制饮食」，但「控制」到底是多少？吃了一份麻辣烫算多少？完全没数，最后靠「感觉吃得不多」安慰自己。</p>

<p>这个工作台不负责让你变瘦，它负责<strong>把「感觉」换成「数字」</strong>。减脂失败十次有九次不是不够努力，是根本不知道自己吃了多少、练了多少。</p>

### 1.2 成品长什么样：一个桌面上的小软件

<p>先说清楚最终形态，免得你搭到一半发现跟想的不一样：</p>

<p><strong>它会是你电脑桌面上的一个图标，双击就打开一个独立窗口，长得像个软件。</strong>不用联网也能用，所有数据都存在你自己电脑里，不需要注册任何账号，不需要装任何其他东西。</p>

<p>打开之后，它有四个页面，各管一件事：</p>

<table><thead><tr><th><p>页面</p></th><th><p>管什么</p></th><th><p>你什么时候打开它</p></th></tr></thead><tbody><tr><td><p>今天</p></td><td><p>今天该练什么（按周计划自动排）+ 体重录入框</p></td><td><p>每天早上</p></td></tr><tr><td><p>身体</p></td><td><p>体重、体脂、围度的趋势，重点是 7 天平均值那条线</p></td><td><p>每天早上 30 秒</p></td></tr><tr><td><p>训练</p></td><td><p>动作库 + 每次训练记录（动作/组数/重量）</p></td><td><p>每次练完</p></td></tr><tr><td><p>饮食</p></td><td><p>常吃食物的热量速查 + 当天摄入估算</p></td><td><p>每顿饭后</p></td></tr></tbody></table>

### 1.3 明确不做什么（这个比做什么更重要）

<p>第一版<strong>故意</strong>砍掉这些功能，别自己加戏：</p>

<table><thead><tr><th><p>不做的事</p></th><th><p>为什么不做</p></th></tr></thead><tbody><tr><td><p>卡路里精确到个位的饮食数据库</p></td><td><p>那需要联网查几万种食物，第一版做不到也不必要。只做「我的常吃 30 种」</p></td></tr><tr><td><p>社交打卡、好友排名</p></td><td><p>一旦要跟人比，断更就羞耻，羞耻就不敢打开</p></td></tr><tr><td><p>训练视频教学</p></td><td><p>那该去视频平台看，软件里塞视频只会变卡</p></td></tr><tr><td><p>AI 体态识别、动作纠正</p></td><td><p>需要摄像头和模型，跟「单文件本地软件」根本不兼容</p></td></tr></tbody></table>

> [!TIP]
> 💡
> <p><strong>为什么是&quot;桌面软件&quot;而不是表格？</strong>体重每天在 1 公斤范围内波动是正常的——水、盐、排便、女性生理周期都在影响它。但人眼只会看「今天比昨天重了」。软件做一件人做不到的事：<strong>算 7 天平均值</strong>。只有平均值才反映真实趋势，这一条就是它比手机备忘录强的地方。</p>

## 二、开工前的准备（10 分钟，全在你这边）

<p>正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。</p>

### 2.1 准备清单

<ol><li><strong>WorkBuddy 客户端装好、登录。</strong>没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。</li><li><strong>在电脑上建一个空文件夹。</strong>比如<code>D:\我的工作台\健身减脂</code>。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。</li><li><strong>挑一个你顺手的浏览器。</strong>Edge 或 Chrome 都行。<strong>定了就一直用它开这个软件</strong>，因为数据跟着浏览器走（原因见第十章）。</li><li><strong>准备几条真实数据</strong>（纸面想好就行，不用打字）：你最近一个月的体重（能想起几个写几个）；你现在的训练安排（或诚实的「完全没有」）；你常吃的 10 样东西。</li></ol>

> [!TIP]
> 💡
> <p><strong>唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。</strong>别用&quot;项目A、测试数据&quot;这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。</p>

### 2.2 全程你会用到的角色分工

<p>整套流程就两个角色，别搞混：</p>

<ul><li><strong>WorkBuddy：施工队。</strong>所有代码、界面、功能都是它写，你一行代码都不用碰。</li><li><strong>你：甲方 + 验收员。</strong>你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。</li></ul>

<p>这个分工意味着：<strong>SOP 里所有&quot;做&quot;的动作都是复制粘贴提示词，所有&quot;判断&quot;的动作是你亲手点一遍。</strong>哪一步跳过了&quot;自己点一遍&quot;，后面必然返工。</p>

## 三、第一步：跟 WorkBuddy 把话说清楚（提示词一）

### 3.1 开工操作

<ol><li>打开 WorkBuddy，点<strong>新建任务</strong>，模式选<strong>Agent 模式</strong>（它能自己动手建文件，别选纯问答模式）。</li><li>把<strong>工作目录</strong>设成第二章建好的那个文件夹（比如<code>D:\我的工作台\健身减脂</code>）。设错也不致命，就是文件会落别处，你得多翻一下。</li><li>在输入框粘贴下面这段提示词，回车。</li></ol>

### 3.2 提示词一：需求确认版（先别让它写代码）

```
我要做一个"健身减脂与身体成长工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。需求背景：我想减脂或增肌，但一直没成功。痛点是：体重天天波动看不出效果、不知道每天该练什么、吃了多少完全没概念、坚持两周就断。
```

### 3.3 为什么第一步是&quot;复述&quot;而不是&quot;开做&quot;

<p>你直接说&quot;帮我做个健身减脂与身体成长工作台&quot;，它会按它想象中的样子给你一个<strong>通用的</strong>东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。</p>

<p>先让它复述，等于把&quot;需求的解释权&quot;拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。</p>

### 3.4 它大概会问你什么（提前有数，答得就快）

<ul><li>&quot;要记录哪些身体数据？&quot;——体重必填，体脂和围度选填</li><li>&quot;训练计划我自己定还是软件排？&quot;——我自己定一个模板，软件按周循环</li><li>&quot;饮食要精确算卡路里吗？&quot;——不要，只估算个大概区间</li><li>&quot;要不要接运动手环？&quot;——不要，手动录就行</li><li>&quot;目标是什么？&quot;——比如三个月减 5 公斤，或增肌 3 公斤</li></ul>

<p><strong>这里出现第一个&quot;需要你输入&quot;的点：</strong>上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。</p>

## 四、第二步：让它先出方案，还是别写代码（提示词二）

### 4.1 提示词二：要一份方案

<p>需求确认完，先别放它写代码。继续粘贴：</p>

```
需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一条记录"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。方案用中文写，控制在 500 字以内，不要贴代码。
```

### 4.2 方案怎么验收：只看三样

<p>500 字方案一分钟看完，重点盯三处：</p>

<table><thead><tr><th><p>看什么</p></th><th><p>合格标准</p></th></tr></thead><tbody><tr><td><p>身体数据有趋势</p></td><td><p>体重必须有「日期 + 数值」，而且要能算 7 天平均。只存一个当前体重等于白存</p></td></tr><tr><td><p>训练有动作和组数</p></td><td><p>每次训练至少要记「做了什么动作、几组、多重」，否则下次不知道该加重量还是维持</p></td></tr><tr><td><p>饮食有常吃清单</p></td><td><p>必须有「我的常吃食物」这个自定义列表，不然每顿都要重新查</p></td></tr></tbody></table>

### 4.3 方案不满意怎么改（提示词三，通用句式）

```
方案整体可以，改三处：
1. 体重曲线画 7 天平均值线，不要只画每天的点；
2. 训练页显示每个动作上次做了多重，方便对比；
3. 把社交和排行榜相关的东西全砍掉。确认后给我更新版方案，还是不要代码。
```

> [!NOTE]
> 📌
> <p><strong>一次最多改三处。</strong>这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。</p>

## 五、第三步：生成第一版（提示词四，这次真写代码）

### 5.1 提示词四：带四条硬约束

<p>方案点头之后，粘贴这段。四条硬约束一条都别删——每一条背后都是踩过的坑：</p>

```
方案确认，开始做第一版。四条硬要求，必须全部满足：
1. 只做成一个单独的 HTML 文件，所有代码都写在这一个文件里，不要拆多个文件，不要安装任何依赖，做完我双击这个文件就能用；
2. 数据全部存在我电脑本地，刷新页面、关掉浏览器再打开，数据都不能丢；
3. 界面全中文，做得干净、字大、好点，我每天要打开好几次，别做成演示 demo 的样子；
4. 体重要能一次补录好几天的数据（我经常忘记称，周末一次性补上）
做完以后，你自己把整个软件从头到尾完整点一遍，告诉我哪里顺手、哪里会让我困惑。做完告诉我：文件叫什么名字、放在哪个文件夹。
```

### 5.2 四条硬约束分别防什么坑

<table><thead><tr><th><p>约束</p></th><th><p>防的坑</p></th></tr></thead><tbody><tr><td><p>单文件、零依赖</p></td><td><p>不拆文件就没有环境问题，双击就能开</p></td></tr><tr><td><p>数据存本地</p></td><td><p>练了三个月的数据丢了，没有人会重新开始</p></td></tr><tr><td><p>全中文、数字看得清</p></td><td><p>这个软件就是看数字的，字小了等于没用</p></td></tr><tr><td><p>支持补录</p></td><td><p>只能录今天的数据，等于逼你每天都别忘了——这不现实</p></td></tr></tbody></table>

### 5.3 第一版验收清单（5 分钟点完）

<p>WorkBuddy 做完后，去工作目录找到那个 HTML 文件，<strong>双击打开</strong>，然后逐条打勾：</p>

<ol><li>录 3 天体重，曲线出来，7 天平均值能显示</li><li>建一个训练模板（3 个动作），点「开始训练」能逐条打勾</li><li>加 3 个常吃食物，带上热量估算</li><li>关掉重开数据不丢</li><li>界面全中文，数字对齐、字够大</li></ol>

> [!TIP]
> 💡
> <p><strong>第一版只验&quot;通不通&quot;，不验&quot;好不好看&quot;。</strong>丑、慢、布局怪，都留到第七章的迭代环节统一处理。第一版就追求完美，你会陷入无止境的细节，搭不完。</p>

## 六、第四步：把真实数据喂进去（决定它是玩具还是工具）

<p>验收通过别急着庆祝。<strong>这一步最容易被跳过，也是决定工作台生死的一步。</strong></p>

### 6.1 操作

<p>录进去：最近一周的真实体重（哪怕只有 3 天）、你现在的训练安排（没有就写「每周三次，随便练」）、你昨天真实吃的三顿饭。别美化——昨天吃了炸鸡就写炸鸡。</p>

### 6.2 录完你会遇到两类问题——这是好事

<p><strong>第一类：字段不合手。</strong>比如它要求体重精确到 0.1 公斤，但你家的秤只显示整数；比如它把「体脂率」设成必填，可你没有体脂秤。这些都要改成选填。</p>

<p><strong>第二类：流程不顺手。</strong>比如每次录体重要点开「身体」页 → 点「新增」→ 选日期 → 输数字 → 保存，五步；你想的是打开就能输。</p>

<p>拿张便签或者开个备忘录，标题就写&quot;工作台待改清单&quot;。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。</p>

> [!NOTE]
> 🎯
> <p><strong>本章验收：</strong>打开「身体」页，看到的是你自己过去一周真实的体重曲线，哪怕只有三个点。</p>

## 七、第五步：迭代优化（8 条现成提示词，抄就完了）

<p>迭代不靠灵感，靠&quot;用的时候哪里硌手&quot;。第六章攒的&quot;待改清单&quot;就是原料。以下 8 条覆盖这个工作台最常见的问题，直接抄，方括号里的换成你的情况：</p>

<table><thead><tr><th><p>哪里硌手</p></th><th><p>直接抄的提示词</p></th><th><p>改完怎么验</p></th></tr></thead><tbody><tr><td><p>录体重太绕</p></td><td><p>首页顶部直接放一个体重输入框，打开就能输，输完自动存今天的日期</p></td><td><p>打开→输数字→回车，3 秒</p></td></tr><tr><td><p>看不出趋势</p></td><td><p>体重曲线除了每日的点，再画一条 7 天平均的粗线，用不同颜色区分</p></td><td><p>两条线能分清</p></td></tr><tr><td><p>不知道怎么练</p></td><td><p>训练页加「今天练什么」卡片，按我设的周计划自动显示，点一下直接开始</p></td><td><p>每天打开有答案</p></td></tr><tr><td><p>忘记上次多重</p></td><td><p>每个动作旁边显示「上次：XX kg × XX 组」</p></td><td><p>一眼看到</p></td></tr><tr><td><p>吃多了有负罪感</p></td><td><p>饮食页改成只记估算区间（少/正常/多），不要精确数字，也别用红色警告</p></td><td><p>记起来没压力</p></td></tr><tr><td><p>想看围度变化</p></td><td><p>加腰围、胸围、臂围三个可选字段，能画趋势</p></td><td><p>能录能看</p></td></tr><tr><td><p>断了两周想重启</p></td><td><p>加一个「重新开始」按钮，把断更期标成灰色，但不显示「失败」字样</p></td><td><p>点了不羞耻</p></td></tr><tr><td><p>想导出给教练看</p></td><td><p>加一个「导出最近 30 天」按钮，生成一段可复制的文字总结</p></td><td><p>复制得出来</p></td></tr></tbody></table>

### 7.1 迭代的三条纪律

<ul><li><strong>一次只提 1~3 条。</strong>一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。</li><li><strong>改完用一遍，再提下一轮。</strong>改动生效后至少真实使用半天，硌手的地方会自己冒出来。</li><li><strong>提示词里带现象，别带结论。</strong>说&quot;我点保存没反应&quot;比说&quot;保存功能坏了，你修一下&quot;效果好——前者是证据，后者是让你俩一起猜。</li></ul>

## 八、第六步：装到桌面（让它看起来像个软件）

<p>现在它还只是个 HTML 文件，打开方式是&quot;找到文件 → 双击 → 浏览器里开一个标签页&quot;。这一章把它变成桌面上真正意义的&quot;软件图标&quot;。</p>

### 8.1 三种方式对比

## 十、数据备份（5 分钟一劳永逸，必须做）

### 10.1 先知道风险在哪

<p>本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：<strong>清理浏览器缓存、卸载浏览器、重装系统时，数据会没。</strong>所以备份不是可选项。</p>

### 10.2 先补上导出功能（如果你的第一版没有）

```
给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 健身工作台备份_20261110.json；2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
```

### 10.3 备份的三条规矩

<ol><li><strong>每次用完固定导出一次</strong>，存进<code>D:\我的工作台\备份</code>。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。</li><li><strong>换电脑、清缓存、重装系统之前，先导出。</strong>记住：清浏览器缓存 = 清空工作台，没有例外。</li><li><strong>恢复方法：</strong>点&quot;导入数据&quot;，选最新的 JSON 文件，确认。数据原样回来。</li></ol>

## 十一、进阶：让 WorkBuddy 继续替你干活

<p>软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：</p>

### 11.1 让它当你的训练教练

<p>训练记录攒够四周，它比你自己更能看出问题。</p>

```
这是我最近 4 周的训练记录和体重数据（粘贴）。请分析：
1. 我的训练频率和容量够不够；
2. 哪些动作的重量两个月没变过（说明没进步）；3. 下周给我一个具体调整方案，写清动作、组数、重量。
```

### 11.2 饮食拍照估算

<p>不用称重、不用查表，拍完给它看。</p>

```
这是我今天三顿饭的照片（附图）。请估算每顿的热量和蛋白质大概在什么区间，并告诉我今天最该补的是什么。不用精确到个位，给区间就行。
```

### 11.3 平台期诊断

<p>体重卡住是每个人都会遇到的，关键是判断原因。</p>

```
我体重已经 3 周没变化了，这是我的训练和饮食记录（粘贴）。请列出最可能的三个原因，按可能性排序，每个原因给我一个下周就能验证的方法。
```

<p><strong>注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。</strong>这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。</p>
