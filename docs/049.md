# WorkBuddy 提问与任务描述指南

WorkBuddy 提问与任务描述指南

技巧一：表达清晰——给虾确切的、可执行的任务
错误示范

"帮我写个报告"
写什么报告？关于什么数据？给谁看？什么格式？
WorkBuddy不是你肚子里的蛔虫，你说"写个报告"，它只能猜。猜对了你运气好，猜错了你觉得AI不行。
正确示范

"打开桌面上的'Q2销售数据.xlsx'，按区域汇总销售额，生成一份给部门经理看的分析报告，用Word格式，包含数据表格和趋势图。"
看到区别了吗？

好的指令 = 对象 + 动作 + 规则 + 输出格式

一个万能模板：

"Take [文件夹/文件]，apply [规则/条件]，do [具体动作]，输出为[格式]"

再举几个例子：
❌ "帮我整理文件" → ✅ "把桌面Downloads文件夹里的文件按类型分类，图片放'图片'文件夹，文档放'文档'文件夹，超过100MB的文件单独放'大文件'文件夹"
❌ "写个邮件" → ✅ "给张经理写一封邮件，主题是本周项目进度汇报，内容包含：本周完成3个模块开发、下周计划、需要协调的资源，语气正式但不生硬"
❌ "分析一下数据" → ✅ "打开'2026年Q1财务.xlsx'，计算每个月的环比增长率，标出增长超过20%的月份，生成柱状图"

记住：你描述得越具体，WorkBuddy干得越漂亮。
就像你去餐厅点菜，"来个菜"和"来一份微辣的宫保鸡丁，少放花生多放鸡肉"，出菜质量能一样吗？

技巧二：拆解大任务——把大象装冰箱分三步
错误示范

"帮我做一个季度总结报告"
这个任务太大了。WorkBuddy收到这么大的指令，要么一口气输出一个粗糙的大杂烩，要么中间卡壳不知道从哪下手。

正确示范
把大任务拆成小步骤，一步一步来：

第一步： "打开'Q1销售数据.xlsx'，按产品线汇总各月销售额，计算环比增长率"
第二步： "根据刚才的数据，生成折线图和柱状图，折线图展示趋势，柱状图展示对比"
第三步： "根据数据分析结果，撰写总结：哪些产品线增长强劲、哪些需要关注、Q2的建议方向"
第四步： "把上面的内容整合成一份Word报告，加上封面页、目录、图表、结论，排版整洁"

每一步都是独立的、可执行的、有明确产出的。
这个思路的核心是：让AI在每一步都能给你一个明确的产出，你在每一步都能检查对不对。
错了就调整，对了就继续。比起"一口气生成整份报告"，这种方式出错率低得多，最终质量也高得多。

工作中其他大任务也一样：
"做一个项目方案" → 调研需求 → 列功能清单 → 写技术方案 → 画架构图 → 排版输出
"写一篇文章" → 确定主题 → 列大纲 → 写各段 → 润色修改 → 排版配图
"做一个数据分析" → 清洗数据 → 描述性统计 → 找异常值 → 深入分析 → 出报告
大任务不可怕，拆成小块就变简单了。

技巧三：多轮对话——别指望一次说清
很多人的使用方式
打开WorkBuddy，噼里啪啦打一大段话，发出去，等结果。结果不满意？关掉，下次再试。
这是最大的浪费。
AI对话不是搜索引擎，不是你输入一次关键词就完了。它更像和一个聪明的新同事合作——你得来回沟通，逐步把需求说清楚。

正确的多轮使用方式
第一轮：出草稿

"帮我写一段产品介绍，关于我们的智能客服系统，面向中小企业客户"
WorkBuddy给了你一个初稿。可能方向对，但细节不够。
第二轮：调整方向

"不错，但语气太正式了，改成轻松亲切的风格。另外在'降本增效'这个点上多展开一些，加一个具体数据"
第三轮：精修细节

"很好了，最后再帮我检查一下：有没有重复的表述？标题能不能更吸引人？结尾加一个行动号召"
三轮下来，输出质量比第一轮直接好3倍。

多轮对话的精髓是：先出框架，再填内容，最后打磨细节。
这个过程就像雕刻——先粗凿出形状，再精雕细琢，最后抛光。你不能要求一块石头一步到位变成艺术品。

技巧四：先本地后远程——信任是慢慢建立的
这是什么意思？
WorkBuddy可以连接很多外部工具：tx文档、扣扣邮箱、浏览器、文件系统……但不要一上来就让它操作你的远程资源。

正确的做法
第一步：先在本地小范围试

"帮我整理一下桌面的文件"
如果效果好，你对它的能力有了信心。
第二步：扩大到本地复杂任务

"帮我分析桌面上这个Excel文件的数据"
没问题，你更信任它了。
第三步：再连接远程资源

"帮我连接tx文档，读取'团队周报'表格，把本周的数据整理成一份报告"
第四步：自动化

"每周五下午5点，自动从tx文档拉取本周数据，生成周报初稿，发到我的邮箱"
这就是渐进式信任。
就像你刚认识一个新同事，第一天不会把所有密码告诉他。先让他做简单的事，靠谱了再逐步放权。
AI也一样。先小任务建立信任，再大任务发挥价值，最后自动化解放双手。

总结：四个技巧，一个核心

核心就一句话：把AI当成一个能力很强但需要你引导的新同事。
你不会对新同事说"你看着办吧"，你会告诉他具体要做什么、做到什么程度、遇到问题怎么办。
WorkBuddy也是一样。你引导得越好，它发挥的价值越大。
