WorkBuddy 工作台全套资料 · 第 02 篇
本篇是「个人成长与目标管理工作台」的完整搭建 SOP。一句话：把你年初立的那一堆目标，变成每天早上能看见、每周会被追问进度的东西。

没做过 01 篇（职场办公）的建议先看那一篇。五步流程在那边讲得最细，这一篇直接按同样的节奏走，重点看差异化部分。
一、这个工作台解决什么问题
1.1 先看看你有没有这三个瞬间
瞬间一：元旦写下的年度目标清单，三月份就找不到了。年底复盘，发现「读书 50 本」实际读了 3 本，中间到底发生了什么，完全想不起来。
瞬间二：想提升的方向太多——英语、健身、写作、考证，每个都在做一点，年底一看每个都停在第一周。
瞬间三：每周日晚上想复盘，但完全想不起这周做了什么，只能凭感觉给自己打个「还行」。
这个工作台不负责激励你，它只负责把目标和进度摆在你眼前。真正让人放弃目标的不是懒，是「看不见进度」。

为什么是"桌面软件"而不是表格？成长这件事最怕延迟反馈——你努力三个月看不见变化，就会怀疑自己。软件的作用是把这个延迟缩短：每周一次复盘，把「我好像什么也没做」变成「我这周确实推进了这 3 件事」。表格做不到，因为它不会主动跳到眼前。
二、开工前的准备（10 分钟，全在你这边）
正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。
2.1 准备清单
WorkBuddy 客户端装好、登录。没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。
在电脑上建一个空文件夹。比如 D:\我的工作台\个人成长。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。
挑一个你顺手的浏览器。Edge 或 Chrome 都行。定了就一直用它开这个软件，因为数据跟着浏览器走（原因见第十章）。
准备几条真实数据（纸面想好就行，不用打字）：你的年度目标（能想起来的那 3-5 条）；这周你实际做了什么（3 条）；你最想改掉的 1 个毛病。

唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。别用"项目A、测试数据"这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。
2.2 全程你会用到的角色分工
整套流程就两个角色，别搞混：
WorkBuddy：施工队。所有代码、界面、功能都是它写，你一行代码都不用碰。
你：甲方 + 验收员。你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。
这个分工意味着：SOP 里所有"做"的动作都是复制粘贴提示词，所有"判断"的动作是你亲手点一遍。哪一步跳过了"自己点一遍"，后面必然返工。
三、第一步：跟 WorkBuddy 把话说清楚（提示词一）
3.1 开工操作
打开 WorkBuddy，点新建任务，模式选 Agent 模式（它能自己动手建文件，别选纯问答模式）。
把工作目录设成第二章建好的那个文件夹（比如 D:\我的工作台\个人成长）。设错也不致命，就是文件会落别处，你得多翻一下。
在输入框粘贴下面这段提示词，回车。
3.2 提示词一：需求确认版（先别让它写代码）

我要做一个"个人成长与目标管理工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。
需求背景：我是上班族，每年年初都会定目标，但基本都没完成过。痛点是：定完就忘、目标太多不知道先做哪个、每周想复盘但想不起这周干了什么。
3.3 为什么第一步是"复述"而不是"开做"
你直接说"帮我做个个人成长与目标管理工作台"，它会按它想象中的样子给你一个通用的东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。
先让它复述，等于把"需求的解释权"拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。
3.4 它大概会问你什么（提前有数，答得就快）
"目标要分年度还是长期？"——先年度，再按季度拆
"每个目标要不要量化？"——要，但允许填完成度百分比，而不是硬性数字
"复盘要不要固定模板？"——要，就三句话
"要不要提醒？"——打开软件能看到「该复盘了」就够
"完成度怎么更新？"——我每周复盘时手动改一次
这里出现第一个"需要你输入"的点：上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。
四、第二步：让它先出方案，还是别写代码（提示词二）
4.1 提示词二：要一份方案
需求确认完，先别放它写代码。继续粘贴：

需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一条记录"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。
方案用中文写，控制在 500 字以内，不要贴代码。
4.2 方案怎么验收：只看三样
500 字方案一分钟看完，重点盯三处：

看什么

合格标准

目标清单在不在

每条目标要有「完成度百分比」和「所属季度」两个字段。没有这两个，你不知道自己做到哪了

季度拆解有没有

一个目标必须能拆成 3 件具体的事，否则它永远只是个愿望

周复盘有没有模板

三句话：做成了什么 / 卡在哪 / 下周最重要的一件事
4.3 方案不满意怎么改（提示词三，通用句式）

方案整体可以，改三处：
1. 目标列表按季度分组，正在推进的排最上面；
2. 周复盘加一个「连续复盘周数」计数；
3. 把图表砍掉，只留四个数字卡片。
确认后给我更新版方案，还是不要代码。

一次最多改三处。这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。
五、第三步：生成第一版（提示词四，这次真写代码）
5.1 提示词四：带四条硬约束
方案点头之后，粘贴这段。四条硬约束一条都别删——每一条背后都是踩过的坑：

方案确认，开始做第一版。四条硬要求，必须全部满足：
1. 只做成一个单独的 HTML 文件，所有代码都写在这一个文件里，不要拆多个文件，不要安装任何依赖，做完我双击这个文件就能用；
2. 数据全部存在我电脑本地，刷新页面、关掉浏览器再打开，数据都不能丢；

六、第四步：把真实数据喂进去（决定它是玩具还是工具）
验收通过别急着庆祝。这一步最容易被跳过，也是决定工作台生死的一步。
6.1 操作
把第二章纸面想的三样东西亲手录进去：3-5 条年度目标（写上你真实的完成度，哪怕只有 10）、这周实际做的 3 件事写成第一条周复盘、那个你最想改的毛病单独记一条。慢一点没关系，20 分钟足够。
6.2 录完你会遇到两类问题——这是好事
第一类：字段不合手。比如它设计的完成度是填数字，但你想按五个阶段点选（没开始/起步/过半/收尾/完成）；比如它要求每条目标写「衡量标准」，可你根本还没想清楚。这些都要记下来。
第二类：流程不顺手。比如写周复盘要点「新建」再选「周」再填日期，三步太绕；比如打开软件默认进「目标」页，可你每天想看的是仪表盘。
拿张便签或者开个备忘录，标题就写"工作台待改清单"。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。

本章验收：打开软件，第一屏能看到你自己的真实目标、真实的完成度。哪怕有些目标只有 5%，那也比「目标A 50%」有用一万倍。

7.1 迭代的三条纪律
一次只提 1~3 条。一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。
改完用一遍，再提下一轮。改动生效后至少真实使用半天，硌手的地方会自己冒出来。
提示词里带现象，别带结论。说"我点保存没反应"比说"保存功能坏了，你修一下"效果好——前者是证据，后者是让你俩一起猜。

十、数据备份（5 分钟一劳永逸，必须做）
10.1 先知道风险在哪
本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：清理浏览器缓存、卸载浏览器、重装系统时，数据会没。所以备份不是可选项。
10.2 先补上导出功能（如果你的第一版没有）

给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 成长工作台备份_20261110.json；
2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
10.3 备份的三条规矩
每次用完固定导出一次，存进 D:\我的工作台\备份。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。
换电脑、清缓存、重装系统之前，先导出。记住：清浏览器缓存 = 清空工作台，没有例外。
恢复方法：点"导入数据"，选最新的 JSON 文件，确认。数据原样回来。
十一、进阶：让 WorkBuddy 继续替你干活
软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：
11.1 让它当周复盘教练
写完三句话，把内容发给 WorkBuddy，让它追问——自己复盘容易自我安慰。

这是我本周的复盘：……（粘贴）。请你像教练一样，只做三件事：
1. 指出我这周最大的一个自我安慰；
2. 判断我卡住的地方是方法问题还是意愿问题；
3. 给我下周一个具体到「做什么、做多久」的建议。
不要说套话。
11.2 目标合理性体检
年初定的目标，往往自己看不出问题。

这是我的年度目标清单（粘贴）。请帮我判断：
1. 哪些目标之间在互相抢时间；
2. 哪几条其实不是目标，是愿望；
3. 如果只能保留三条，你建议留哪三条，为什么。
11.3 年度回顾代写
52 条周复盘，你自己拼不动，它一分钟搞定。

这是我全年 52 条周复盘（粘贴导出内容）。帮我写一份 1000 字以内的年度回顾，分三部分：今年真正推进了什么 / 哪些目标该放弃 / 明年建议只做什么。语气平实，不要励志腔。
注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。
十二、常见问题快答

问题

答案

数据会上传到云上吗？

本地版不会，数据就在你电脑的浏览器里，断网照常用

换个浏览器打开，数据还在吗？

不在。数据跟浏览器走，固定用一个浏览器开

能多人一起用吗？

本地版不能。这是给你自己用的私人工具

做出来的东西太简陋？

不是软件的问题，是提示词的问题。回第七章一条条提

断电、关机丢数据吗？

不丢，数据在硬盘上。丢数据的只有「清浏览器缓存」

能给软件加 AI 功能吗？

纯本地文件里没有 AI。AI 走 WorkBuddy 对话（第十一章）

我想改字段、加页面？

直接提，参考第七章句式。一次别超过 3 条

HTML 文件被我删了？

让 WorkBuddy 按原提示词重新生成，五分钟的事；数据在浏览器里不受影响

能不能加习惯打卡？

建议不要。打卡断一次就整盘弃，这是这类软件最常见的死法。想打卡用手机自带提醒
