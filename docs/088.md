# 02 个人成长与目标管理工作台 · 完整搭建 SOP

## WorkBuddy 工作台全套资料 · 第 02 篇

<p><strong>本篇是「个人成长与目标管理工作台」的完整搭建 SOP。</strong>一句话：把你年初立的那一堆目标，变成每天早上能看见、每周会被追问进度的东西。</p>

> [!NOTE]
> 📌
> <p><strong>没做过 01 篇（职场办公）的建议先看那一篇。</strong>五步流程在那边讲得最细，这一篇直接按同样的节奏走，重点看差异化部分。</p>

## 一、这个工作台解决什么问题

### 1.1 先看看你有没有这三个瞬间

<p><strong>瞬间一：</strong>元旦写下的年度目标清单，三月份就找不到了。年底复盘，发现「读书 50 本」实际读了 3 本，中间到底发生了什么，完全想不起来。</p>

<p><strong>瞬间二：</strong>想提升的方向太多——英语、健身、写作、考证，每个都在做一点，年底一看每个都停在第一周。</p>

<p><strong>瞬间三：</strong>每周日晚上想复盘，但完全想不起这周做了什么，只能凭感觉给自己打个「还行」。</p>

<p>这个工作台不负责激励你，它只负责<strong>把目标和进度摆在你眼前</strong>。真正让人放弃目标的不是懒，是「看不见进度」。</p>

### 1.2 成品长什么样：一个桌面上的小软件

<p>先说清楚最终形态，免得你搭到一半发现跟想的不一样：</p>

<p><strong>它会是你电脑桌面上的一个图标，双击就打开一个独立窗口，长得像个软件。</strong>不用联网也能用，所有数据都存在你自己电脑里，不需要注册任何账号，不需要装任何其他东西。</p>

<p>打开之后，它有四个页面，各管一件事：</p>

<table><thead><tr><th><p>页面</p></th><th><p>管什么</p></th><th><p>你什么时候打开它</p></th></tr></thead><tbody><tr><td><p>目标</p></td><td><p>年度/季度目标清单，每条带完成度百分比</p></td><td><p>每季度初看一眼，感到迷茫的时候看</p></td></tr><tr><td><p>季度拆解</p></td><td><p>一个目标拆成本季度要交的 3 件具体事</p></td><td><p>每季度第一天</p></td></tr><tr><td><p>周复盘</p></td><td><p>每周三句话：做成了什么、卡在哪、下周最重要的一件事</p></td><td><p>每周日晚上</p></td></tr><tr><td><p>仪表盘</p></td><td><p>四个数字：目标总数、推进中、已完成、连续复盘周数</p></td><td><p>每天早上扫一眼</p></td></tr></tbody></table>

### 1.3 明确不做什么（这个比做什么更重要）

<p>第一版<strong>故意</strong>砍掉这些功能，别自己加戏：</p>

<table><thead><tr><th><p>不做的事</p></th><th><p>为什么不做</p></th></tr></thead><tbody><tr><td><p>习惯打卡那种每天点一下的功能</p></td><td><p>打卡是最容易断的东西，断了就整盘弃用。只做目标和复盘，不做打卡</p></td></tr><tr><td><p>番茄钟、待办清单</p></td><td><p>那些是别的软件擅长的，混进来会分散注意力</p></td></tr><tr><td><p>社交、排行榜、组队监督</p></td><td><p>一旦涉及别人，就要处理「今天没脸见人」的羞耻感，反而不敢打开</p></td></tr><tr><td><p>复杂的图表</p></td><td><p>第一版四个数字够了。图表看多了，会变成「看数据」而不是「做事」</p></td></tr></tbody></table>

> [!TIP]
> 💡
> <p><strong>为什么是&quot;桌面软件&quot;而不是表格？</strong>成长这件事最怕延迟反馈——你努力三个月看不见变化，就会怀疑自己。软件的作用是把这个延迟缩短：每周一次复盘，把「我好像什么也没做」变成「我这周确实推进了这 3 件事」。表格做不到，因为它不会主动跳到眼前。</p>

## 二、开工前的准备（10 分钟，全在你这边）

<p>正式开始前，把下面四样备齐。前三样是死要求，第四样需要你动点脑子。</p>

### 2.1 准备清单

<ol><li><strong>WorkBuddy 客户端装好、登录。</strong>没装的到官网下载，桌面端或网页版都行，本教程以桌面端为准。</li><li><strong>在电脑上建一个空文件夹。</strong>比如<code>D:\我的工作台\个人成长</code>。这是 WorkBuddy 干活的地方，它生成的文件都会落在这里，别用 C 盘根目录或桌面，乱。</li><li><strong>挑一个你顺手的浏览器。</strong>Edge 或 Chrome 都行。<strong>定了就一直用它开这个软件</strong>，因为数据跟着浏览器走（原因见第十章）。</li><li><strong>准备几条真实数据</strong>（纸面想好就行，不用打字）：你的年度目标（能想起来的那 3-5 条）；这周你实际做了什么（3 条）；你最想改掉的 1 个毛病。</li></ol>

> [!TIP]
> 💡
> <p><strong>唯一需要你动脑的就是第四条，但它是全套流程里最不能省的一步。</strong>别用&quot;项目A、测试数据&quot;这种假东西——第一天就往里塞真内容，它才会真的帮你记事。用假数据搭出来的软件，归宿都是三天弃坑。</p>

### 2.2 全程你会用到的角色分工

<p>整套流程就两个角色，别搞混：</p>

<ul><li><strong>WorkBuddy：施工队。</strong>所有代码、界面、功能都是它写，你一行代码都不用碰。</li><li><strong>你：甲方 + 验收员。</strong>你负责说清楚要什么、检查它做出来的东西顺不顺手、决定下一步改什么。</li></ul>

<p>这个分工意味着：<strong>SOP 里所有&quot;做&quot;的动作都是复制粘贴提示词，所有&quot;判断&quot;的动作是你亲手点一遍。</strong>哪一步跳过了&quot;自己点一遍&quot;，后面必然返工。</p>

## 三、第一步：跟 WorkBuddy 把话说清楚（提示词一）

### 3.1 开工操作

<ol><li>打开 WorkBuddy，点<strong>新建任务</strong>，模式选<strong>Agent 模式</strong>（它能自己动手建文件，别选纯问答模式）。</li><li>把<strong>工作目录</strong>设成第二章建好的那个文件夹（比如<code>D:\我的工作台\个人成长</code>）。设错也不致命，就是文件会落别处，你得多翻一下。</li><li>在输入框粘贴下面这段提示词，回车。</li></ol>

### 3.2 提示词一：需求确认版（先别让它写代码）

```
我要做一个"个人成长与目标管理工作台"，一个本地网页小软件，做完我会放在桌面双击打开用。在动手之前，你先不要写代码，只做两件事：
1. 用你自己的话复述一遍你理解的需求，列出来给我确认；
2. 针对我没说清楚的地方，一次性问我 5 个以内的问题，我答完你再往下走。需求背景：我是上班族，每年年初都会定目标，但基本都没完成过。痛点是：定完就忘、目标太多不知道先做哪个、每周想复盘但想不起这周干了什么。
```

### 3.3 为什么第一步是&quot;复述&quot;而不是&quot;开做&quot;

<p>你直接说&quot;帮我做个个人成长与目标管理工作台&quot;，它会按它想象中的样子给你一个<strong>通用的</strong>东西——很多功能你用不上，你真正要的它又没做，返工都是从这里开始的。</p>

<p>先让它复述，等于把&quot;需求的解释权&quot;拿回自己手里。它复述歪了，你当场纠正，成本是一句话；做完才发现歪了，成本是重来一遍。</p>

### 3.4 它大概会问你什么（提前有数，答得就快）

<ul><li>&quot;目标要分年度还是长期？&quot;——先年度，再按季度拆</li><li>&quot;每个目标要不要量化？&quot;——要，但允许填完成度百分比，而不是硬性数字</li><li>&quot;复盘要不要固定模板？&quot;——要，就三句话</li><li>&quot;要不要提醒？&quot;——打开软件能看到「该复盘了」就够</li><li>&quot;完成度怎么更新？&quot;——我每周复盘时手动改一次</li></ul>

<p><strong>这里出现第一个&quot;需要你输入&quot;的点：</strong>上面这几个答案是我给的参考版本，你照抄能跑通，但最好按自己的真实情况改。这几句话，就是你这个工作台和别人的不一样的地方。</p>

## 四、第二步：让它先出方案，还是别写代码（提示词二）

### 4.1 提示词二：要一份方案

<p>需求确认完，先别放它写代码。继续粘贴：</p>

```
需求确认了。现在还是不要写代码。请先给我一份搭建方案，包含四部分：
1. 页面结构：这个软件一共几个页面，每个页面放什么内容；
2. 数据结构：需要存哪些数据，每条数据有哪些字段；
3. 核心操作路径：我日常用它的 3 条主要流程（比如"新建一条记录"从哪点到哪）；
4. 你建议砍掉的功能：哪些听起来有用但第一版不该做。方案用中文写，控制在 500 字以内，不要贴代码。
```

### 4.2 方案怎么验收：只看三样

<p>500 字方案一分钟看完，重点盯三处：</p>

<table><thead><tr><th><p>看什么</p></th><th><p>合格标准</p></th></tr></thead><tbody><tr><td><p>目标清单在不在</p></td><td><p>每条目标要有「完成度百分比」和「所属季度」两个字段。没有这两个，你不知道自己做到哪了</p></td></tr><tr><td><p>季度拆解有没有</p></td><td><p>一个目标必须能拆成 3 件具体的事，否则它永远只是个愿望</p></td></tr><tr><td><p>周复盘有没有模板</p></td><td><p>三句话：做成了什么 / 卡在哪 / 下周最重要的一件事</p></td></tr></tbody></table>

### 4.3 方案不满意怎么改（提示词三，通用句式）

```
方案整体可以，改三处：
1. 目标列表按季度分组，正在推进的排最上面；
2. 周复盘加一个「连续复盘周数」计数；
3. 把图表砍掉，只留四个数字卡片。确认后给我更新版方案，还是不要代码。
```

> [!NOTE]
> 📌
> <p><strong>一次最多改三处。</strong>这不是规矩是经验：改的条数越多，每一处改得越潦草，而且你回头都验不了。</p>

## 五、第三步：生成第一版（提示词四，这次真写代码）

### 5.1 提示词四：带四条硬约束

<p>方案点头之后，粘贴这段。四条硬约束一条都别删——每一条背后都是踩过的坑：</p>

```
方案确认，开始做第一版。四条硬要求，必须全部满足：
1. 只做成一个单独的 HTML 文件，所有代码都写在这一个文件里，不要拆多个文件，不要安装任何依赖，做完我双击这个文件就能用；
2. 数据全部存在我电脑本地，刷新页面、关掉浏览器再打开，数据都不能丢；
3. 界面全中文，做得干净、字大、好点，我每天要打开好几次，别做成演示 demo 的样子；
4. 周复盘要能记住我上一次写的内容，打开就显示上周写的，方便我接着往下写
做完以后，你自己把整个软件从头到尾完整点一遍，告诉我哪里顺手、哪里会让我困惑。做完告诉我：文件叫什么名字、放在哪个文件夹。
```

### 5.2 四条硬约束分别防什么坑

<table><thead><tr><th><p>约束</p></th><th><p>防的坑</p></th></tr></thead><tbody><tr><td><p>单文件、零依赖</p></td><td><p>不拆文件就没有环境问题，双击就能开</p></td></tr><tr><td><p>数据存本地</p></td><td><p>数据丢失是这类工具的第一死因</p></td></tr><tr><td><p>全中文、不做 demo 样</p></td><td><p>每天开好几次的东西，丑一点你就懒得开了</p></td></tr><tr><td><p>复盘能接上一次</p></td><td><p>每周从空白框开始写，是最容易放弃的环节</p></td></tr></tbody></table>

### 5.3 第一版验收清单（5 分钟点完）

<p>WorkBuddy 做完后，去工作目录找到那个 HTML 文件，<strong>双击打开</strong>，然后逐条打勾：</p>

<ol><li>建一个目标，完成度填 30，关掉浏览器重开，数字还在</li><li>写一条周复盘，保存后能在列表里看到</li><li>仪表盘的「连续复盘周数」能正确加 1</li><li>界面全中文，没有乱码、没有英文残留</li><li>四个页面都点得开，没有点了没反应的按钮</li></ol>

> [!TIP]
> 💡
> <p><strong>第一版只验&quot;通不通&quot;，不验&quot;好不好看&quot;。</strong>丑、慢、布局怪，都留到第七章的迭代环节统一处理。第一版就追求完美，你会陷入无止境的细节，搭不完。</p>

## 六、第四步：把真实数据喂进去（决定它是玩具还是工具）

<p>验收通过别急着庆祝。<strong>这一步最容易被跳过，也是决定工作台生死的一步。</strong></p>

### 6.1 操作

<p>把第二章纸面想的三样东西亲手录进去：3-5 条年度目标（写上你真实的完成度，哪怕只有 10）、这周实际做的 3 件事写成第一条周复盘、那个你最想改的毛病单独记一条。慢一点没关系，20 分钟足够。</p>

### 6.2 录完你会遇到两类问题——这是好事

<p><strong>第一类：字段不合手。</strong>比如它设计的完成度是填数字，但你想按五个阶段点选（没开始/起步/过半/收尾/完成）；比如它要求每条目标写「衡量标准」，可你根本还没想清楚。这些都要记下来。</p>

<p><strong>第二类：流程不顺手。</strong>比如写周复盘要点「新建」再选「周」再填日期，三步太绕；比如打开软件默认进「目标」页，可你每天想看的是仪表盘。</p>

<p>拿张便签或者开个备忘录，标题就写&quot;工作台待改清单&quot;。这个清单会持续好几天，你每次用它觉得硌手就添一条，攒够了再让 WorkBuddy 一次改。</p>

> [!NOTE]
> 🎯
> <p><strong>本章验收：</strong>打开软件，第一屏能看到你自己的真实目标、真实的完成度。哪怕有些目标只有 5%，那也比「目标A 50%」有用一万倍。</p>

## 七、第五步：迭代优化（8 条现成提示词，抄就完了）

<p>迭代不靠灵感，靠&quot;用的时候哪里硌手&quot;。第六章攒的&quot;待改清单&quot;就是原料。以下 8 条覆盖这个工作台最常见的问题，直接抄，方括号里的换成你的情况：</p>

<table><thead><tr><th><p>哪里硌手</p></th><th><p>直接抄的提示词</p></th><th><p>改完怎么验</p></th></tr></thead><tbody><tr><td><p>输入太麻烦</p></td><td><p>周复盘改成：打开就直接是一个空文本框，三段标题已经预填好，我只管往下写，写完点保存</p></td><td><p>打开就是能写字的状态</p></td></tr><tr><td><p>完成度懒得改</p></td><td><p>目标列表每一行加一个滑块，拖动就改完成度，不用点进去编辑</p></td><td><p>拖一下数字立刻变</p></td></tr><tr><td><p>看不出这季度该干啥</p></td><td><p>加一个「本季度」页面，只显示这三个月的目标和拆解出来的具体事</p></td><td><p>打开只看到 3 件事</p></td></tr><tr><td><p>忘了要复盘</p></td><td><p>每周日晚上 8 点后第一次打开，顶部横幅提示：本周还没复盘，已连续 X 周</p></td><td><p>改系统时间验证</p></td></tr><tr><td><p>目标太多</p></td><td><p>目标超过 5 条时，提示「建议只保留 3 条在推进中」，其余自动折叠</p></td><td><p>建 8 条试试</p></td></tr><tr><td><p>年终想看看</p></td><td><p>加一个「年度回顾」按钮，把所有周复盘按时间顺序拼成一份可复制的长文</p></td><td><p>点一下出全文</p></td></tr><tr><td><p>界面太花</p></td><td><p>整体改成极简风，白底黑字，只保留完成度用颜色区分</p></td><td><p>看着安静</p></td></tr><tr><td><p>想记录为什么没做到</p></td><td><p>周复盘的「卡在哪」后面加一个下拉：没时间/不会做/不想做/被别的打断</p></td><td><p>能选了</p></td></tr></tbody></table>

### 7.1 迭代的三条纪律

<ul><li><strong>一次只提 1~3 条。</strong>一次丢十条过去，它改出来的东西你自己都验不过来，坏一处你还不知道是哪条改坏的。</li><li><strong>改完用一遍，再提下一轮。</strong>改动生效后至少真实使用半天，硌手的地方会自己冒出来。</li><li><strong>提示词里带现象，别带结论。</strong>说&quot;我点保存没反应&quot;比说&quot;保存功能坏了，你修一下&quot;效果好——前者是证据，后者是让你俩一起猜。</li></ul>

## 八、第六步：装到桌面（让它看起来像个软件）

<p>现在它还只是个 HTML 文件，打开方式是&quot;找到文件 → 双击 → 浏览器里开一个标签页&quot;。这一章把它变成桌面上真正意义的&quot;软件图标&quot;。</p>

### 8.1 三种方式对比

## 十、数据备份（5 分钟一劳永逸，必须做）

### 10.1 先知道风险在哪

<p>本地版的数据存在你电脑的浏览器里（技术上叫 localStorage）。正常开关机、断网都不会丢。真正的风险只有一个：<strong>清理浏览器缓存、卸载浏览器、重装系统时，数据会没。</strong>所以备份不是可选项。</p>

### 10.2 先补上导出功能（如果你的第一版没有）

```
给软件加两个功能：
1. 右上角一个"导出数据"按钮，把全部数据下载成一个 JSON 文件，文件名自动带当天日期，比如 成长工作台备份_20261110.json；2. 一个"导入数据"按钮，选择 JSON 文件后完整恢复，导入前弹窗让我确认，防止覆盖错。
```

### 10.3 备份的三条规矩

<ol><li><strong>每次用完固定导出一次</strong>，存进<code>D:\我的工作台\备份</code>。绑定在一个固定动作后面（比如周日晚上整理完），就不容易忘。</li><li><strong>换电脑、清缓存、重装系统之前，先导出。</strong>记住：清浏览器缓存 = 清空工作台，没有例外。</li><li><strong>恢复方法：</strong>点&quot;导入数据&quot;，选最新的 JSON 文件，确认。数据原样回来。</li></ol>

## 十一、进阶：让 WorkBuddy 继续替你干活

<p>软件搭好只是起点，真正的杠杆是让 WorkBuddy 跟这个工作台配合。三个进阶玩法：</p>

### 11.1 让它当周复盘教练

<p>写完三句话，把内容发给 WorkBuddy，让它追问——自己复盘容易自我安慰。</p>

```
这是我本周的复盘：……（粘贴）。请你像教练一样，只做三件事：
1. 指出我这周最大的一个自我安慰；
2. 判断我卡住的地方是方法问题还是意愿问题；
3. 给我下周一个具体到「做什么、做多久」的建议。不要说套话。
```

### 11.2 目标合理性体检

<p>年初定的目标，往往自己看不出问题。</p>

```
这是我的年度目标清单（粘贴）。请帮我判断：
1. 哪些目标之间在互相抢时间；
2. 哪几条其实不是目标，是愿望；3. 如果只能保留三条，你建议留哪三条，为什么。
```

### 11.3 年度回顾代写

<p>52 条周复盘，你自己拼不动，它一分钟搞定。</p>

```
这是我全年 52 条周复盘（粘贴导出内容）。帮我写一份 1000 字以内的年度回顾，分三部分：今年真正推进了什么 / 哪些目标该放弃 / 明年建议只做什么。语气平实，不要励志腔。
```

<p><strong>注意分工：本地软件没有 AI（它只存数据、做展示），AI 能力全部走 WorkBuddy 对话完成。</strong>这个分工反而是最稳的组合——软件不崩、AI 不用嵌进去，各干各的。</p>
