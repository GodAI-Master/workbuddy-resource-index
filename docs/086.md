# 00 工作台风格设定 · 图标配色布局全套提示词

## WorkBuddy 工作台全套资料 ·第 00 篇

<p><strong>本篇是全套 24 个工作台的「风格总纲」：图标怎么设计、配色怎么定、布局怎么调、格式怎么统一，全部整理成可以直接复制的提示词。</strong>最核心的，是第三节那条压在所有提示词之上的「风格设定总提示词」——以后不管做哪一个工作台，先发它，再发功能提示词，出来的东西就自带一套统一的、顺眼的风格。</p>

> [!NOTE]
> 📌
> <p><strong>本篇和后面 24 篇的关系</strong><strong>：</strong>01 篇教的是「怎么把工作台做出来」，本篇教的是「怎么把它做好看、好认、好点」。前 24 篇的提示词负责功能，本篇的提示词负责脸面。两条线互相不冲突，可以叠加使用。</p>

---

## 一、为什么风格这件事值得单独一篇

### 1.1 先看看你有没有这三个瞬间

<p><strong>瞬间一：</strong>功能都做出来了，打开一看——白底黑字满屏表格，像一张Excel截图套了个浏览器边框。功能没问题，但你就是不想天天打开它。</p>

<p><strong>瞬间二：</strong>让它&quot;美化一下&quot;，它给你加了一堆渐变、圆角、阴影、彩色图标，花花绿绿，热闹是热闹，想找&quot;今天该干什么&quot;反而比原来更费劲了。</p>

<p><strong>瞬间三：</strong>做了三个工作台，一个蓝色一个绿色一个粉色，导航一个在顶上一个在左边，图标一套是emoji一套是方块——桌面上摆三个&quot;软件&quot;，像三个不认识的开发商做的。</p>

<p>这三个瞬间的共同点：<strong>风格不是装饰，风格是&quot;想不想打开它&quot;的决定因素。</strong>一个天天要见的东西，丑三天就弃坑——功能再对也救不回来。</p>

### 1.2 好风格的四条标准（先建立判断力）

<p>审美没有标准答案，但&quot;好用的工作台风格&quot;有。拿这四条去验收，比&quot;我觉得好看&quot;靠谱得多：</p>

<table><thead><tr><th><p>标准</p></th><th><p>一句话解释</p></th><th><p>反例</p></th></tr></thead><tbody><tr><td><p>一眼分区</p></td><td><p>打开 3 秒内知道：我在哪、该看哪、点什么</p></td><td><p>所有内容挤在同一层级，找&quot;新建&quot;按钮扫半天</p></td></tr><tr><td><p>色彩克制</p></td><td><p>颜色只用来表意（状态、选中），不用来装饰</p></td><td><p>六个卡片六种颜色，红的绿的谁是谁分不清</p></td></tr><tr><td><p>密度合理</p></td><td><p>一屏看到今天要干的事，不用滚动</p></td><td><p>字小行密像财报，或者空旷得一屏一个按钮</p></td></tr><tr><td><p>风格统一</p></td><td><p>圆角、间距、图标、按钮，全软件一个脾气</p></td><td><p>有的卡片圆角 4px 有的 16px，emoji 和线框图标混用</p></td></tr></tbody></table>

> [!TIP]
> 💡
> <p><strong>最常犯的错：把&quot;美化&quot;理解成&quot;加东西&quot;。</strong>渐变、阴影、彩色图标一拥而上。真正的美化多半是<strong>减</strong>：统一颜色、对齐间距、砍掉装饰。给AI下风格指令时，&quot;克制&quot;两个字要明说，不然它天然倾向炫技。</p>

### 1.3 本篇的用法（两条路，都对）

<p><strong>路 A · 新建工作台：</strong>先发本篇第三节的「风格设定总提示词」，再发 01 篇或其他篇的功能提示词——风格和功能一次到位。</p>

<p><strong>路 B · 已有工作台翻新：</strong>功能已经跑起来，只是丑——直接把总提示词的&quot;翻新版&quot;发给它（3.3 节有），它会在不动功能的前提下把脸换了。</p>

## 二、先看懂：一个顺眼的工作台长什么样

<p>下指令之前，先得能&quot;说出它哪里好&quot;。把任何工作台页面拆开，无非五块：</p>

<table><thead><tr><th><p>部位</p></th><th><p>管什么</p></th><th><p>风格要点</p></th></tr></thead><tbody><tr><td><p>顶部栏</p></td><td><p>软件名 + 当前页面名</p></td><td><p>高 48-56px，底色比背景深一档，页面名加粗</p></td></tr><tr><td><p>导航区</p></td><td><p>切换页面（今日 / 明细 / 统计 / 设置）</p></td><td><p>选中项用主色底+白字或主色左侧竖条，别用彩虹色区分</p></td></tr><tr><td><p>卡片/区块</p></td><td><p>每组信息住一张卡</p></td><td><p>统一圆角（建议 8-12px）、统一留白（建议 16px）、浅边框或极浅阴影二选一</p></td></tr><tr><td><p>表格/列表</p></td><td><p>一行一条记录</p></td><td><p>表头底色浅灰、数字右对齐、行高 40px 上下、隔行微弱底色</p></td></tr><tr><td><p>状态标识</p></td><td><p>完成/逾期/进行中</p></td><td><p>固定的状态色规则（见第五节），小圆点或浅色胶囊，别整行涂色</p></td></tr></tbody></table>

<p>把这五块的风格要点讲给AI听，它就知道你要的不是&quot;炫&quot;，是&quot;整&quot;。第三节的总提示词，就是把这五块连同字体、图标、暗色模式，写成了它一次能听懂的话。</p>

## 三、风格设定总提示词（★本篇核心，压在所有提示词之上）

### 3.1 这条提示词的地位

<p>后面所有风格提示词（图标、配色、布局、格式）都是从它身上拆出来的细化版。<strong>用法只有一条规矩：发功能提示词之前，先发它。</strong>就像装修先定设计图纸，再让工人进场——反过来，先砌墙再定图纸，只能砸了重来。</p>

### 3.2 完整版（新建工作台用，直接复制）

```
在动手写任何代码之前，先给我确定这个工作台的视觉风格，风格定了之后所有页面都必须遵守，中途不许自由发挥。风格规范如下：

【整体气质】克制、干净、信息优先。禁止大渐变、禁止霓虹色、禁止炫技动效。宁可素一点，不要花。
【配色体系】只用四类颜色：
1. 主色 1 个：用于导航选中、主要按钮、强调数字（给你定一个：__PLACEHOLDER__）；
2. 状态色固定语义：成功/完成=绿，逾期/危险=红，进行中/提醒=橙黄，普通信息=蓝，不要挪用；
3. 背景中性色：页面背景浅灰、卡片纯白、边框浅灰，三档分明；
4. 文字色：正文深灰（不是纯黑）、次要说明中灰、禁用浅灰，共三档。
除以上四类，不得新增任何颜色。
【字体字号】中文用系统默认无衬线字体；页面标题 18-20px 加粗，区块标题 15-16px 加粗，正文 14px，辅助说明 12px。行高 1.5。所有数字用等宽字体对齐。
【布局骨架】顶部一条标题栏（高 52px），左侧导航栏（宽 180-200px），右侧内容区四边留白 16-24px。内容区里同层级的卡片宽度一致、间距一致（统一 16px）。
【圆角与阴影】全局统一：卡片圆角 10px，按钮圆角 8px，输入框圆角 6px。阴影只用一档极浅的，或干脆用 1px 浅边框，二选一全局统一。
【图标风格】页面内图标统一用一套线性图标或统一用 emoji，禁止混用；图标颜色跟随文字色，不单独上色。
【交互反馈】按钮有 hover 变色；删除等危险操作用红色但需二次确认；保存成功用 2 秒的轻提示，不弹大对话框。
【暗色模式】支持浅色/深色双主题，跟随系统自动切换，所有颜色成对定义，切换后对比度必须达标。先复述一遍这套规范，然后所有页面严格按这套规范实现。
```

<p>其中<strong>__PLACEHOLDER__</strong>是唯一需要你自己填的：主色。不知道填什么就从第五节的六套现成配色里抄一个色值，比如<strong>#3B82F6（冷静蓝）</strong>。填一个色，整套软件的气质就有了锚点。</p>

### 3.3 翻新版（工作台已经建好了，只换脸用）

```
我现在有一个已经能用的本地工作台小软件，功能一律不许动、数据结构不许动，只做视觉翻新。请按下面这套风格规范重做所有页面的样式：
（此处粘贴 3.2 节的规范，从【整体气质】到【暗色模式】）要求：一次只改样式层，改完每个页面截图或描述变化点给我确认；改完之后功能必须和之前完全一样，如有任何功能行为变化，立刻回退并告诉我。
```

> [!TIP]
> 💡
> <p><strong>翻新最容易翻车的点：</strong>&quot;只换脸&quot;指令不够硬，AI会顺手&quot;优化&quot;你的功能，数据字段一改，之前存的数据就读不出来了。所以&quot;功能一律不许动、数据结构不许动&quot;这两句一句都不能省，末尾那句回退要求也别删。</p>

### 3.4 三分钟精简版（懒得发长文时用）

```
帮我给这个工作台定一套风格：主色 __（填色值）__，完成绿/逾期红/进行中橙黄，背景浅灰卡片白，正文 14px 深灰，卡片圆角 10px 间距 16px 全局统一，图标统一用一套，支持深浅双主题。风格克制素净，禁止渐变和霓虹色。先复述规范再动手，之后所有页面都按这套来。
```

<p>总提示词里的【整体气质】和主色换一下，整套软件性格就变了。四套预设对应四类人，选一套顺眼的：</p>

## 四、图标设计提示词

### 4.1 桌面图标：让它给你画一个

<p>工作台装到桌面后（01 篇第八章的快捷方式做法），默认图标是浏览器 logo，一眼假。给它配一个专属图标，&quot;软件感&quot;立刻翻倍。让 WorkBuddy 生成图标文件：</p>

```
帮这个工作台设计一个桌面应用图标：
1. 先给我 3 个图标方案，用 SVG 画出来，每个方案一句话说明设计思路；
2. 风格要求：扁平简洁、单个主体、能缩到 32px 依然认得出、主色用工作台的主色 __（填色值）__、深浅两个底色版本各一份；3. 我选定一个后，导出为 512px 的 PNG 保存到项目文件夹，并告诉我怎么把它设成桌面快捷方式的图标（Windows 下 .lnk 换图标的操作步骤，一步步写）。
```

<p>验收就看一条：<strong>缩到很小还认得出主体。</strong>花里胡哨的细节缩小后全糊成一团，只剩主体轮廓——所以方案阶段就盯&quot;主体大不大、轮廓简不简&quot;。</p>

> [!NOTE]
> 📌
> <p><strong>换图标的手工步骤（Windows）：</strong>右键桌面快捷方式 → 属性 → 「快捷方式」页 → 更改图标 → 浏览选中导出的 .ico/.png → 确定。AI 给的步骤若与此不同，以系统实际界面为准，让AI重写一遍即可。</p>

### 4.2 页面内图标统一（治&quot;emoji 和方块混用&quot;）

```
这个工作台页面里的图标现在很乱：有的用 emoji、有的用几何符号。请统一处理：
1. 全软件只保留一种图标体系——建议统一用 emoji（简单直观不引入依赖），导航每项一个，语义要贴；
2. 列出你现在用的全部图标和替换后的对应关系表，先给我确认再改；3. 图标不单独上色，跟随文字颜色；同一含义的图标全软件只用一个（比如"删除"永远是同一个，别这页垃圾桶那页叉子）。
```

## 五、配色方案提示词

### 5.1 状态色规则（比主色更重要）

<p>主色只管&quot;气质&quot;，状态色管&quot;看一眼就知道事情处于什么状态&quot;。规则必须钉死，不许AI自由发挥：</p>

```
给这个工作台钉死状态色语义，全软件所有页面统一执行：
- 完成/达标/收益 = 绿色；
- 逾期/危险/亏损 = 红色；
- 进行中/待办/提醒 = 橙黄色；
- 一般信息/进行中的中性提示 = 蓝色；
- 已归档/不再活跃 = 灰色（并降低透明度）。状态只能用"小圆点、浅色胶囊、文字变色"三种形式呈现，禁止整行整卡大面积涂色；同屏同时出现的状态色不超过三种。另外：不许只用颜色区分状态，每个状态必须同时带文字或图标——照顾色弱的用户。
```

## 六、布局调整提示词

### 6.1 三种骨架，什么时候换哪种

<table><thead><tr><th><p>骨架</p></th><th><p>长什么样</p></th><th><p>适用</p></th></tr></thead><tbody><tr><td><p>侧边导航</p></td><td><p>左窄栏列 4-6 个页面（默认）</p></td><td><p>页面多、每页内容长（项目、财务、自媒体）</p></td></tr><tr><td><p>顶部导航</p></td><td><p>横条Tabs在标题栏下</p></td><td><p>页面少（≤4）且以表格为主（记录类）</p></td></tr><tr><td><p>卡片宫格</p></td><td><p>首页几大模块一屏摆开</p></td><td><p>每天只看一眼的工作台（梦境、追番进度）</p></td></tr></tbody></table>

<p>换骨架的提示词（结构改动大，务必先要求备份）：</p>

```
我要把工作台的布局骨架从现在的 __（现状）__ 改成 __（目标，如：左侧导航改成顶部Tabs）__。要求：
1. 先把当前完整代码备份一份到项目文件夹里的 backup 文件，再动手；
2. 只动布局结构，功能和数据完全不动；3. 改完列出所有页面的新位置对照表给我确认。
```

### 6.2 首页仪表盘：把&quot;今天该干什么&quot;钉在第一屏

```
把首页改成仪表盘式布局：第一屏不滚动就能看到——
1. 顶部一行 3-4 个关键数字卡（如：今日待办数、本周完成率、逾期数）；
2. 中间是"今天要做的事"列表，按时间排，可勾选；
3. 下方最多放一个趋势图或最近记录，不许更多；4. 每张卡片只能承载一个主题，禁止把无关内容塞进同一张卡。
```

### 6.3 密度调节与窄窗口适配

```
两个布局细节调整：
1. 信息密度调成"适中偏紧凑"：表格行高 40px 左右、卡片内边距 16px、区块间距 24px——我自己用不用给别人看，宁可多看几行也别一屏只装三条；2. 窗口缩到 900px 宽以下时自动变单列布局，导航收到顶部，表格允许横向滚动但关键字段（名称、状态、日期）固定不滚出屏幕。
```

## 七、格式细节提示词

### 7.1 数字与日期格式（治&quot;看串行&quot;）

```
全软件统一数据格式：
- 金额一律两位小数 + 千分位（1,286.50），带货币符号；
- 数字表格列右对齐，用等宽字体；
- 日期统一"2026-11-10"式短格式，需要时间时用"11-10 14:30"；- 表格为空时显示一句"还没有记录，点右上角添加第一条"，不要留一片空白。
```

### 7.2 按钮层级（治&quot;满屏都是重点&quot;）

```
整顿按钮层级，一屏只许一个主按钮：
- 主操作（如"添加记录"）：主色实底、白字，每页只放一个；
- 次操作（如"筛选""导出"）：白底灰边或浅色底；
- 危险操作（删除、清空）：红字或红描边，必须二次确认；- 同一排按钮统一高度 36px，禁止大小不一。
```

## 八、暗色模式与跟随系统

<p>总提示词里已含双主题要求，这里是落地细则。工作台晚上开灯率很高（梦境、追番、钓鱼复盘都是睡前/夜间场景），深色模式不是加分项是刚需：</p>

```
实现深浅双主题：
1. 所有颜色用 CSS 变量成对定义（浅色一套、深色一套），代码里不许出现写死的颜色值；
2. 默认跟随系统 prefers-color-scheme 自动切换，并在设置页给一个"浅色/深色/跟随系统"三选开关，选择存到本地；
3. 深色模式不等于反色：背景用深灰而不是纯黑，卡片比背景亮一档，文字用接近白而不是纯白，主色在深底下提亮 10-20% 保证对比度；4. 切换主题后每个页面检查一遍：没有看不清的文字、没有残留的浅色块。
```

## 九、八条风格迭代提示词（照抄返工）

<p>风格这事一遍到不了位，搭完用几天，哪不顺眼修哪。八条常用的，每条独立使用：</p>

<table><thead><tr><th><p>返工提示词</p></th><th><p>验法</p></th></tr></thead><tbody><tr><td><p>1. 颜色太花了，把所有非主色、非状态色的彩色全部去掉，只留四类颜色</p></td><td><p>截屏数颜色种类，应明显变少</p></td></tr><tr><td><p>2. 圆角和间距不统一，全局统一成卡片 10px、按钮 8px、间距 16px，逐页检查</p></td><td><p>两卡叠放边缘严丝合缝</p></td></tr><tr><td><p>3. 字太密看串行，行高加到 1.5，段落间距加大，次要信息降为 12px 灰字</p></td><td><p>眯眼看，第一眼只看到重点</p></td></tr><tr><td><p>4. 图标混乱，按 4.2 节统一成一套 emoji，先给对应表再改</p></td><td><p>全软件&quot;删除&quot;是同一个图标</p></td></tr><tr><td><p>5. 首页太空/太挤，按 6.2 节改成三段式仪表盘</p></td><td><p>第一屏不滚动看到今天的事</p></td></tr><tr><td><p>6. 表格数字看串位，金额千分位两位小数、数字列右对齐等宽字体</p></td><td><p>一列数字小数点对齐成直线</p></td></tr><tr><td><p>7. 深色模式下有看不清的字和残留浅色块，按第八节细则修</p></td><td><p>切深色逐页扫一遍</p></td></tr><tr><td><p>8. 整体太平没重点，只给主按钮和关键数字用主色，其他全部降级</p></td><td><p>每屏只一个最抢眼的元素</p></td></tr></tbody></table>

## 十一、验收清单

<ol><li>打开 3 秒内能说出：这是哪个工作台、今天该干什么（一眼分区）</li><li>数颜色：全软件彩色只有主色 + 状态色，没有第六种（色彩克制）</li><li>随机抽两张卡片叠一起：圆角、边框、内边距完全一致（风格统一）</li><li>表格一列数字：小数点对成直线，金额带千分位（格式合格）</li><li>切到深色模式逐页扫：没有看不清的字、没有白块残留（双主题达标）</li><li>桌面图标缩到很小仍认得出主体，且和主色一致（图标合格）</li><li>每屏只有一个主按钮抢眼（按钮层级合格）</li></ol>

## 十二、常见问题

<p><strong>Q1：总提示词太长，能砍吗？</strong>能，砍成 3.4 精简版。但【配色四类】和【状态色固定语义】两段别砍——这两段是防&quot;花&quot;和防&quot;看不懂状态&quot;的底线，砍了必返工。</p>

<p><strong>Q2：主色选纠结了怎么办？</strong>第一版永远用冷静蓝 #3B82F6，用一个月有感觉了再换。选色的时间成本远高于换色的成本。</p>

<p><strong>Q3：AI 生成出来的还是丑，反复修不好？</strong>九成是&quot;一次改太多&quot;。退回去：一次只发第九节里的一条，改完验收再发下一条。风格是迭代出来的，不是一次到位的。</p>

<p><strong>Q4：24 个工作台要 24 套风格吗？</strong>不要。共用一套（同主色同骨架），只换图标主材——这样桌面上摆一排才像&quot;一家出品&quot;。想要差异，最多按 3.5 的四套气质预设分组换色。</p>

<p><strong>Q5：换风格会不会弄丢数据？</strong>按 3.3 和 6.1 的写法（&quot;功能不许动、数据结构不许动、先备份&quot;）不会。但每次大改前手动导出一份备份文件（01 篇第七章的导出功能），是最稳的保险。</p>
